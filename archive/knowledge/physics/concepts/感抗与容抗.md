> [!TIP]
> **读完这一条，你应该**能用 `X_L = 2πfL` 与 `X_C = 1/(2πfC)` 算出感抗、容抗，说明电感上电压超前电流 90°、电容上电压滞后电流 90°，并用 `Z = √(R² + (X_L − X_C)²)`、`f0 = 1/(2π√(LC))` 与 `cosφ = R/Z` 分析串联 RLC 电路

## 定义

电阻、电感、电容接在同一个正弦交流源上，表现完全不同：

| 元件 | 电压与电流的相位 | 对交流的「阻力」 | 频率升高时 |
|---|---|---|---|
| 电阻 `R` | 同相（0°） | `R`，与频率无关 | 不变 |
| 电感 `L` | 电压超前电流 90°（1/4 周期） | 感抗 `X_L = 2πfL` | 变大 |
| 电容 `C` | 电压滞后电流 90°（1/4 周期） | 容抗 `X_C = 1/(2πfC)` | 变小 |

**感抗**与**容抗**统称电抗，单位都是欧姆。纯电感、纯电容的「交流欧姆定律」是

`I_rms = V_rms/X_L`，`I_rms = V_rms/X_C`

其中 `V_rms` 是元件两端的有效电压。教材的定性理由：电感反抗电流变化，`V = −L(ΔI/Δt)`，频率越高、电流变化越快，阻碍越大；电容在充满电时切断电流，频率越高、每次充电的时间越短，阻碍越小。

**串联 RLC 电路**里，三个元件流过同一个电流，但电压不同相，不能算术相加。教材给

`V0 = √(V0R² + (V0L − V0C)²)`

代入 `V0R = I0R`、`V0L = I0X_L`、`V0C = I0X_C`，得**阻抗**

`Z = √(R² + (X_L − X_C)²)`

以及 `I0 = V0/Z`、`I_rms = V_rms/Z`。电压与电流的相位差满足

`cosφ = R/Z`

平均功率为

`P_ave = I_rms V_rms cosφ`

`cosφ` 叫**功率因数**。当 `X_L = X_C` 时，二者抵消，`Z = R` 达到最小、电流达到最大，这个频率叫**谐振频率**：

`f0 = 1/(2π√(LC))`

教材的例子（`R = 40.0 Ω`、`L = 3.00 mH`、`C = 5.00 μF`、`V_rms = 120 V`）：

- 60 Hz：`X_L = 1.13 Ω`、`X_C = 531 Ω`、`Z = 531 Ω`、`I_rms = 0.226 A`
- 10 kHz：`X_L = 188 Ω`、`X_C = 3.18 Ω`、`Z = 190 Ω`、`I_rms = 0.633 A`
- 谐振：`f0 = 1.30 kHz`、`Z = R = 40.0 Ω`、`I_rms = 3.00 A`
- 60 Hz：`cosφ = 0.0753`、`φ = 85.7°`、`P_ave = 2.04 W`；谐振时 `P_ave = 360 W`

低频时容抗占主导，高频时感抗占主导；教材用这一点解释滤波：电感串联可挡高频，电容串联可挡低频。

> [!IMPORTANT]
> **电抗不是电阻。**
>
> 教材把 `X_L`、`X_C` 叫作 `effective resistance`，这只是「对电流的阻碍」的比喻。电阻把电能变成热，电抗只把能量在电场与磁场之间来回存取：电感储能 `½LI²`，电容储能 `½CV²`，理想电抗不耗散功率。所以 `I_rms = V_rms/X` 形式上像欧姆定律，`P_ave` 却不能写成 `I_rms²X`——RLC 电路的平均功率只由 `R` 耗散，等于 `I_rms²R`。

> [!IMPORTANT]
> **相位差的符号要自己判，教材只给了 `cosφ`。**
>
> `cosφ = R/Z` 只确定相位差的大小，不能区分电流超前还是滞后。本库补出判据：`X_C > X_L` 时电路呈容性，电流超前电压；`X_L > X_C` 时呈感性，电流滞后电压；相等时谐振、同相。教材的 60 Hz 例子里 `X_C` 远大于 `X_L`，所以是容性、电流超前；10 kHz 例子相反。教材没有写这条判据，只写「电容上电压滞后电流、电感上电压超前电流」。

> [!NOTE]
> **教材的五处问题（本条的处理方式）。**
>
> 1. **`effective resistance` 的说法**把不耗能的电抗与电阻混为一谈；本条改称「电抗」，并明确它不耗散平均功率。
> 2. **`X_L` 与频率成正比的解释**写成「f 大所以 Δt 小、ΔI/Δt 大」，把频率与变化率混为一谈；严格关系来自 `V = L dI/dt`，本例的推导见 K1。
> 3. **m42431 的习题写 `f = 7.50 Hz`**，但答案 `cosφ = 0.159`、`φ = 80.9°` 对应约 1.0 kHz（7.50 Hz 时为 `cosφ ≈ 1.18×10⁻³`，7.50 kHz 时为 `cosφ ≈ 0.765`）；且 (c) 的 `26.4 W` 是视在功率 `V_rms²/Z`，按 `P_ave = I_rms²R` 应约为 `4.2 W`。本条不采用这组答案。
> 4. **术语表把功率因数定义为「功率比最大值小的量」**，把比值写成了量；功率因数是 `cosφ`，范围 0 到 1，无量纲。
> 5. **「高频时电容像一根导线」说过头**：理想电容的 `X_C → 0`，但实际元件有引线电感与等效串联电阻；「设计高效电机要看功率因数」也超出串联 RLC 的适用范围，本条只把它当作功率因数的一个应用，不展开电机模型。

## 论证

### K1 · 感抗与容抗来自「电压—电流」的微积分关系（尚无攻击）

- **主张**：电感上电压超前电流 90°、`X_L = ωL`；电容上电压滞后电流 90°、`X_C = 1/(ωC)`
- **前提**：教材给 `V_L = −L(ΔI/Δt)`、`V_C = Q/C`、`I = ΔQ/Δt`，并说 `X_L = 2πfL`、`X_C = 1/(2πfC)` 可由基尔霍夫定律与微积分得到，但没有写出推导（ev-195）；推导是本库补写的
- **推理**：设电感两端电压 `V = V0 cosωt`。由 `V = L dI/dt` 得 `dI/dt = (V0/L)cosωt`，积分得 `I = (V0/(ωL)) sinωt = I0 cos(ωt − 90°)`，所以电流滞后电压 90°，振幅比 `V0/I0 = ωL`。设电容两端电压 `V = V0 cosωt`，由 `I = C dV/dt` 得 `I = −ωCV0 sinωt = I0 cos(ωt + 90°)`，所以电流超前电压 90°，振幅比 `V0/I0 = 1/(ωC)`
- **证据**：ev-195
- **被攻击**：教材没有推导，只把微积分结果当作已知；本条补出的是**稳态正弦解**，不含开关瞬间的暂态（暂态需要初始条件与微分方程的通解，本库未建）。另外，这个推导用到了导数，高中教材通常只要求记住结果与定性理由
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 串联 RLC 的阻抗是「电阻与净电抗的勾股和」（尚无攻击）

- **主张**：`Z = √(R² + (X_L − X_C)²)`；谐振时 `X_L = X_C`、`Z = R`、电流最大，`f0 = 1/(2π√(LC))`
- **前提**：教材由 `V0² = V0R² + (V0L − V0C)²` 与 `V0R = I0R`、`V0L = I0X_L`、`V0C = I0X_C` 得到 `Z`，再由 `X_L = X_C` 解出 `f0`（ev-195）
- **推理**：串联电路电流相同，`R` 上电压与电流同相，`L` 上电压超前 90°，`C` 上电压滞后 90°；后两者方向相反、先相减，再与 `R` 上的同相电压按直角合成，所以是勾股和。谐振时 `X_L = X_C`，两个电抗电压大小相等、方向相反，完全抵消，阻抗只剩 `R`；此时 `I_rms = V_rms/R` 最大。由 `2πf0L = 1/(2πf0C)` 解出 `f0`
- **证据**：ev-195
- **被攻击**：教材只给结果，没有画相量图或解释「先相减再勾股」；本条补出这条几何论证。谐振时电感与电容上的电压可以各自大于电源电压（大小相等、方向相反），教材没有讨论品质因数 `Q`，本库把它记在缺口表
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 平均功率由电阻决定，功率因数修正「电压电流不同相」（尚无攻击）

- **主张**：RLC 串联电路的平均功率 `P_ave = I_rms V_rms cosφ = I_rms²R`；只有电阻耗散能量，电感与电容只交换能量
- **前提**：教材写 `cosφ = R/Z`、`P_ave = I_rmsV_rms cosφ`，并强调电感与电容「有能量输入输出但不耗散」，电阻耗散的正好是电源输入的能量；例子里 60 Hz 的 `P_ave = 2.04 W`、谐振时 `360 W`（ev-195）
- **推理**：`I_rmsV_rms cosφ = I_rmsV_rms(R/Z) = I_rms(V_rms/Z)R = I_rms²R`，所以平均功率等于电阻上的焦耳热。相位差越大，`cosφ` 越小，同样的 `I_rmsV_rms` 中真正被耗散的比例越低；谐振时 `φ = 0`、`cosφ = 1`，平均功率最大
- **证据**：ev-195
- **被攻击**：教材把「功率因数接近 1 对高效电机有利」当作例子，但电机不是串联 RLC，不能直接套本条的 `cosφ = R/Z`；本条只保留「平均功率由 R 决定、相位差降低功率因数」这一层，不把电机模型当作已建内容。另外，`cosφ` 只给大小，超前／滞后的判据见上面的 IMPORTANT
