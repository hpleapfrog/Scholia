> [!TIP]
> **读完这一条，你应该**能用 `ε = Bℓv` 计算导体棒切割磁感线的电动势、用 `F = qvB` 与 `ε = ΔΦ/Δt` 两条路线说明它为什么成立，并解释涡流为什么会阻尼运动、为什么开槽或换用绝缘体就不阻尼

## 定义

**动生电动势**是导体与磁场有相对运动时产生的电动势。当 `B`、导体长度 `ℓ`、速度 `v` 三者两两垂直时：

`ε = Bℓv`

教材给出两条入口，结果相同：

- **洛伦兹力路线**：导体中的电荷随导体一起以 `v` 运动，受 `F = qvB` 沿导体方向推。电荷在两端积累，直到电场力与磁力平衡：`qE = qvB`，即 `E = vB`；两端电势差为 `ε = Eℓ = Bℓv`- **法拉第路线**：导体扫过的面积 `ΔA = ℓΔx`，`ΔΦ = BΔA`，`ε = ΔΦ/Δt = BℓΔx/Δt = Bℓv`

方向由楞次定律或右手定则判断；教材的滑块电路里，棒向右运动、磁场垂直纸面向里时，感应电流逆时针、棒的上端为正。相对运动才是关键：导体动、磁场动都算。

不两两垂直时，一般式为 `ε = Bℓv sinθ`（`θ` 是 `v` 与 `B` 的夹角，或 `ℓ` 与 `B` 的夹角，取决于哪一对垂直）。教材正文只写垂直情形，这个一般式只出现在习题要求里。

**涡流**是导体内部的感应电流环。导体进出磁场时磁通量变化，涡流受的磁场力**反抗相对运动**，称为**磁阻尼**：

- 进入磁场：磁通量增加，感应电流的方向使回路受力向后；离开磁场：磁通量减少，感应电流反向，受力仍向后
- 导体**完全处在均匀磁场内部**时磁通量不变，没有涡流、没有阻尼
- 开槽的金属板把大回路切成小回路，相邻回路电流相反、效果相消；绝缘体中涡流极小
- 磁阻尼力随速度减小而减小，**不能把物体完全停住**——列车与过山车的涡流制动只能减速，最后还要靠摩擦制动

数量级：地磁场中 `1.0 m` 的棒以 `3.0 m/s` 运动，`ε = 5.0×10⁻⁵ × 1.0 × 3.0 = 150 μV`；系绳卫星的 `20 km` 导体以 `7.80 km/s` 穿越 `5.00×10⁻⁵ T`，最大 `7.80 kV`（实际约 `5 kV`，因为速度与磁场不垂直）。

> [!IMPORTANT]
> **两条路线的等价性由本库补出。**
>
> 教材说运动电荷的磁力「产生 `emf = Bℓv`」，又说这与霍尔效应的表达式相同，但**没有写出电荷分离到 `qE = qvB` 的平衡过程**——那是本条的推导（K1）。教材也没有区分「沿导体长度的动生电动势」与「横跨导体宽度的霍尔电压」：两者都写成 `B×长度×v`，用的却是不同的长度。教材只把霍尔效应称为感应的一个方面。

> [!IMPORTANT]
> **涡流不是「只有动生电动势才有」。**
>
> 教材术语表把涡流定义为「由动生电动势引起的电流环」，但正文自己说：导体运动或**磁场相对导体运动**都会产生动生电动势。更一般地，导体不动、磁场随时间变化（变压器铁芯）同样有涡流。本条按「导体中的感应电流环」理解，不把涡流限制在切割磁感线的情形。

> [!NOTE]
> **教材的四处问题（本条的处理方式）。**
>
> 1. **正文只给 `ε = Bℓv`（垂直条件）**，习题却要求证明 `ε = Bℓv sinθ`；本条把一般式补在定义里，并注明来源位置。
> 2. **系绳卫星题的能量不一致**：题给 `5.00 kV × 10.0 A = 50 kW`，但 (b) 的 `2.81×10⁸ J` 来自 `F = IℓB = 10.0 N` 乘 `7.80 km/s` 乘 `3600 s`，即 `78 kW`，两者相差 `1.56` 倍。本条只采用力的计算与能量量级，不把这条能量链当作自洽结论。
> 3. **电磁炉「锅底必须是铁磁性的，感应才工作」说过头**：涡流在任何导体中都能产生；铁磁性是常见炉具的耦合与效率条件，教材没有展开。本条只写「常见电磁炉要求铁磁性锅底」，不把它当成物理必要条件。
> 4. **「磁阻尼力与速度成正比」未推导**，教材只在应用处这样描述；本条的 K2 把它标为未证的理想化。

## 论证

### K1 · 洛伦兹力路线与法拉第路线给出同一个 `Bℓv`（尚无攻击）

- **主张**：动生电动势既可以用导体中电荷受 `qvB` 的微观力解释，也可以用磁通量变化率的法拉第定律解释，两者给出同一个 `ε = Bℓv`
- **前提**：教材写运动电荷受 `F = qvB`、正负电荷向相反方向移动并「产生 `emf = Bℓv`」，随后用 `ΔA = ℓΔx` 与 `v = Δx/Δt` 从法拉第定律推出同一结果（ev-193）；电荷分离到 `qE = qvB` 的平衡过程是本条补出的推导
- **推理**：在实验室系看，电荷随棒运动，磁力沿棒推动电荷；电荷积累产生的电场最终与磁力平衡，`E = vB`，沿棒积分得 `Bℓv`。换到棒的静止系，电荷不动、磁场以 `−v` 运动，运动的磁场产生电场，同样给出 `E = vB`。两条路线是同一物理事实的两种描述
- **证据**：ev-193
- **被攻击**：教材把「霍尔效应」与「动生电动势」直接并列，但没有写出平衡推导，也没有说明两个「长度」不同：霍尔电压横跨导体宽度，动生电动势沿导体长度。教材的「力的统一」框只提到运动电场与运动磁场的关系，没有展开参考系变换
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 涡流阻尼来自楞次定律，进入与离开都减速（尚无攻击）

- **主张**：导体进出磁场时，涡流受的磁场力总与运动方向相反；均匀磁场内部没有涡流
- **前提**：教材分析金属摆在磁极间摆动：进入时磁通量增加、感应电流逆时针，只有位于场内的右边受力向左；离开时磁通量减少、电流顺时针，受力仍向左；完全进入均匀场后磁通量不变、无电流；开槽板的小回路电流相消，绝缘摆几乎不受影响（ev-193）
- **推理**：楞次定律要求感应电流的磁场反抗磁通量变化。进入时「反抗增加」，离开时「反抗减少」，两种情况下磁场对电流的安培力都指向运动的反方向，所以阻尼在进出两个边界都出现。均匀场内部没有通量变化，也就没有感应电流和阻尼
- **证据**：ev-193
- **被攻击**：教材说磁阻尼「drag is proportional to speed」，但没有推导；实际的涡流分布、电阻率与频率都会影响阻尼力，开槽板的「效果相消」也只是定性描述。本条不把「正比于速度」当作已证结论
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 涡流的应用是一组取舍（尚无攻击）

- **主张**：磁阻尼可用于天平、垃圾分选、金属探测器与车辆制动，但每种应用都有边界
- **前提**：教材列出：天平用磁阻尼快速止摆，速度为零时阻尼也为零，所以不影响灵敏度；垃圾分选利用涡流只发生在导体中，可分出所有金属而不只是铁磁金属；金属探测器用涡流改变副线圈电流；列车与过山车制动平稳、受天气影响小，但不能完全停车；电磁炉用涡流加热锅底，常见炉具要求铁磁性锅底（ev-193）
- **推理**：阻尼力随速度减小，意味着它擅长「快速消能」而不擅长「最终锁死」；涡流只在导体中产生，意味着它能区分金属与非金属，但不能区分金属种类；涡流加热不需要火焰，但锅底材料与炉具的耦合决定效率
- **证据**：ev-193
- **被攻击**：教材对金属探测器给了两套机制——m42420 说金属改变线圈的自感，m42404 说涡流改变副线圈电流——没有合并；对电磁炉的「必须铁磁性」也没有区分物理必要与工程常用。本条把这两处标为未核，不替教材补因果
