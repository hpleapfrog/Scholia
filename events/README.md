# 事件

> **English: [README.en.md](README.en.md)**

> [!IMPORTANT]
> **本目录是「事件」——与知识对象（[`knowledge/`](../knowledge/)）并列的另一类记录。**
>
> 命题回答「**什么是真的**」（有真值、可被论证攻防、收敛到 `已确证`/`已推翻`/`失据`）；
> 事件回答「**发生了什么**」（按时间记录官方发布的事实，**只有证据、没有可被攻击的主张**）。
>
> 因此事件**单开顶层**、**不进 `index.json` 的 `objects`**、不计入对象总数、
> **没有 `## 论证` 段、没有任何 `先修`/`支持`/`攻击` 边**。
> 规则见 [FORMAT.md §4「事件」](../FORMAT.md)。

## 状态

`事件` 的状态只回答一个问题：**这条现在还在更新吗。**

| 状态 | 含义 |
|---|---|
| **持续更新** | 事件仍在发展，本条随新进展**增补证据行** |
| **已封存** | 事件已不再发展，不再增补 |

> [!NOTE]
> 事件**没有** `已确证` / `已推翻` / `失据` / `已失效`——那些是命题的档，事件不靠论证成立，
> 也不会「失效」。**「发生了」就是「发生了」。**

## 维护协议（每次有新进展）

1. `陈述` 的时间线**加一行**
2. 若是新来源 → `依据` 表与 [`evidence/README.md`](../evidence/README.md) 各加一行
3. `变更记录` 加一行
4. `updated:` 改为当日；`status` 保持 `持续更新`
5. 跑 `python tools/kbcheck.py --write-index`（会更新 `index.json`）
6. 提交 PR
