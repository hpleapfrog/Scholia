# Scholia

> **一张知识图，无限本教科书。**
>
> 对教材与教法做公开、可追溯的勘误与复核。没有权威主副本。

---

## 使命

> **在网络时代去除噪音，存放真实信息。**

这句话必须说得更准确一点，否则会被误读成一个本库**并不做**的承诺：

| 它**不**做 | 它**做** |
|---|---|
| ❌ 判定「什么是真的」 | ✅ 让每个主张**带上它的证据与它的反驳** |
| ❌ 由多数人或权威裁定结论 | ✅ 由**证据等级 + 反驳关系**按规则算出状态 |
| ❌ 声称自己可靠 | ✅ 让**可核验性**可见：谁署名的 · 从哪来 · 被谁攻击过 · 攻不攻得倒 |

> [!IMPORTANT]
> **噪音不是「错的东西」，是「无法追溯的东西」。**
>
> 一条来源不明的断言，和一条有据可查的错误——**前者的危害更大**，
> 因为后者能被改，前者连从哪下手都不知道。
>
> **本库的可靠性不来自它说得对，而来自它把「凭什么这么说」摆在明面上。**

### 已经发生过的三次

这不是宣言，是**已经跑过的三次**：

| 情形 | 机制怎么处理的 |
|---|---|
| 早期为演示格式而**编造的数据**（ev-009~ev-012）差点被当成证据引用 | 三条示例条目全部改为真实来源；作废证据**标记「已作废」并保留编号**，不删除痕迹 |
| 一条命题用 **n=2 且同来源**的观测做归因 | 被 [命题：n=2 无法归因](knowledge/物理/命题/两个样本无法归因.md) 攻击，状态转为 **`失据`** |
| 一条命题号称有 **15 条支持** | 校验器指出：**它们全部来自同一本书**，不是 15 份独立证据 |

> **三次都是机制发现的，不是人偶然注意到的。** 这就是「去除噪音」在工程上的含义。

## 这是什么

教材里有错，老师会口头告诉你哪一处错了。Scholia 把这件事制度化：

- 协议层只回答三件事：**这份内容是谁署名的？它从哪里来？它和谁冲突？**
- 协议层**永不回答**"什么是真的"。真伪由每个读者在本地视图里裁决。
- 知识图是唯一的；教科书是这张图**针对某个具体读者**的一次投影。

## 三条判断

1. **投票不能决定真理。** 结论由「证据等级 + 反驳关系」按规则算出，不由人数决定。少数方只要证据够硬，就不会被人数抹掉。
2. **知识要收敛，教法要并存。** 命题必须收敛成一个结论；教法**禁止**排唯一最优——强行给教法排名就是制造教条。
3. **可退出。** 任何人可以带全部历史 fork 离开，不需要任何人同意。

## 最小目标

**先做完一个学科的一章。**

不是"备份人类知识"——那不是一个可执行的目标。可执行的是：一本教材的一章，200 条勘误，跑通从 0 到 200 的全过程。

> [!TIP]
> **别从完整知识点开始，从单点勘误开始。**
>
> 「这页第 3 行剂量印错了，正确值见说明书第 X 版 P.Y」——这种条目 **3 分钟**能做完，
> 而且数值、单位、引用这类错误**程序能验证**，不需要画论证图。
>
> 完整知识点要 30–60 分钟。**录入成本决定这个项目的生死。**

> [!WARNING]
> **但本库目前的实际做法与上面这条建议是相反的。**
>
> 45 条里绝大多数是**完整知识对象**（30–60 分钟一条），不是单点勘误。
> 原因不是那条建议错了，而是采集路径先撞上了「**带教学指导的开放教材**」——
> 一次全量提取就能批量产出可复算的来源依据，单点勘误的路子反而没有先走。
>
> **录入成本这条约束仍然有效，只是暂时还没成为瓶颈。** 见文末「未决」。仍见 [Issue #2](https://github.com/hpleapfrog/Scholia/issues/2) 那批勘误——那条路是通的。

## 格式

**一个知识点 = 一个 `.md` 文件**：`front-matter` 存机器需要的，正文存人需要的。

- GitHub **原生渲染**——打开网页就能看懂，不需要任何工具
- 论证图用 **Mermaid** 写在正文里，GitHub 直接画出来
- 争议用 **GitHub alert**（`> [!WARNING]`）显著标出
- diff 看得见改了哪句话，而不只是哪个字段变了

完整规范见 [FORMAT.md](FORMAT.md)。示例见 [`knowledge/`](knowledge/README.md)。

## 校验

```bash
python tools/kbcheck.py
```

零依赖、不联网、不要密钥。它查两类东西。

**文件级**（单看一个文件就能查）：

- `front-matter` 字段是否完整
- `type` / `status` 是否合法（只有 `命题` 可以用「已确证」）
- `id` 有没有撞
- 相对链接是否都可达
- 必备小节是否齐全

**图级**（单看一个文件**查不出来**，问题只在文件之间）：

- `先修` 边只连「知识点」，且**无环**
- `教法` 都有 `knowledge_point`，且指向「知识点」
- `支持` / `攻击` 边都落在**具体论证**上（锚点必须存在）
- 每条路径的**先修缺口**
- 每条路径的**目标覆盖度**（有成果没被覆盖 → **直接判失败**）
- 论证图进边统计（并提醒：**条数不代表强度**）

**每一项都注入了错误验证过**——不是「写了就算」。

**这是「手动挡」：提交前你得自己跑一次。**

> [!NOTE]
> 想改成自动挡（每次 PR 自动跑、不通过就合不进去），加一个十来行的 workflow 即可，零成本、不要密钥。
> 按 [CONTRIBUTING.md](CONTRIBUTING.md) 的触发条件 C，这件事等到**第一次出现违规改动**时再做。

## 怎么贡献

| 你想做什么 | 去哪里 | 影响结论吗 |
|---|---|---|
| 提问、聊方法论、提还不成熟的想法 | **Discussions** | ❌ **不影响** |
| 报告疑似错误、提交教法 | **Issue**（用模板） | 间接 |
| 真的修改知识本身 | **PR** | ✅ **唯一能改变结论的通道** |

两条护栏：**`status` 只能由 PR 作者按规则写入**（写成「已确证」需一名非作者的独立复核）；**👍 reactions 只作注意力排序，绝不作判定依据**。

详见 [CONTRIBUTING.md](CONTRIBUTING.md)。

代码与格式规范用 **MIT**：格式带共享条款，等于亲手阻止它成为标准。

**署名**：见每个条目的 `author` 字段与 Git 提交历史。复用本库时，保留一条指向本仓库的链接即视为满足署名要求。

## 免责

> [!CAUTION]
> **使用前请完整阅读本节。**

- **这不是教材，也不是教学处方。** 它不替代任何正式教材、课程标准或教师资格要求。
- **「已确证」不表示绝对正确。** 它只表示：在当前证据下，存活论证的结论一致，且不存在未决反驳。它**不表示**没有更强的证据尚未出现。
- **`争议` 是正常且诚实的结果**，不是缺陷。真实世界的深水区本来就长期存在分歧。
- **教法效果因人而异。** 所有教法都是条件性结论。使用前必须核对「禁忌」栏。
- **绝不上传教材原文或扫描页**，只存页码定位、短引用、原创摘要与结论。事实与数据不受版权保护，**表达**受版权保护。
- 内容按「现状」提供，不附带任何明示或默示的担保。

## 未决

### 结构

1. **前置在学科之外时表达不了** —— 「会读几何里的角」→`光的反射`。
   目前只有 **1 例**，[Issue #17](https://github.com/hpleapfrog/Scholia/issues/17) 挂着，**等积累到 3–5 例再动结构**
2. **「进阶」关系没有表达手段** —— 初中「力与运动」与高中「惯性」是**深化**而非前置，
   现在只能写在正文里，建边会被跨学段警告提示为「请确认为前置而非进阶」
3. **`支持` 边的独立性算不出来** —— 来源归属是自由文本，校验器只能报条数并提醒，
   **独立与否必须由人判断**

### 机制

4. **`已确证` / `争议` / `已推翻` 三个状态从未被使用** —— 都要求独立复核者，
   **单贡献者状态下无法诚实地产生**。这不是可以靠写代码补的缺口
5. **「目标覆盖度」只算「有没有环节覆盖」**，不算**覆盖得够不够** —— 质量无从机械判断

### 生存

6. **录入成本能否压到 5 分钟以内** ← **这条决定项目生死**
