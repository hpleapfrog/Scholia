# 资源 模板

> `资源` 是**外部材料**：交互式模拟、官方文件、图示、习题集。
> 它只声明「这个材料是什么、在哪、能不能用」，**不声明它说了什么**。
>
> 跑 `python tools/new_entry.py --type 资源 --subject 生活 --slug your-slug --title "你的标题"`。

```markdown
---
id: {{ID}}
type: 资源
title: {{TITLE}}
status: 草案
author: "{{AUTHOR}}"
created: {{DATE}}
updated: {{DATE}}
scope:
  学科: {{SUBJECT}}
  学段: {{STAGE}}
  适用: {{APPLY}}
  条件: {{CONDITION}}
edges:
  先修: []
  支持: []
  攻击: []
evidence: [{{EVIDENCE}}]
license: CC-BY-SA-4.0
---

## 定位

| 项 | 内容 |
|---|---|
| 名称 | {{TITLE}} |
| 类型 | 交互式模拟 / 官方文件 / 图示 / 习题 |
| 权威发布者 | （谁发布 —— 可问责的主体） |
| 版本 · 生效时间 | （只声明该版本如此） |
| 地址 | |
| 许可 | （**逐条核对**：教材是 CC BY 不等于它嵌的东西也是） |

> [!CAUTION]
> **资源条目不转述内容。** 说「该文件规定了 X」要另立一条 `命题` 并逐条核对；
> 资源条目只说「它在那儿」。

## 论证

### A1 · 这是一份真实存在的材料（尚无攻击）

- **主张**：
- **前提**：
- **推理**：
- **证据**：{{EVIDENCE}}
- **署名**：{{AUTHOR}} · {{DATE}}

## 变更记录

| 日期 | 操作 | 依据 | 谁 |
|---|---|---|---|
| {{DATE}} | 建立条目 | {{EVIDENCE}} | {{AUTHOR}} |
```

## 这个类型最容易写错的地方

| 错法 | 后果 |
|---|---|
| 在资源条目里转述内容 | 「链接打得开」不等于「它这么说」——转述必须另立命题 |
| 许可靠印象 | 教材 CC BY ≠ 它嵌的图/视频也是 CC BY |
| 不写版本与生效时间 | 官方文件会换版，不限定版本就等于声明「永远如此」 |
