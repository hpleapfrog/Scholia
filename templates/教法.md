# 教法 模板

> `教法` 是 **(知识点 × 水平档)** 的一种讲法。它**条件性有效、不收敛**——所以**必填禁忌**，
> 而且**永远不能写成 `已确证`**：允许一个教法「已确证」，等于承认存在唯一最优讲法。
>
> 跑 `python tools/new_entry.py --type 教法 --subject 物理 --slug your-slug --title "你的标题"`，
> 生成后**先改 `knowledge_point`**，让它指回你的知识点。

```markdown
---
id: {{ID}}
type: 教法
title: {{TITLE}}
status: 草案
author: "{{AUTHOR}}"
created: {{DATE}}
updated: {{DATE}}
scope:
  学科: {{SUBJECT}}
  学段: {{STAGE}}
  水平档: {{LEVEL}}
  适用: {{APPLY}}
  条件: {{CONDITION}}
knowledge_point: ["[知识点]({{KPATH}})"]
edges:
  先修: []
  支持: []
  攻击: []
evidence: [{{EVIDENCE}}]
license: CC-BY-SA-4.0
---

## 做法

**先说清这一步要学生做什么**，再给可以照着说的话（原话优先，带中文说明）。

| # | 环节 | 老师说 / 学生做 |
|---|---|---|
| 1 | | |
| 2 | | |

## 禁忌

**对谁不适用？**（人群 / 适用性维度，**不是**失败模式）

| 不适用 | 证据强度 |
|---|---|
| | 强 / 弱（**拿不出强证据就写「弱」，不要编**） |

## 风险

**用这个方法会怎么翻车？**（做法本身的失效模式）

| 风险 | 怎么发生 | 怎么止损 |
|---|---|---|
| | | |

> [!IMPORTANT]
> **`禁忌` 与 `风险` 必须分开。** 前者答「对谁不适用」，后者答「怎么做会翻车」。
> 路径的自检要判断「所选教法在本画像下是否被标注为不适用」——两栏混了，这项自检就永远判不了。

## 证据

| 编号 | 类型 | 等级 | 定位 | 许可 |
|---|---|---|---|---|
| {{EVIDENCE}} | （教材 Teacher Support / 课堂实验 / 准实验） | 中 / 低 | | |

> **教法的等级阶梯与命题不同**（高 → 低）：可复现的课堂实验 > 准实验 > 大样本课堂数据 >
> 单一课堂经验 > 专家直觉。**单一课堂经验在教法里是合法证据**——不要套用医学标准。

```

## 这个类型最容易写错的地方

| 错法 | 后果 |
|---|---|
| 缺 `scope.水平档` | 校验器失败（`R-SCHEMA-13`）：BL / OL / AL，或跨档写「不分档」 |
| `knowledge_point` 指向命题或教法 | 校验器失败（`R-SCHEMA-12`）：**必须指向知识点** |
| 把风险写进禁忌 | 路径自检失效（`禁忌` 只答「对谁不适用」） |
| 写成「这样教有效」 | 证据只支持「这本教材建议这样教」——**跨过这一步就是过度推断** |
