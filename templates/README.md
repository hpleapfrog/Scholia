# 模板：把一条知识的录入压到 5 分钟

> English → [**README.en.md**](README.en.md)

> [!IMPORTANT]
> **本目录回答项目的第一号未决问题**：「录入成本能否压到 5 分钟以内」。
> 在此之前，绝大多数条目是 30–60 分钟的**完整对象**——这跟「从单点勘误开始」的建议正好相反，
> 也是单贡献者项目最容易死掉的地方。
>
> **模板不降低标准，只降低摩擦。** 该填的证据、该写的论证、该标的禁忌，一个都不少。

## 两种用法

### 一、一条命令生成（推荐）

```bash
python tools/new_entry.py --type 命题 --subject 物理 --slug deceleration-not-a-term --title "「减速」不是物理术语"
```

它会：按类型选目录 → 抄对应模板 → 填 `id` / `作者` / `日期` / `许可` → 打印还差哪几步。

### 二、手工复制

打开 `命题.md` / `知识点.md` / … ，复制里面围栏中的内容，另存为
`knowledge/<学科>/<类型>/<标题>.md`，再把 `{{…}}` 占位符换成真实内容。

## 六个类型各管什么（别选错）

| 你有的是 | 用哪个模板 | 一句话判据 |
|---|---|---|
| 一个**概念** | [知识点](知识点.md) | 它是「什么」，不判断真假 |
| 一个**有真假的结论** | [命题](命题.md) | 它**可能被反驳**，而且你能说出凭什么 |
| 一种**讲法** | [教法](教法.md) | 它回答「怎么教」，**条件性**成立 |
| 一个**常见错误理解** | [误解](误解.md) | 它把「很多人会怎么错」写成资产 |
| 一条**学习顺序** | [路径](路径.md) | 它是知识点的编排，每一步都连到条目 |
| 一份**外部材料** | [资源](资源.md) | 它只说「东西在哪」，不转述内容 |
| 一件**发生的事** | [事件](事件.md) | 它只有时间与证据，**没有主张可攻** |

> **拿不准的时候问一句**：这条东西**能不能被反驳**？
> 能，就是 `命题`；不能，看它是概念、讲法、误解、顺序还是材料。

## 英文译本：文件名由 `id` 派生

每个条目还有一份英文译本。**它的文件名不是中文名 + `.en.md`**，而是由 `id` 派生：

```
id:   kb:physics:kp-frame-of-reference
中文： knowledge/物理/知识点/参考系.md
英文： knowledge/物理/知识点/frame-of-reference.en.md
```

规则：取 `id` 最后一段 → 去掉类型前缀（`kp-` `prop-` `method-` `mis-` `path-` `res-` `attack-`）
→ 加 `.en.md` → **放在与中文原件同一个目录**。

`python tools/new_entry.py` 生成完会把**这个文件名直接打印出来**，复制就行。

英文页第一行固定写：

```markdown
> **English version of [`参考系.md`](参考系.md).**
```

> [!IMPORTANT]
> **漏建译本不判失败，但每次跑校验都会列出来**；而**文件名不由 `id` 派生**、
> **英文页链到中文页**，都是**失败**（`R-BILING-01` / `R-LINK-03`）。
> 为什么这么定，见[决策记录](../docs/decisions/english-filenames-from-id.md)。

## 占位符
| 占位符 | 填什么 | 谁来填 |
|---|---|---|
| `{{ID}}` | 稳定标识，`kb:<学科slug>:<你的slug>`，**重命名文件也不变** | 脚本按 `--slug` 自动填 |
| `{{TITLE}}` | 人类可读标题 | 脚本 |
| `{{AUTHOR}}` | `@handle`，**不可匿名** | 脚本（取 `--author`，默认 `@hpleapfrog`） |
| `{{DATE}}` | `YYYY-MM-DD` | 脚本（当天） |
| `{{EVIDENCE}}` | 证据编号，如 `ev-073`；**必须先在 `evidence/README.md` 登记**（脚本默认填 `ev-000` 占位） | **你** |
| `{{SUBJECT}}` `{{STAGE}}` `{{LEVEL}}` | 学科（可带方向，如 `法律 · 权限划分`）· 学段枚举 · 水平档 | 脚本给默认值，**你核对** |
| `{{APPLY}}` `{{CONDITION}}` | **对谁成立 · 在什么条件下成立**（缺了它，任何结论都会被误用） | **你** |
| `{{KPATH}}` | 教法指回知识点的相对路径 | **你** |

## 生成之后，校验器还会拦你三件事

这不是模板的缺陷，是**故意的**——缺口必须可见：

| 校验器会报 | 为什么 |
|---|---|
| `evidence` 引用了索引里没有的编号（`R-EVID-01`） | 模板默认写 `ev-000`（占位符）。去 [`evidence/README.md`](../evidence/README.md) 登记真来源 |
| **学科 README 里没有登记它**（`R-README-01`） | 新条目必须出现在 `knowledge/<学科>/README.md` 的「现状」表里 |
| `暂定确认` 但证据没读过（`R-EVID-03`） | 没读过正文不能写「确认」。如实写 `待审` / `有效` |

跑一次就知道还差什么：

```bash
python tools/kbcheck.py
```

## 不要为了过校验而降级内容

**「保留小节并写明『暂无数据』」永远优于「删掉小节」或「放宽规则」。**
让缺口可见是诚实的；把规则放宽是掩盖缺口。
