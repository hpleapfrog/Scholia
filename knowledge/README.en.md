## Folder conventions

**Folder names are English** (paths get copied into URLs, where Chinese becomes percent-encoding);
**Chinese entries keep Chinese filenames**.

| Folder | `type` | Holds |
|---|---|---|
| `concepts/` | 知识点 (knowledge point) | **concept nodes**: they carry prerequisites; methods hang under them |
| `claims/` | 命题 (proposition) | claims with a truth value that must converge |
| `claims/attacks/` | 命题 | attack entries (`type` is still 命题) |
| `methods/` | 教法 (method) | teaching practices: conditional, **non-converging**, contraindications required |
| `misconceptions/` | 误解 | common wrong ideas — a teaching asset |
| `paths/` | 路径 (path) | an ordering of concepts, with prerequisites and outcomes |
| `resources/` | 资源 | figures, animations, worked examples, exercises |
| `coverage/` | — | coverage pages (an index, not a knowledge object) |

Subject folders: `physics` `life` `medicine` `geography` `science` `transport` `computing`
`economics` `law`.

`evidence/` sits at the repo root and is shared library-wide.

## Status legend

| Status | Meaning |
|---|---|
| 草案 / draft | just written, not self-checked |
| 待审 / pending review | has evidence, waiting for anyone to review it |
| 暂定确认 / provisionally confirmed | the author checked it, but **no independent non-author review** (claims only) |
| 已确证 / confirmed | surviving arguments agree (**claims only**) |
| 失据 / unsupported | once had arguments, **all knocked down**: the claim stands with nothing supporting it (claims only) |
| 争议 / disputed | surviving arguments conflict; shown side by side, no side taken |
| 有效 / effective | holds conditionally (methods / misconceptions / resources / paths) |
| 需复审 / needs re-review | evidence stale or conditions changed |
| 已推翻 / overturned · 已失效 / expired | overturned by stronger evidence, or its anchor can no longer be located |

> [!IMPORTANT]
> **Methods, misconceptions and resources may never use `已确证`** — there is no single correct one.

> [!IMPORTANT]

> but invented evidence: **backing a true conclusion with fabricated data is still fabrication.**

## Why so many entries sit at `待审`

> [!NOTE]
> Per [CONTRIBUTING](../CONTRIBUTING.en.md) rules 3–4: writing `已确证` requires **one independent
> reviewer who is not the author**, and the repo has **one contributor**.
>
> So **nothing here is in a terminal state**; most sit at `待审` / `有效` / `暂定确认`.
> **This is the rule working, not the entry work being unfinished.** Long suspension is allowed;
> `已确证` becomes possible when a second contributor appears.
