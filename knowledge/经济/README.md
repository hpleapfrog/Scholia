# 经济

> **English: [README.en.md](README.en.md)**

> [!IMPORTANT]
> **本学科收「这个指标怎么定义、口径是什么、官方发布了什么数」，不收预测，也不收建议。**
>
> 经济类内容最常见的错不在算错，在**拿错口径**：同比当环比、现价当不变价、
> 一个调查失业率当成另一个。**口径写不清的数字进不了本库**——
> 两个数字对不上时，第一件事是查它们是不是同一个口径，而不是查谁算错了。

### 还缺什么

| 缺口 | 为什么重要 | 需要的来源 |
|---|---|---|
| **其他指标的口径** | 目前只有失业率。GDP 核算（现价 / 不变价、生产法 / 支出法）、CPI（同比 / 环比、基期）、PMI（荣枯线 50 的含义）**一个都没有**，而这些正是「拿错口径」最高发的地方 | 国家统计局各指标的核算方法说明，带版本与发布日期 |
| **ILO / IMF / OECD 的原始标准** | 两页解读都转述 ILO 的分类标准，**而 ILO 原文一篇都没登记**。转述与原文是否一致，本库无法判断 | ILO 就业与失业统计标准、IMF《手册》相应章节 |
| **官方发布物本身** | 本库收的是「怎么定义、怎么用」，**没有收任何一期的实际发布物**（统计公报、月度发布稿）。「某期说了什么」目前是空的 | 国家统计局月度发布页、年度统计公报 |
| **登记失业率的原始口径文件** | `ev-056` 只是国家统计局对人社部口径的转述，**人社部自己的定义文件本库没读过** | 人力资源社会保障部相关规章与说明 |

## 边界

| | 收 | 不收 |
|---|---|---|
| 内容 | 指标定义与统计口径、官方发布物的原文表述 | 预测、走势判断、配置与政策建议 |
| 出处 | 统计机构、央行、国际组织的**正式发布**，带期次与发布日期 | 二手转述、机构观点摘要 |
| 表述 | 「X 指标的口径为 …（发布机构 · 期次 · 待核对）」 | 「今年将会 …」 |

**本库不判定「经济往哪个方向走」**——那既无法逐条对回原文，也正是最容易变成意见的地方。
收录的只能是**已经发布、能点开、有期次**的定义与数值。

### 数据会变，时效是主要攻击点

同一条经济条目，下一期发布就可能被推翻或取代。本库的处理方式与
[生活](../生活/README.md) 里的两条规则相同：**条目记录的是「某期发布说了什么」，
不是「经济现在是什么样」**；被更新的一期出现时，旧条目转 `已失效`，而不是就地改写。

> [!NOTE]
> 本库目前**没有版本探测机制**，`已失效` 从未被真正触发过——
> 这条限制记在 [生活](../生活/README.md)「仍然记着、没有动手改的事」里，本学科同样受它约束。

### 与医学指南的关系

**医学指南不另开学科。** 指南原文规定的操作参数归
[医学](../医学/README.md)，收录方式与免责要求见该页「边界的一次修正」。
本学科只管经济统计与经济文本。
