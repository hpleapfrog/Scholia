## 三者之间的关系

```mermaid
graph LR
  M["教法：水管类比"] -.->|内生风险| X["误解：把电压当成水流速度"]
  M -->|讲解| K["命题：欧姆定律"]
```

**这张图就是本项目的核心区分：**

- 「欧姆定律」是**命题** → 有真假，必须**收敛**成一个结论
- 「水管类比」是**教法** → 只对特定人群有效，必须**并存**，不许排名
- 「把电压当成水流速度」是**误解** → 它是教法的**副产品**，是资产，不是垃圾

第 2 条尤其重要：水管类比对初中生有效（ev-009），对物理系本科生**有害**（ev-010）。
两条论证**同时存活、互不冲突**——因为它们指向不同人群。
