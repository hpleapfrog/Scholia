# 交通

> **English: [README.en.md](README.en.md)**

> [!IMPORTANT]
> **本学科收「通行规则是什么」，不收「怎么走、怎么办」。**
>
> 判据沿用本库已经立过的两条：**稀缺性**（现场标志牌保证能拿到的，本库不重复）与
> **风险**（会出事的流程不装，见[决策记录：程序性知识的边界](../../docs/decisions/procedural-knowledge-boundary.md)）。
> 所以这里写的是**法律与标准里的义务、数值和禁止性规定**——
> **「谁必须做什么」「什么行为被禁止」**，每条都要能对回原文条款。

## 现状

**尚无条目。** 首批条目要等对应证据登记进 [evidence/README.md](../../evidence/README.md) 才会写入，
在此之前这个目录只有本文件。

`knowledge/README.md` 的学科统计表只列**已有条目**的学科，所以本学科暂时不会出现在那张表里；
按学科浏览请直接打开本页。

## 边界

| | 收 | 不收 |
|---|---|---|
| 内容 | 法律、行政法规、部门规章、国家标准中**可逐条对照**的义务、数值与禁止性规定 | 办事流程、操作步骤、出行路线 |
| 出处 | 官方发布、有文号或施行日期 | 无来源的转述、二手归纳 |
| 表述 | 「某文件规定了 X（文号 · 条款号 · 待核对）」 | 「你应该 X」 |

**条款号一律标注为待核对**：本库不凭记忆写条款号，未逐字对回原文的定位一律不填。

### 与相邻学科的分界

| 学科 | 它回答什么 |
|---|---|
| **交通** | 道路上与轨道上的**通行行为**规则：什么被禁止、义务归谁 |
| [生活](../生活/README.md) | 乘车与乘机过程中的**服务与票务**权利义务：行李、退改、超售 |
| [法律](../法律/README.md) | **制度怎么规定**：构成要件、期限、法律效果与权限划分（通行规则的**上位依据**在这里） |

同一份文件可能同时支撑两个学科的结论。**一条内容只进一个学科**；
真被具体条目撞出问题时，改的是本节，不是条目。

### 为什么现在是空的

不是「找不到题材」，是**还没有一条符合证据门槛的来源登记进来**。
在 [CONTRIBUTING](../../CONTRIBUTING.md) 的证据要求被满足之前，宁可空着——
**本库的门是 kbcheck 全绿，不是目录里有文件。**
