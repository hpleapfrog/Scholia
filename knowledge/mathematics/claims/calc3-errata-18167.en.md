## Statement

The public errata record [#18167](https://openstax.org/errata/18167) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.4 Green’s Theorem** and states the following (submitted 2021-11-16; status Completed;
resolution Approved):

> In the integral, "C+" is written instead of "C^+" (the plus should be in superscript relative to the C)

Publisher's resolution:

> Set the "+" as superscript.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
