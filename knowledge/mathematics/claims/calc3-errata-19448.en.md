## Statement

The public errata record [#19448](https://openstax.org/errata/19448) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.3 Conservative Vector Fields** and states the following (submitted 2022-04-08; status Completed;
resolution Approved):

> In exercise 6.3.140, inconsistent notation is used. Boldface c(t) is used rather than using C in defining the curve of integration, where boldface c(t) is not used elsewhere in the text (that I can find).

Publisher's resolution:

> Revise "c(t) =" to "C is the curve".

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
