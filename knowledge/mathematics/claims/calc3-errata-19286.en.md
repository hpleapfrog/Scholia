## Statement

The public errata record [#19286](https://openstax.org/errata/19286) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Applications of Integration: Section 6.6 Moments and Centers of Mass** and states the following (submitted 2022-03-21; status Completed;
resolution Approved):

> Currently the text reads "and N is an upward pointing normal vector S, where S is the triangular region". The first copy of "S" should be removed; the second copy of "S" should be in italics / math mode.

Publisher's resolution:

> Delete the first instance of "S" and set the second "S" in italics.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
