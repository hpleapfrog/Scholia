## Statement

The public errata record [#7107](https://openstax.org/errata/7107) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 section 3 problem 121** and states the following (submitted 2018-10-10; status Completed;
resolution Approved):

> This vector field is not conservative since the curl is not equal to 0. If the vector field was changed to < -1/y, x/y^2, 2z-1> then it would be conservative and you can find the potential function to be z*(z-1)- x/y.

Publisher's resolution:

> Revise the stem to F(x, y, z) = (–(1/y))i + (x/y^2)j + (2z – 1)k. Revise the potential function in the answer to f(x, y, z) = z^2 – z – x/y.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
