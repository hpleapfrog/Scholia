## Statement

The public errata record [#25088](https://openstax.org/errata/25088) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.1 Vector Fields** and states the following (submitted 2024-05-21; status Completed;
resolution Approved):

> Issue: The given answer has incorrect notation, and is unclear.
> Priority: Type 1
> Fix: Update the answer to be:
> ||E||=c/(x^2+y^2 ) √(x^2+y^2 )=c/√(x^2+y^2 )=c/r

Publisher's resolution:

> This assessment will be updated.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
