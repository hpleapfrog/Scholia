## Statement

The public errata record [#10417](https://openstax.org/errata/10417) for OpenStax *Calculus Volume 3* concerns
**Chapter 6, Sec. 6.6, Example 6.66, page 770-771 of pdf file https://legacy.cnx.org/content/m54004/latest/?collection=col11966/latest** and states the following (submitted 2019-11-24; status Completed;
resolution Approved):

> Hi, I already submitted a report on this, but I was not logged in, so I am not sure if my report was lost or not. In Example 6.66 the cylinder is initially defined as x^2+y^2=4, which implies radius of length r = 2. However, the exercise applies calculations to the cylinder of unit radius, namely, takes x^2+y^2=1 which is different than the initial statement. So, maybe change the initial statement to match the calculations. Otherwise, if original statement is kept, then the result should be 24*pi. Thanks.

Publisher's resolution:

> The last two lines of the solution will be updated. The radius has been updated to 2 in webview previously.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
