## Statement

The public errata record [#16615](https://openstax.org/errata/16615) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.2 Line Integrals** and states the following (submitted 2021-05-21; status Completed;
resolution Approved):

> It seems you already adjusted this problem recently due to an earlier mistake, but the current version seems to be still incorrect. As currently written the z-coordinate of r'(t) is t, so you should get (-sin t)^2 + (cos t)^2 + t^2 in the square root als ||r'(t)||. The easiest fix would be to take r(t) = < cos t, sin t, 2/3 t^(3/2)>, which would make the rest of the calculation correct.

Publisher's resolution:

> This problem will be updated.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
