## Statement

The public errata record [#24958](https://openstax.org/errata/24958) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.3 Conservative Vector Fields** and states the following (submitted 2024-05-07; status Completed;
resolution Approved):

> Issues: The "=(x,y,z)" is incorrect notation, the integral notation should use dr, C should be italicized, and the curve should be notated as a vector, not a point.
> Priority: Type 3
> Fix: Remove "=(x,y,z)", use dr, italicize C, and update the curve definition to use r(t) and angle brackets.
> "Let F =(e^x □sin y)i +(e^x □cos y)j +z^2k. Evaluate the integral ∫_C F ⋅dr, where C is the curve r(t)=〈 √t,〖t^3,e〗^√t 〉, 0≤t≤1."

Publisher's resolution:

> This assessment will be updated.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
