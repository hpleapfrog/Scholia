## Statement

The public errata record [#8611](https://openstax.org/errata/8611) for OpenStax *Calculus Volume 3* concerns
**Chapter 6.4, Example 6.43** and states the following (submitted 2019-05-09; status Completed;
resolution Approved):

> In the solution to example 6.43, flux is written as \int v.dr, but should be written as \int v.N ds

Publisher's resolution:

> Revise "dr" to "Nds" in the solution.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
