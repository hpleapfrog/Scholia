## Statement

The public errata record [#18232](https://openstax.org/errata/18232) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.6 Surface Integrals** and states the following (submitted 2021-11-28; status Completed;
resolution Approved):

> The body of the text uses rho for density. These six questions use either xi (287, 288, 289, 301) or delta (319, 320); only question 301 explains that the alternate symbol is supposed to represent density. Probably (for consistency) all six questions should be changed to use rho for density.
>
> Relatedly, the instructions to 287, 288, and 289 refer to a "homogeneous lamina" -- this phrase is not defined in the chapter, but I would have expected it meant "lamina of constant density", so it's then very strange that the questions ask about a lamina of variable density.

Publisher's resolution:

> Update all to use "ρ" (rho) for density.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
