## Statement

The public errata record [#18394](https://openstax.org/errata/18394) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.7 Stokes’ Theorem** and states the following (submitted 2021-12-12; status Completed;
resolution Approved):

> In Example 6.74, when substituting the parametrization in to the line integral, there are two sign errors: it should be
> < 1 - cos(t), 0, sin(t) > dot < sin(t), 0, cos(t) >
> and then the following lines will need to be corrected accordingly.
>
> (This is error seems to be the result of not correcting the entire example following this erratum from 2019: https://openstax.org/errata/10454 )

Publisher's resolution:

> The solution will be updated.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
