## Statement

The public errata record [#10416](https://openstax.org/errata/10416) for OpenStax *Calculus Volume 3* concerns
**Chapter 6, Example 6.67 pages 772-773 of pdf file or https://legacy.cnx.org/content/m54004/latest/?collection=col11966/latest** and states the following (submitted 2019-11-24; status Completed;
resolution Approved):

> Hello,
>
> Example 6.67 in Calculus 3 has errors in computing both integrals (over each S1 and S2). In the first case the integral of u is incorrectly calculated and in the second case the upper limit for the phi angle is incorrect. 
>
> I attached a file that shows the errors.
> Thank you.

Publisher's resolution:

> This example will be updated.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
