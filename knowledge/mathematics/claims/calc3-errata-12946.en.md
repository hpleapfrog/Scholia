## Statement

The public errata record [#12946](https://openstax.org/errata/12946) for OpenStax *Calculus Volume 3* concerns
**Chapter 6 Vector Calculus: Section 6.3 Conservative Vector Fields** and states the following (submitted 2020-08-29; status Completed;
resolution Approved):

> The comment shows an example of a vector field supposedly from Example 6.30. That linked example has totally different vector field than the one discussed in the text. Probably the easiest way to correct this is to remove the reference to Example 6.30. Verifying that the discussed vector field satisfies cross-partial property may be left as an exercise: something that most likely had been done in the previous version of Example 6.30.

Publisher's resolution:

> Delete "from Example 6.30".

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
