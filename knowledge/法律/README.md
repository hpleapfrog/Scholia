# 法律

> **English: [README.en.md](README.en.md)**

> [!IMPORTANT]
> **本学科收「成文法怎么规定」，不收「这个案子怎么判」，也不收「你该怎么办」。**
>
> 收进来的是**制度本身**：某法确立了什么制度、构成要件是什么、期限多久、
> 法律效果归谁、权限划给哪个机关——**每一条都要能对回具体法条**。
> **个案裁判与法律意见都不收**：前者不是法律文本，后者是建议。

## 现状

**尚无条目。** 首批条目要等对应证据登记进 [evidence/README.md](../../evidence/README.md) 才会写入。

`knowledge/README.md` 的学科统计表只列**已有条目**的学科，所以本学科暂时不会出现在那张表里；
按学科浏览请直接打开本页。

## 边界

| | 收 | 不收 |
|---|---|---|
| 内容 | 法律、行政法规、司法解释中**可逐条对照**的构成要件、期限、法律效果与权限划分 | 个案裁判结果、法律意见与咨询结论、维权攻略 |
| 出处 | 官方公布的法律文本，带**版本与施行日期** | 转载页、律所解读文章、自媒体归纳 |
| 表述 | 「《X 法》第 N 条规定了 X（版本 · 施行日期 · 条款号待核对）」 | 「你应当 X」「法院通常会判 X」 |

**条款号一律标注为待核对**——本库不凭记忆写条款号，与[交通](../交通/README.md)同一条规矩。

### 与相邻学科的分界

| 学科 | 它回答什么 |
|---|---|
| **法律** | **制度怎么规定**：要件、期限、效果、权限 |
| [交通](../交通/README.md) | 道路上与轨道上的**通行行为**规则（领域内的具体义务） |
| [经济](../经济/README.md) | **统计口径**与官方发布数值 |

**同一部法律可能同时支撑多个学科。** 一条内容只进一个学科；
被具体条目撞出问题时，改的是本节，不是条目。

### 时效：法条会改

法条修订之后，旧条目的结论就不再成立。处理方式与
[经济](../经济/README.md) 相同：**条目记录的是「某版本规定了什么」**，
新版本出现时旧条目转 `已失效`，**而不是就地改写**——
这样读者始终知道自己看的是哪一版。

> [!NOTE]
> 本库**没有版本探测机制**，`已失效` 从未被真正触发过。这条限制记在
> [生活](../生活/README.md)，本学科同样受它约束。

### 为什么现在是空的

不是「找不到题材」，是**还没有一条符合证据门槛的来源登记进来**。
在[证据门槛](../../evidence/README.md)的三问被答上之前，宁可空着——
**本库的门是 kbcheck 全绿，不是目录里有文件。**
