## 做法

教材给的是一条**三问链**，从演示直接推到加速度方向：

> `[BL] [OL] [AL] Demonstrate circular motion by tying a weight to a string and twirling it around. Ask students what would happen if you suddenly cut the string? In which direction would the object travel? Why? What does this say about the direction of acceleration?`

拆成四步：

| # | 老师说 / 学生做 | 这一步在做什么 |
|---|---|---|
| 1 | 系重物、转起来 | 先给**现象**，不给公式 |
| 2 | 「如果我现在剪断绳子，它会往哪走？」 | 让学生说**切向**——多数人会说「往外甩」 |
| 3 | 「为什么？」 | 逼出「因为没有力拉着它了」→ **惯性** |
| 4 | 「那这说明加速度指向哪？」 | 由「剪断后走直线」反推「没剪断时一定有个指向圆心的力」 |

第 2 步的答案**允许错**：学生说「沿着半径往外飞」正是这个演示要暴露的东西。
第 3 步是转折点——把「往外」改成「沿切线」，靠的不是纠正，而是问「力没了之后它按什么规则走」。

### 配套：同一演示可以接着问关系式

> `[BL] [OL] [AL] Using the same demonstration as before, ask students to predict the relationships between the quantities of angular velocity, centripetal acceleration, mass, centripetal force. Invite students to experiment by using various lengths of string and different weights.`

**换绳长、换重物**，让学生自己先说「谁变大谁变小」，再对照 `a_c = v²/r`、`F_c = m v²/r`。

## 禁忌

| 不适用对象 / 情形 | 依据 | 强度 |
|---|---|---|
| **还没学过惯性/牛一**的学生 | 第 3 步整个建立在「没有力就走直线」上；缺这条，演示只剩「东西飞出去了」 | **强**——由做法的推理链推出 |
| 只想尽快进入计算题的课堂 | 这条做法把时间花在**归因**上，不产出解题步骤 | **中** |
| 只能口头描述、无法演示的场景 | 三问链的起点是**可观测的剪断瞬间**；纯口头时学生没有共同的观察对象 | **中** |

## 风险

| 会翻车的地方 | 为什么 |
|---|---|
| 学生把「飞出去」当成离心力的证据 | 这是**最可能发生**的误读，而且演示本身会强化它。必须走完第 3 步才收尾，否则等于亲手演示了一遍「离心力」 |
| 老师顺口说「因为离心力把它甩出去」 | 一句话就把整个演示变成反教材：教材要求教师 `Address any misconceptions about centrifugal force` |
| 第 2 步直接给答案 | 学生没有做预测，第 3 步的「为什么」就变成了复述老师的话 |
| 只做第一步（转圈）就讲向心力公式 | 演示成了装饰，学生记住的是「绳子拉着」，不是「合力垂直分量」 |

## 论证

### M1 · 教材为三个档位共同指定（尚无攻击）

- **主张**：这是教材给 BL / OL / AL 三个档位**同时**建议的做法
- **前提**：该段 Teacher Support 的标记是 `[BL] [OL] [AL]`（ev-081）
- **推理**：三档并列意味着教材没有把它绑定到某一认知水平——故本条的 `水平档` 写「不分档」
- **证据**：ev-081
- **被攻击**：**「三档都标」不等于「三档都有效」**。它只说明教材认为这条演示对三个水平都合适，
  本库没有任何课堂数据。**这正是 `教法` 不能「已确证」的原因。**
