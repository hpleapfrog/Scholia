## Statement

The public errata record [#21379](https://openstax.org/errata/21379) for OpenStax *University Physics Volume 1* concerns
**Answer Key: Chapter 2** and states the following (submitted 2022-12-27; status Completed;
resolution Approved):

> The components of the resultant vector (R) should have metres (m) as units.
>
> The question defines vector D to have metres as units. According to the equation, vector R should have the same units.
>
> From the answer key,
>
> > "R = -3i - 16j"
>
> correction: R = (-3i - 16j)m
> or, R = -(3i + 16j)m

Publisher's resolution:

> The answer will be updated.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
