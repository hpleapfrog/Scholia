## Statement

The public errata record [#5093](https://openstax.org/errata/5093) for OpenStax *University Physics Volume 1* concerns
**Chapter 2 Problem 28 (g)** and states the following (submitted 2018-01-30; status Completed;
resolution Approved):

> Chapter 2 Problem 28 (g)does not show the vector addition task (based on solution manual that the vector summation task is C-2D+3F).

Publisher's resolution:

> This error has been corrected in web view and will be reflected in the next edition of the pdf.

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
