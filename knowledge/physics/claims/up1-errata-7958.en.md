## Statement

The public errata record [#7958](https://openstax.org/errata/7958) for OpenStax *University Physics Volume 1* concerns
**Chapter 2, Problem 47 (b), page 930, version 12.5** and states the following (submitted 2019-02-12; status Completed;
resolution Approved):

> The difference vector should be -2i + 2j

Publisher's resolution:

> Revise to "−2i + 2j".

> [!NOTE]
> This entry claims only that "the publisher recorded and accepted this erratum".
> **It does not claim that this repository checked the current web text**; cite the
> permanent link when verifying.
