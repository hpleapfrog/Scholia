> [!TIP]
> **读完这一条，你应该**能解释放射性药物为什么能当示踪剂、PET 怎样用两个反向光子定位，分清活度 `Bq`、吸收剂量 `Gy` 与等效剂量 `Sv`，并用治疗比说明放疗为什么分次、从多方向照射

## 定义

**医学中的电离辐射**指用 X 射线或放射性核素放出的射线做诊断与治疗。两条主线：

- **诊断**：把少量放射性核素标记到药物上（**放射性药物**，radiopharmaceutical），从体外探测它浓集在哪里；或者用 X 射线穿过身体成像
- **治疗**：把足够大的剂量送到肿瘤，同时尽量少伤正常组织

**示踪为什么可行**：教材给出两条理由——γ 射线容易穿透组织；**衰变只取决于核素，与它所在的化合物无关**。把放射性核素接到一个会被特定器官摄取的化合物上，就叫**标记**（tagging）。探测体外 γ 射线的位置与强度，就能反推药物在体内的分布。

| 检查 | 核素 | 典型活度 | 说明 |
|---|---|---|---|
| 甲状腺扫描 | `131I` | `0.05 mCi` | 甲状腺浓集碘，癌细胞摄取更多；摄取少提示功能低下 |
| 骨扫描 | `99mTc` | `10 mCi` | 锝-99m 可接到多种化合物上 |
| 脑 / 全身 PET | `18F`、`11C`、`13N`、`15O` | `10–50 mCi` | β⁺ 发射体，见下 |

- `99mTc` 是主力：教材估计约 **80%** 的放射性药物操作用它。亚稳态放出单一 `0.142 MeV` γ，半衰期 `6.0 h`，由中子活化钼生成 `99Mo`、再经 β− 衰变得到
- 活度与 Bq 的换算：`1 mCi = 3.7×10^7 Bq`
- 其他例子：铊-201 随血流用于心肌；镓-67 浓集在快速生长或感染的部位

**三种成像设备**：

- **γ 相机（Anger 相机）**：铅准直器只让某一方向的 γ 进入探测器阵列，计算机重建图像；**只有二维，没有深度信息**
- **SPECT**：探测器绕病人旋转，得到三维分布；空间分辨率约 `1 cm`，但对比度好
- **PET**：用 β⁺ 发射体。正电子在组织中很快与电子相遇，两者**湮没**，放出两个 `0.511 MeV` 的 γ 光子，方向几乎相反。两侧探测器**同时**收到一对光子，就确定一条穿过湮没点的直线；多条直线相交，定位湮没点。分辨率约 `0.5 cm`
- **MRI** 不是核辐射成像：它用强磁场与射频脉冲操纵氢核自旋，没有电离辐射。教材只在侧栏提了一句，本条不展开

> [!IMPORTANT]
> **活度不是剂量。**
>
> 活度 `R = λN` 描述**源**每秒衰变多少次（单位 Bq）；剂量描述**人体组织**吸收了多少能量、造成多大生物效应。一个活度很高的源，只要离得远、照射时间短，剂量可以很小。反过来，α 发射体在体外容易被皮肤挡住，吸入体内后却因为射程短、电离密集而更危险。被照射也不等于被沾染：外照射在离开源后就停止，沾染则意味着放射性物质进入了身体或附在表面。

**剂量怎样记账**：

- **吸收剂量** `D = E/m`：每千克组织吸收的电离能量。`1 Gy = 1 J/kg = 100 rad`
- **等效剂量** `H = D × RBE`：同样 1 Gy，不同射线的生物效应不同。`1 Sv = 1 Gy × RBE = 100 rem`
- **RBE（相对生物效应，也叫品质因数）**是近似值：

| 射线 | RBE |
|---|---|
| X 射线、γ、`>32 keV` 的 β | 1 |
| `<32 keV` 的 β | 1.7 |
| 热中子到慢中子 | 2–5 |
| 快中子、质子 | 10（体）/ 32（眼） |
| α、加速器重离子 | 10–20 |

- 例：2 rad 的 γ 是 2 rem；同样 2 rad 的 α 是 `2 × 20 = 40 rem`——吸收能量相同，生物效应差 20 倍
- 50 kg 的人全身吸收 1 J：`1 J / 50 kg = 0.02 Gy = 2 rad`

**本底与诊断剂量**（教材表，世界平均）：

| 来源 | 剂量 |
|---|---|
| 宇宙射线 | `0.39 mSv/y` |
| 土壤与建材 | `0.48 mSv/y` |
| 氡气 | `1.2 mSv/y` |
| 体内核素（`40K`、`14C`、`226Ra`） | `0.29 mSv/y` |
| 医疗与牙科 | `0.40 mSv/y` |
| **合计** | **`2.8 mSv/y`** |

| 检查 | 有效剂量 |
|---|---|
| 胸片 | `0.02 mSv` |
| 牙片 | `0.01 mSv` |
| 乳腺摄影 | `0.40 mSv` |
| 头部 CT | `2.0 mSv` |
| 腹部 CT | `10.0 mSv` |

- 教材指出：CT 只占 X 射线检查不到 20%，却贡献约 50% 的年医疗剂量
- 复算：一次腹部 CT 的 `10 mSv` 约等于 `10 / 2.8 ≈ 3.6` 年的世界平均本底；一张胸片 `0.02 mSv` 约等于 `0.02 / 2.8 × 365 ≈ 2.6` 天

**放疗**：

- 癌细胞分裂快，对辐射更敏感；但正常组织也会受损。**治疗比** = 杀死的异常细胞数 / 杀死的正常细胞数
- **几何汇聚**：多束窄射线从不同方向穿过病人，在肿瘤处交叉。每束对正常组织的剂量不大，交点处叠加得很高
- **分次**：教材的典型方案是每周 3–5 次、每次 `200 rem`、持续数周；两次之间正常组织有时间修复
- 其他方式：把放射性籽源植入前列腺；用放射性碘治疗甲状腺癌（甲状腺浓集碘）；把抗体标记后回输，让放射性集中在肿瘤
- 教材的剂量表（部分）：肺 `10–20 Sv`、乳腺 `50–80+ Sv`、脑/颈/骨/软组织/甲状腺 `80+ Sv`。这些是**局部、分次**的肿瘤剂量，不是全身剂量

**防护**：屏蔽、增加距离、缩短时间。教材给出的职业全身限值是 `20–50 mSv/y`，公众为职业限值的 1/10；核动力对公众的限值是 `0.05 mSv/y`。

> [!NOTE]
> **教材里的几处问题与本库的补写**（ev-187/ev-188/ev-189）
>
> 1. m42654 把前列腺籽源的核素写成 `135I`（6 个月）与 `103Pd`（3 个月）。这组同位素/半衰期配对无法由本条已核材料内部核实，本条只保留「籽源植入」机制，**不采用这组数字**，记为待核。
> 2. m42652 说「每张牙片约 `5 mSv`（0.5 rem）」，同一模块的表却写牙片 `0.01 mSv`，相差约 500 倍。本条采用表值，不采用正文的 5 mSv。
> 3. m42652 把低剂量定义为「小于 `100 mSv`」、中剂量定义为「`0.1 Sv` 到 `1 Sv`」；`0.1 Sv = 100 mSv`，两个区间在边界重叠。本条按「低、中、高」的定性划分使用，不把边界当精确阈值。
> 4. m42654 的剂量表把 `80+ Sv` 直接列给脑、颈、骨等部位，没有说明这是分次、局部、特定技术下的数值；「200 rem」与 Gy 混用，只有 RBE = 1 时数值才相等。
> 5. m42649 说湮没能量来自「一个电子或正电子质量」；实际是电子与正电子**两个**静质量（合计 `1.022 MeV`）湮没成两个 `0.511 MeV` 光子。数值正确，表述不精确。
> 6. 教材只在侧栏用「氢核是微型无线电发射机」的类比介绍 MRI；强磁场、射频脉冲、弛豫与梯度编码都是本库补写的背景，不来自这三个模块。
>
> **本库补写、教材未给的**：`10 mSv` 与 `0.02 mSv` 相当于多少年/天本底、`0.75 Sv` 对 `15 mSv` 的 50 倍差距、`50–80 Sv` 按每次 `2 Sv` 折合 25–40 次、以及「活度不是剂量、被照射不是被沾染」的区分。教材给了单位定义、RBE 表、本底表、诊断表与放疗方案，但没有把这些量放进同一个参照系。

## 论证

### K1 · 示踪可行的前提是「衰变只认核素，不认化合物」（尚无攻击）

- **主张**：把 γ 发射体标记到药物上，体外探测 γ 就能读出药物在体内的分布；在近似意义上，标记不改变载体的化学行为
- **前提**：教材给出两条理由（γ 易穿透组织；衰变只取决于核素、与化合物无关），定义 tagging 与 radiopharmaceutical，并列举甲状腺碘、铊心肌、镓肿瘤（ev-187）
- **推理**：核素的半衰期与射线能量由核决定，化合物只决定它被哪个器官摄取、排出多快。把 `99mTc` 接到不同载体上，同一台 γ 相机就能看骨、心、肾。探测器计数率正比于局部活度，经准直与重建得到分布。甲状腺的例子最直接：碘被甲状腺浓集，癌细胞摄取更多，所以图像上的「热区」对应活跃组织
- **被攻击**：教材只给定性原理，没有给探测器效率、衰减校正、部分容积效应，也没有给药物动力学模型；「标记不改变化学行为」只是近似——教材自己的习题要求把放射性碘与稳定碘混合（载体），说明化学量会影响分布；γ 相机没有深度信息，SPECT 的分辨率约 1 cm。本条只解释「为什么能看见」，不解释「怎样定量」
- **证据**：ev-187
- **署名**：@hpleapfrog · 2026-10-21

### K2 · PET 靠湮没光子的方向与同时性定位（`1.022 MeV` 的合记账是本库补写）

- **主张**：PET 用 β⁺ 湮没产生的两个反向 `0.511 MeV` 光子，通过符合探测确定湮没点所在的直线，再由多条直线定位
- **前提**：教材说 β⁺ 与电子湮没放出两个能量相同、方向相反的 `0.511 MeV` γ，两侧探测器同时探测；给出 `11C`/`13N`/`15O`/`18F` 与 `0.5 cm` 分辨率（ev-187）；结合能模块给出 `E = mc²` 与电子静质量对应的 `0.511 MeV`（ev-186）
- **推理**：正负电子各有一个静质量，合计 `2 × 0.511 = 1.022 MeV`；湮没把这份质量—能量变成两个光子。动量守恒要求两个光子反向，能量守恒要求每个 `0.511 MeV`。同时收到两个光子，湮没点就在两探测器连线上；不同角度的一对对探测器给出多条直线，交点就是源的位置。符合探测把「同时」作为筛选条件，所以不需要机械准直器
- **被攻击**：教材没有给符合时间窗、随机符合、散射与衰减校正，也没有给 `18F` 的半衰期与生产；「同时」在实验上是纳秒量级的时间窗，不是数学上的同时；本条的 `1.022 MeV` 是由两个电子静质量相加得到，教材只给单个 `0.511 MeV`；β⁺ 衰变的完整方程与阈值仍记在[放射性衰变](放射性衰变.md)的缺口表
- **证据**：ev-187、ev-186
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 剂量分两层：吸收了多少能量，与造成多大生物效应（尚无攻击）

- **主张**：吸收剂量 `D = E/m`（Gy）描述能量沉积；等效剂量 `H = D × RBE`（Sv）描述生物效应。两者不能混用，活度更不是剂量
- **前提**：教材定义 `1 rad = 0.01 J/kg`、`1 Gy = 100 rad`、`rem = rad × RBE`、`1 Sv = 100 rem`，给出 RBE 表、2 rad γ 与 2 rad α 的例子，并用误解框区分 activity 与 dose（ev-188）
- **推理**：同样的 1 J，落在 50 kg 全身是 0.02 Gy，落在 2 kg 前臂是 0.5 Gy——剂量必须先说明受照组织。同样的吸收剂量，α 的径迹短、电离密集，损伤更难修复，所以 RBE 取 10–20；γ 取 1。`H = D × RBE` 把两者合成一个可比较的量。`1 Sv = 100 rem`，所以 2 rad α = 40 rem = 0.4 Sv
- **被攻击**：RBE 是近似值，依赖射线能量、剂量率与生物终点；Sv 不是可直接测量的物理量，而是用 RBE 加权后的量；线性假设（低剂量风险正比于高剂量）有争议，教材自己也说 hormesis 的证据不足；教材的低/中剂量边界在 100 mSv 处重叠；牙片 `5 mSv` 与表值 `0.01 mSv` 矛盾
- **证据**：ev-188
- **署名**：@hpleapfrog · 2026-10-21

### K4 · 放疗靠治疗比：把剂量集中到肿瘤，让正常组织分次修复（尚无攻击）

- **主张**：放疗的可行性来自治疗比——把高剂量集中到肿瘤，同时让正常组织在分次之间修复
- **前提**：教材说癌细胞分裂快、更敏感；治疗比 = 杀死异常/正常细胞；几何汇聚；每周 3–5 次、每次 200 rem；籽源、放射性碘、标记抗体（ev-189）
- **推理**：单束射线穿过正常组织也会给剂量；多束从不同方向交叉，每束路径上的正常组织只承受一小部分，交点处叠加。分次把总剂量拆开，正常组织在间隔中修复，而肿瘤细胞对辐射更敏感，损伤更容易累积。甲状腺癌用放射性碘是「化学靶向」：甲状腺（包括癌细胞）主动浓集碘，辐射就地释放
- **被攻击**：教材没有给 TCP/NTCP 模型、分次放射生物学（再氧合、再分布、再增殖、修复）、质子/重离子的剂量学；`135I`/`103Pd` 的数字不采用；「收益远大于长期风险」没有引用；`80+ Sv` 的一列缺少分次与局部说明；200 rem 与 Gy 混用
- **证据**：ev-189
- **署名**：@hpleapfrog · 2026-10-21
