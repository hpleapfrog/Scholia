> [!TIP]
> **读完这一条，你应该**能用 `I_rms = I0/√2`、`V_rms = V0/√2` 在峰值与有效值之间换算，说明 `P_ave = I_rms V_rms = I_rms²R = V_rms²/R` 为什么与直流公式同形，并解释「平均值」为什么不能代替有效值

## 定义

**有效值**（root mean square，RMS）是把周期变化的电流或电压折算成「产生同样热效应」的直流值。教材的定义是：把该量平方、求一个周期的平均、再开方；对正弦式交变电流：

`I_rms = I0/√2 ≈ 0.707 I0`，`V_rms = V0/√2 ≈ 0.707 V0`

其中 `I0`、`V0` 是峰值。教材先写瞬时值 `V = V0 sin 2πft`、`I = I0 sin 2πft`，纯电阻中二者同相；瞬时功率是 `P = I0V0 sin² 2πft`，平均功率是

`P_ave = ½ I0 V0`

把 `I0 = √2 I_rms`、`V0 = √2 V_rms` 代回，就得到与直流同形的三式：

- `P_ave = I_rms V_rms`
- `P_ave = I_rms² R`
- `P_ave = V_rms²/R`
- 纯电阻的「交流欧姆定律」：`I_rms = V_rms/R`

日常标称值都是有效值：教材写 `most household electricity is 120 V AC, which means that V_rms is 120 V`，10 A 断路器限制的是 `I_rms`，1.0 kW 微波炉标的是 `P_ave`。由 `V0 = √2 V_rms`，120 V 市电的峰值是

`V0 = 1.414 × 120 V = 170 V`

峰值功率与平均功率的关系（纯电阻）：

`P0 = I0 V0 = 2 P_ave`

所以 60.0 W 的灯泡，瞬时功率在 0 与 120 W 之间以 `2f` 起伏，平均仍是 60.0 W。

数量级：25 W、120 V 的灯泡，热电阻 `R = V_rms²/P_ave = 576 Ω`，`I_rms = 0.208 A`，`I0 = 0.294 A`，`P0 = 50 W`；60 Hz 的周期 `T = 1/f = 16.7 ms`，电压每周期两次过零，灯泡以 120 Hz 通断（「交变电流」条目已讲）。

> [!IMPORTANT]
> **「平均值」与「有效值」不是一回事。**
>
> 教材把两者写成 `average or rms current`，但同一段又说正弦量的平均值是零——若真是「平均」，电流表该读零。有效值走的是「平方 → 平均 → 开方」，不是直接平均。全波整流后的正弦量，其平均值为 `2V0/π ≈ 0.637 V0`，仍不等于 `0.707 V0`；两者一个是直流分量，一个是热效应等效值。本库按后一种理解使用 `rms`。

> [!IMPORTANT]
> **`√2` 是正弦波的结果，不是有效值的定义。**
>
> 教材只给 `I_rms = I0/√2`，没有推导。本库在 K1 补出：一个周期内 `sin²ωt` 的平均值是 `½`，所以均方根是 `1/√2`。换成方波，有效值等于峰值；换成三角波，有效值是 `V0/√3`。把 `√2` 当成「有效值的定义」会在非正弦波形上直接算错。

> [!NOTE]
> **教材的四处问题（本条的处理方式）。**
>
> 1. **`average` 与 `rms` 混用**：见上一条 IMPORTANT，本条只把 rms 当有效值。
> 2. **`√2` 无推导**：K1 补出均方根推导，并标明是本库补写。
> 3. **「交流电击比直流更危险」未给引用**：教材在历史段这样写，没有给实验或标准依据；本条不采用为定量结论。
> 4. **120 V 被当作精确值**：教材用它做 `√2` 换算，实际市电有电压容差；本条的数字只作教材例题复算，不声明为电网保证值。

## 论证

### K1 · 有效值等于「产生同样热效应的直流值」（尚无攻击）

- **主张**：对正弦式电流，`I_rms = I0/√2`；在电阻上，它与同样大小的直流产生相同的平均功率
- **前提**：教材写 rms 是「平方、取平均、开方」，并给 `P_ave = ½I0V0`、`I_rms = I0/√2`、`V_rms = V0/√2`（ev-194）；推导是本库补写的
- **推理**：一个周期内电阻耗能 `W = ∫I0²R sin²ωt dt = I0²R·T/2`。若直流 `I_rms` 在同一电阻、同一时间耗能相同，则 `I_rms²R·T = I0²R·T/2`，故 `I_rms = I0/√2`。等价地，`sin²ωt` 在一个周期上的平均是 `½`，均方根就是 `1/√2`。电压同理
- **证据**：ev-194
- **被攻击**：教材没有推导，也没有说明 `√2` 只对正弦波成立；本条把「只对正弦波」写进 TIP 与 K1。非正弦波必须回到「平方—平均—开方」的定义，不能套 `√2`
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 平均功率用有效值写，与直流公式同形（尚无攻击）

- **主张**：纯电阻交流电路中 `P_ave = I_rms V_rms = I_rms²R = V_rms²/R`；峰值功率是平均功率的两倍
- **前提**：教材由 `P = I0V0 sin²2πft` 得 `P_ave = ½I0V0`，再代入 rms 定义得三式；并给 60 W 灯泡的峰值功率 `P0 = 2P_ave = 120 W`（ev-194）
- **推理**：`I0V0 = (√2I_rms)(√2V_rms) = 2I_rmsV_rms`，所以 `½I0V0 = I_rmsV_rms`。峰值功率 `P0 = I0V0` 因此是平均值的两倍。功率以 `2f` 起伏，但电表与用电器标称的是平均值
- **证据**：ev-194
- **被攻击**：`P0 = 2P_ave` **只对纯电阻**成立。含电感或电容时电压与电流有相位差，`P_ave = I_rmsV_rms cosφ`，峰值功率也不再简单等于两倍平均值；教材没有强调这个前提，本条把它限定在纯电阻，相位差见「感抗与容抗」
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 用有效值算输电，才能看出高压为什么省线损（尚无攻击）

- **主张**：输送同样的平均功率，电压提高 `k` 倍，线路电流降为 `1/k`，线损降为 `1/k²`
- **前提**：教材用 `P_ave = I_rmsV_rms` 算 100 MW、200 kV → 500 A，1.00 Ω 线损 250 kW（0.250%）；改用 25 kV → 4000 A、16.0 MW（16.0%）（ev-194）
- **推理**：`I_rms = P_ave/V_rms`，`P_loss = I_rms²R = P_ave²R/V_rms²`。电压从 25 kV 提到 200 kV 是 8 倍，线损降为 `1/64`：`16.0%/64 = 0.250%`，与教材两例一致
- **证据**：ev-194
- **被攻击**：教材把「AC 胜出」归因于变压器与高压低损耗，这是历史与工程叙述，不是本条复算的结论；同样的 `P = IV`、`P_loss = I²R` 对高压直流也成立，教材没有讨论现代高压直流输电。本条只保留计算，不把「必须用 AC」当作物理必然
- **署名**：@hpleapfrog · 2026-10-21
