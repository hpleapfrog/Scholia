> [!TIP]
> **读完这一条，你应该**能用 `C = Q/V` 与 `C = κε₀A/d` 算电容、用 `U = ½CV²` 算储能，并说清插入电介质在「仍接电池」与「已断开电池」两种情况下为什么能量结论相反

## 定义

**电容器**是由两块导体（极板）和它们之间的绝缘层组成的器件。把两块金属板面对面放置、分别接到电池的正负极，两板就带上等量异号电荷，板间形成**匀强电场**。这个装置就是**平行板电容器**。

**充电要克服排斥做功**：把第一对正负电荷放上极板几乎不需要做功；第二对要克服第一对的斥力，第三对要克服前两对的斥力……所需功越来越多。这些功来自电池的化学能，最终**储存在板间的电场里**。断开电池后，电荷与能量仍留在电容器上；把两板接到灯泡，灯泡就会亮，直到能量用完。

**电容**定义为极板电荷大小 `Q` 与板间电势差 `V` 之比：

`C = Q/V`

`Q` 是**每块**极板上电荷的大小，`V` 是从负极板到正极板的电势差；两者都取正值，所以 `C` 恒为正。电容的单位是 `C/V`，称为**法拉**（F），常用 `µF`、`nF`、`pF`。

> [!IMPORTANT]
> **电容不由 `Q` 或 `V` 决定。**
>
> 对给定的电容器，`V` 加倍时 `Q` 也加倍，比值 `Q/V` 不变。电容只由**几何形状与所用材料**决定。教材的平行板公式
>
> `C₀ = ε₀A/d`
>
> 就是这一点：`A` 是极板面积，`d` 是板间距，`ε₀ = 8.85×10⁻¹² F/m` 是真空介电常数。`C₀` 的下标 0 表示板间是真空（或近似空气）。

**电介质**：插入板间的绝缘材料。它在电场中**极化**——分子中的负电荷向正极板一侧偏移、正电荷向负极板一侧偏移，表面出现束缚电荷，于是板间电场减弱、电势差变小，在同样电荷下电容变大：

`C = κ ε₀A/d = κ C₀`

`κ`（kappa）是**相对介电常数**，无量纲，对电介质 `κ > 1`。教材表中的值：真空 `1.00000`、空气 `1.00059`、特氟龙 `2.1`、聚苯乙烯 `2.56`、尼龙 `3.4`、纸 `3.7`、熔融石英 `3.78`、派热克斯玻璃 `5.6`、氯丁橡胶 `6.7`、水 `80`、钛酸锶 `233`。

**储能**：把电压 `V` 加在电容为 `C` 的电容器上，储存的电势能为

`U_E = ½ C V²`

用 `Q = CV` 还可写成 `U_E = Q²/(2C) = ½ Q V`。它的形式与动能 `½mv²` 类似。

## 论证

### K1 · 平行板电容由几何决定（尚无攻击）

- **主张**：真空平行板电容器的电容为 `C₀ = ε₀A/d`，与所加电压无关
- **前提**：板间电场近似匀强，`E = σ/ε₀`；两板电势差 `V = Ed`；每板电荷大小 `Q = σA`；教材的定义式与公式（ev-175）
- **推理**：把 `Q = σA` 与 `V = Ed = (σ/ε₀)d` 代入定义式：`C = Q/V = σA / [(σ/ε₀)d] = ε₀A/d`。`σ` 被约掉，说明电容与带电量无关。数值检验：`A = 1.00 m²`、`d = 0.0010 m` 时，`C₀ = 8.85×10⁻¹² × 1.00 / 0.0010 = 8.85×10⁻⁹ F ≈ 8.9 nF`；加上 `V = 3.00×10³ V` 后 `Q = CV = 2.66×10⁻⁵ C`，与教材的 `2.7×10⁻⁵ C` 一致
- **证据**：ev-175
- **被攻击**：公式忽略边缘场，只在 `d` 远小于板尺寸时近似成立；真实电容器有漏电、介质损耗与击穿电压；把「电容只由几何决定」绝对化也不对——材料（电介质）同样决定电容，教材随后用 `κ` 修正了这一点
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 插入电介质的效果取决于电路条件（尚无攻击）

- **主张**：插入相对介电常数为 `κ` 的电介质使电容变为 `κC₀`；若充电后**断开**电池（`Q` 不变），储能变为原来的 `1/κ`；若**仍接**电池（`V` 不变），储能变为原来的 `κ` 倍
- **前提**：`C = κC₀`；`U = Q²/(2C)` 与 `U = ½CV²`；教材关于「同样电荷下电介质使电场减弱、储能减少」与「先加电介质再充电可储存更多能量」的两段叙述（ev-175）
- **推理**：断开时 `Q` 固定，`U = Q²/(2C)`，C 增大 `κ` 倍即 `U` 变为 `1/κ`；能量差在插入过程中以对电介质的极化功（以及把电介质吸入的机械功）的形式释放。仍接电池时 `V` 固定，`U = ½CV²`，C 增大 `κ` 倍即 `U` 增大 `κ` 倍；此时电池还要多送电荷 `ΔQ = (κ−1)C₀V`，电池做功 `VΔQ = 2ΔU`，一半变成电容器的储能，另一半在充电回路中耗散或辐射掉
- **证据**：ev-175
- **被攻击**：教材的概念题「插入电介质如何影响储能」与两道判断题**没有说明电池是否仍接着**，而两种接法结论相反，这道题按原文无法唯一作答；教材只讨论了断开时的能量去向，没有计算仍接电池时电池做的功；「分子像小弹簧」只是定性模型，不能给出 `κ` 的数值
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 储能公式给出可检验的量级（尚无攻击）

- **主张**：`U_E = ½CV²` 能给出电容器储能的正确量级；教材的闪光灯例题与 10 µF 例题可以用它复核
- **前提**：`U_E = ½CV²`；`Q = CV`；教材的三个例题（ev-175）
- **推理**：相机闪光灯 `C = 200 µF`、`V = 100 V`，`U = ½ × 200×10⁻⁶ × (100)² = 1.0 J`；若在 `0.001 s` 内放出，功率 `P = U/t = 1.0/0.001 = 1 kW`，与教材一致。10 µF、120 µC 的例题：`U = Q²/(2C) = (120×10⁻⁶)² / (2 × 10×10⁻⁶) = 7.2×10⁻⁴ J = 0.72 mJ`，而教材印的是 `72 mJ`，大了 100 倍
- **证据**：ev-175
- **被攻击**：`½CV²` 假设电容在工作过程中不变；实际电容器有等效串联电阻、漏电与介质损耗，放电不是理想过程；闪光灯例题的 1 kW 是平均功率，瞬时功率更高；教材 10 µF 例题的数量级错误说明不能用它复核 `U`
- **署名**：@hpleapfrog · 2026-10-21

> [!IMPORTANT]
> **教材把 10 µF、120 µC 的储能算成了 `72 mJ`，正确值是 `0.72 mJ`。**
>
> 原文：`U_E = ½CV² = ½(10×10⁻⁶ F)(12 V)² = 72 mJ`。实际 `½ × 10⁻⁵ × 144 = 7.2×10⁻⁴ J = 0.72 mJ`，相差 100 倍。随后一句「普通商用电池可轻松提供这么多能量」在 `0.72 mJ` 下更成立，但数字本身必须按 `0.72 mJ` 记。

> [!IMPORTANT]
> **「插入电介质后储能增加还是减少」必须写明电路条件。**
>
> 教材的概念题只问「插入电介质如何影响储能」，两道判断题分别断言「插入电介质会增加能量」与「插入电介质会减弱电场」，都**没有说明电容器是否仍接在电池上**。正确结论是：**断开电池（`Q` 固定）**时 `C` 增大、`U = Q²/(2C)` 减小、`E = Q/(κε₀A) = E₀/κ` 减小；**仍接电池（`V` 固定）**时 `C` 增大、`U = ½CV²` 增大、而 `E = V/d` 不变。教材的 Critical Thinking 只讨论了断开的情形，本条把两种情形分开写。

> [!IMPORTANT]
> **12 µF 板间吸引力题的四个选项没有一个正确。**
>
> 题目：`C = 12 µF`、`V = 12 V`、每板面电荷密度 `σ = 7.2 mC/m²`，求一板对另一板的吸引力。由 `Q = CV = 1.44×10⁻⁴ C` 与 `A = Q/σ = 0.020 m²` 得 `d = ε₀A/C ≈ 1.48×10⁻⁸ m`，板间场强 `E = σ/ε₀ ≈ 8.1×10⁸ V/m`。一块板受到的力只由**另一块板**的场 `E/2` 产生：`F = QE/2 = Qσ/(2ε₀) ≈ 5.9×10⁴ N`。四个选项 `0.81×10⁵`、`0.81×10⁶`、`1.2×10⁵`、`1.2×10⁶ N` 都不对；其中 `1.2×10⁵ N` 正是漏掉 `½`（用整个 `E` 而不是 `E/2`）会得到的错误答案。

> [!IMPORTANT]
> **教材另有几处需要留意的错误与失配。**
>
> 电容的定义句漏了介词，写成 `can store energy an electric field`（应为 `in an electric field`）；一道求电容的选择题把选项单位写成 `nC` 而不是 `nF`（正确值 `2.3 nF`）；介电常数表把 `silicone oil` 写成 `Silicon oil`；教法提示说前缀 `di` 意为 `two or double`、并称电介质「can have two electric charges」，词源与物理都不对（`dielectric` 来自希腊语 `dia-`「穿过」+ `electric`）；模块末尾的 Performance Task 讲的是万有引力与库仑定律，与电容无关。本条不沿用这些说法。
