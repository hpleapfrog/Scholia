> [!TIP]
> **读完这一条，你应该**能说清「匀速圆周运动里『匀速』指的是什么不变」，并用 v = rω 和 a = v²/r 算出速度与加速度

## 定义

**匀速圆周运动**是物体沿圆周路径、**以恒定速率**运动：

> `the motion of an object in a circular path at constant speed`

这句话里的「匀速」是**速率**（speed）不变，**不是速度**（velocity）不变。速度是矢量，
它的**方向沿圆周的切线**，每时每刻都在变——所以物体**始终在加速**，
即便速度的大小一动不动。

| 量 | 关系 | 说明 |
|---|---|---|
| 转角 | `Δθ = Δs / r` | 弧长除以半径；单位弧度 |
| 角速度 | `ω = Δθ / Δt` | 转过多少弧度每秒 |
| 线速度 | `v = r ω` | **同一个 ω**，半径越大线速度越大 |
| 周期 | `T = 2π / ω` | 转一圈的时间 |
| 单位换算 | `1 转 = 2π rad = 360°` | `1 rad ≈ 57.3°` |

加速度指向圆心，叫**向心加速度**：

```
a_c = v² / r = r ω²
```

对应的合力分量就是**向心力** `F_c = m a_c = m v² / r`。

> [!IMPORTANT]
> **「匀速」这个词是这一节最大的坑。**
>
> 学生看到「匀速」就以为「什么都不变」，于是认为加速度为零。
> 教材的提示直接把问题问出来：
>
> > `[AL] Ask students whether or not velocity changes in uniform circular motion. What about speed? What about acceleration?`
>
> 三问的答案分别是：**变**、**不变**、**不为零**（指向圆心）。
> 这一条如果不问，后面所有向心力的计算都会建在「a = 0」的错误前提上。

## 论证

### K1 · 「速率不变、速度在变」是教材原话，不是本库的推论（尚无攻击）

- **主张**：匀速圆周运动的「匀速」指速率不变，速度因方向改变而持续变化，故存在指向圆心的加速度
- **前提**：教材把该运动定义为 `at constant speed`（ev-080），并把向心加速度定义为
  「垂直于速度的分量、指向圆心」（ev-081）
- **推理**：速度是矢量；方向改变即速度改变；速度改变即存在加速度——三步都是定义层面的
- **证据**：ev-080 · ev-081
- **被攻击**：**教材没有在正文里明说「匀速圆周运动有加速度」这一整句**，
  它给的是三个引导性提问（`What about acceleration?`）。**结论严格说来自加速度的定义，
  不是来自一句直引的断言。** 这一点如实写在这里，而不是把推论写成原文。
- **署名**：@hpleapfrog · 2026-10-18

### K2 · v = rω 的成立条件（尚无攻击）

- **主张**：`v = rω` 只在**角速度用弧度每秒**时成立
- **前提**：教材把转角定义为 `Δθ = Δs / r`，并用它推出 `v = rω`（ev-080）
- **推理**：弧长 `Δs` 与转角 `Δθ` 的定义式里，弧度是「弧长 / 半径」这个纯比值；
  换成「度每秒」时该比值要乘 `π/180`，`v = rω` 就不成立了
- **证据**：ev-080
- **被攻击**：尚无攻击
