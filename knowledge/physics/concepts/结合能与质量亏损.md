> [!TIP]
> **读完这一条，你应该**能把质量亏损 `Δm` 换算成结合能 `BE`（`1 u = 931.5 MeV/c²`），解释 `BE/A` 曲线为什么在铁附近最高，并说清「质量亏损」不是质量凭空消失

## 定义

### 结合能：把核拆开要付的能量

**结合能**（binding energy，BE）是把一个核完全拆成单独的质子与中子所需的能量；反过来，把这些核子从远处放到一起组成核时，会放出同样多的能量（ev-186）。

- 拆开时外力做正功，能量进入系统；拆开后的核子静止时，总静质量比原来大了 `BE/c²`
- 所以束缚系统比它的组成部分**更轻**：差多少，就束缚得多紧
- 结合能不是「核里存着的一份能量」，而是**拆开它必须付出多少能量**的度量
- 核子数越多，BE 越大；为了比较不同核的束缚程度，通常除以核子数，得到**每核子结合能** `BE/A`

### 质量亏损与 `E = mc²`

设核内有 `Z` 个质子、`N` 个中子，核的质量为 `m_核`：

`Δm = (Z m_p + N m_n) − m_核`

`BE = Δm c²`

`Δm` 就是**质量亏损**（mass defect）。用中性原子的质量计算更方便（ev-186）：

`BE = {[Z m(1H) + N m_n] − m(^{A}_{Z}X)} c²`

- `m(1H)` 是氢**原子**的质量，`m(^{A}_{Z}X)` 是中性的**原子**质量
- 两边各有 `Z` 个电子，电子质量相消；电子自身的结合能是 eV 量级，比核结合能的 MeV 量级小得多，忽略不计
- 换算：`1 u = 931.5 MeV/c²`，所以 `BE[MeV] = Δm[u] × 931.5`

教材的 α 粒子例题（ev-186，本库复算）：

| 量 | 数值 |
|---|---|
| `m(4He)` | `4.002602 u` |
| `m(1H)` | `1.007825 u` |
| `m_n` | `1.008665 u` |
| `Δm = 2m(1H) + 2m_n − m(4He)` | `0.030378 u` |
| `BE = Δm × 931.5` | `28.30 MeV`（教材给 `28.3 MeV`） |
| `BE/A = BE/4` | `7.07 MeV/核子` |

### `BE/A` 曲线与铁峰

`BE/A` 不是常数。教材给出的曲线（ev-186）：

- 平均约 `8 MeV/核子`
- 在 `A ≈ 60`（铁附近）达到最高
- 轻核（`A` 小）与重核（`A` 大）两端都更低
- 曲线上有若干尖峰，对应幻数核（如 `4He`、`12C`、`56Fe` 等特别紧的核）

教材的解释（ev-186）：强核力是**短程**吸引，库仑力是**长程**排斥。

- 轻核里，每个新增核子能与几乎所有其他核子吸引，`BE/A` 随 `A` 增大而上升
- 重核里，新增核子只能与附近核子吸引，但新增质子会受到**所有**质子的库仑排斥；吸引趋于饱和、排斥继续累加，`BE/A` 转而下降
- 因此 `A > 40` 的稳定核中子多于质子：多一个中子只增加吸引，不增加排斥

教材习题给出的几个读数（ev-186）：`2H` 为 `1.112 MeV/核子`，`12C` 为 `7.680`，`14C` 为 `7.520`，`209Bi` 为 `7.848`。这些数值与曲线一致。

> [!IMPORTANT]
> **质量亏损不是「质量凭空消失」。**
>
> 把一个束缚系统拆开，外力做的功变成了拆开后核子的静质量；反过来，核子结合时，系统把一部分静质量以动能、光子等形式放出。若把放出的能量也关在同一个盒子里，盒子的总质量—能量仍然守恒。所谓「亏损」，亏的是**束缚系统的静质量**，不是宇宙里少了一块质量。
>
> 另外，「`BE/A` 越大越稳定」是一条经验概括，不是充分条件。一个核能否衰变，还取决于它到**具体子核**的质量差、角动量与选择定则；`BE/A` 只告诉你它束缚得紧不紧。

> [!NOTE]
> **教材里的几处问题与本库的补写**（ev-185/ev-186）
>
> 1. m42640 的 Section Summary 写 `The larger the BE/A, the more stable the nucleus`，把稳定性简化成单一指标；本库在正文里把它降为经验概括，并在上面的 IMPORTANT 块说明边界。
> 2. m42640 说「宇宙中最常见的元素具有结合最紧的核」，但最丰富的元素是氢，氢核只有一个质子，没有「拆成质子与中子」的结合能可言。这句话是过度概括。
> 3. m42640 的解题策略说 β⁺ 用原子质量时「每个电子补偿 `0.511 MeV`」，没有说明 β⁺ 涉及**两个**电子（发射的正电子与失去的轨道电子）；按原子质量计算应为 `1.022 MeV`。本条目正文不使用该句，把它记为缺口。
> 4. m54574 的 Section Summary 把聚变放能说成「核子靠得更近，强核力减小」，与同一模块正文「产物 `BE/A` 更大、每核子质量更小」相矛盾；本库按正文与 `BE/A` 曲线处理，详见[核裂变与核聚变](核裂变与核聚变.md)。
>
> **本库补写、教材未给的**：`Q = ΔBE` 的反应能记账、`BE/A` 读数与 α 例题的两位小数复算、以及「质量亏损不是质量消失」的表述。教材给了 `BE = Δm c²`、α 粒子例题与 `BE/A` 曲线的定性解释，但没有把「能量释放 = 总结合能增加」写成一条规则。

## 论证

### K1 · 结合能就是质量亏损乘以 `c²`（尚无攻击）

- **主张**：`BE = Δm c²`；用中性原子质量时，`BE = {[Z m(1H) + N m_n] − m(^{A}_{Z}X)} c²`；α 粒子的 `0.030378 u` 对应 `28.30 MeV`
- **前提**：教材把 BE 定义为「把核完全拆成质子与中子所需的能量」，说束缚系统质量小于组成部分之和，给出 `Δm=BE/c²`、核质量公式与原子质量公式，并写 `1 u = 931.5 MeV/c²`；α 例题给出 `4.002602 u`、`1.007825 u`、`1.008665 u`、`0.030378 u`、`28.3 MeV`、`7.07 MeV/核子`（ev-186）
- **推理**：把核拆开，外力做功 `BE` 进入系统，拆开后核子的总静质量比原来大 `BE/c²`；反过来，核子结合时总静质量减少 `Δm`，减少的部分以能量放出。用中性原子质量时，反应式两边各有 `Z` 个电子，电子质量相消；剩下的电子结合能是 eV 量级，与 MeV 量级的核结合能相比可忽略。把 `Δm = 0.030378 u` 乘 `931.5 MeV/u` 得 `28.297 MeV`，取三位有效数字为 `28.3 MeV`；再除以 `A = 4` 得 `7.07 MeV/核子`
- **证据**：ev-186
- **被攻击**：**教材没有推导 `E = mc²`，也没有讨论「放出的能量带走了等价质量」在封闭系统里怎样记账**；它只把 `E = mc²` 当作已知关系使用。另外，原子质量公式忽略了电子结合能（教材习题自己算出氢原子电子结合能为 `13.6 eV`，与 `0.511 MeV` 的电子静质量相比约 `2.66×10^-5`），这不是严格相等，只是非常好的近似
- **署名**：@hpleapfrog · 2026-10-21

### K2 · `BE/A` 在铁附近最高，轻核与重核各自向峰值靠近时放能（铁峰两侧的定量对照是本库补写）

- **主张**：`BE/A` 在 `A ≈ 60` 附近最高；`A` 小于峰值的核靠聚变放能，`A` 大于峰值的核靠裂变放能；一次反应放出的能量等于产物总结合能减去反应物总结合能
- **前提**：教材说 `BE/A` 平均约 `8 MeV`、在 `A ≈ 60`（铁附近）最大、轻核与重核两端更低，并用短程强核力与长程库仑斥力解释；另一模块说轻核聚变放能、重核裂变放能，铁是分界，聚变产物的 `BE/A` 更大（ev-185/ev-186）
- **推理**：反应放能 `Q = BE_产物 − BE_反应物 = −(m_产物 − m_反应物)c²`。产物总结合能更大，说明产物总静质量更小，差值为放出的能量。对 `A < 60` 的轻核，聚变把核子移向峰值，`Q > 0`；对 `A > 60` 的重核，裂变把核子移向峰值，`Q > 0`。用教材的 `200 MeV/裂变` 除以 `236` 个核子得约 `0.85 MeV/核子`，与 `235U`（约 `7.6 MeV/核子`）到裂变产物（约 `8.4–8.5 MeV/核子`）的曲线抬升同量级；太阳 p-p 链的 `26.7 MeV` 除以 4 个质子得 `6.675 MeV/核子`，也落在轻核向峰值爬升的一侧
- **证据**：ev-185、ev-186
- **被攻击**：**教材只给 `BE/A` 曲线的定性形状，没有给 `235U` 与裂变产物的精确 `BE/A` 读数，也没有写 `Q = ΔBE` 这条规则**；上面 `7.6` 与 `8.4–8.5` 是本库按常见 `BE/A` 数据读出的近似值，不是教材原文。曲线的「铁峰」也是近似说法：最高点常在 `A ≈ 60` 的 `62Ni`、`58Fe`、`56Fe` 一带，而不是严格的「铁」

### K3 · 稳定重核需要更多中子，是短程吸引与长程排斥的几何结果（尚无攻击）

- **主张**：`A > 40` 的稳定核中子多于质子；原因是库仑排斥随质子数累加，而核吸引在短程内饱和
- **前提**：教材说稳定核在 `A ≈ 40` 以上中子多于质子，并解释重核 `BE/A` 下降是因为新增质子受所有质子的库仑排斥、而核吸引只作用于邻近核子（ev-186）
- **推理**：库仑排斥大致随 `Z²` 增长（每对质子都排斥），核吸引大致随 `A` 增长但在核变大后饱和（每个核子只与邻近核子吸引）。增加中子只增加 `A`、不增加 `Z`，所以能提高总吸引而不增加总排斥；重核因此需要 `N > Z` 才能稳定。教材还指出，这一效应随核变重而更明显
- **证据**：ev-186
- **被攻击**：教材没有给 `N/Z` 的定量曲线，也没有讨论配对效应、壳层效应与不稳定核；「`A > 40`」只是一个粗略的分界，不是严格的阈值。实际稳定核的 `N/Z` 分布还要由核壳层模型与 β 稳定线解释
