> [!TIP]
> **读完这一条，你应该**能说出阻尼为什么让振幅减小、区分欠阻尼/临界阻尼/过阻尼，解释受迫振动为什么在驱动频率等于固有频率时振幅最大，并说明阻尼大小怎样改变共振峰的高低与宽窄

## 定义

**阻尼振动**是有非保守力（摩擦、黏滞阻力等）参与的振动。教材用功与能量的关系描述它（ev-191）：

`W_nc = Δ(KE + PE)`

对阻尼振动，`W_nc < 0`：机械能减少，转化为热，**振幅逐渐减小**。阻尼很小时，周期与频率与无阻尼时几乎相同；阻尼增大到一定程度，周期与频率才明显改变。

按回到平衡位置的方式，教材区分三种情形：

- **欠阻尼**：物体穿过平衡位置一次或多次，振幅逐渐减小
- **临界阻尼**：物体尽可能快地回到平衡位置
- **过阻尼**：物体不振荡，比临界阻尼更慢地回到平衡位置

教材把临界阻尼用于汽车悬挂与指针式体重秤：希望指针或车身尽快稳定，又不要来回摆动。

**受迫振动**是物体在周期性驱动力作用下的振动。教材用拍球说明：手指慢慢上下移动时，球跟着动；驱动频率接近球的固有频率时振幅增大，等于固有频率时振幅最大；驱动频率继续升高，振幅又减小。稳定后的受迫振动按驱动频率进行——教材用跟随手指的球表达了这个意思，但没有写出这句话（见下方说明）。

**固有频率** `f0` 是系统在没有驱动、没有阻尼时会以之振动的频率（教材定义）。**共振**是驱动频率等于固有频率的现象（教材定义）；教材写 `The phenomenon of driving a system with a frequency equal to its natural frequency is called resonance.`

阻尼改变共振曲线的形状：阻尼越小，共振峰越高、越窄；阻尼越大，响应越低、越宽（教材的图注与 Section Summary）。教材的例子包括钢琴弦、秋千、收音机调谐、MRI（约 `100 MHz`）、塔科马海峡大桥（1940）、伦敦千禧桥、汽车悬挂与搓板路。驱动力做功补偿阻尼耗散时，受迫振动可以保持等幅——教材的 AP 答案明确写出这一点。

用量复算：

- 摩擦阻尼例题：`m = 0.200 kg`、`μ_k = 0.0800`、`X = 0.100 m`、`k = 50.0 N/m`，教材得 `f = 0.157 N`、`d = 1.59 m`。重算 `f = μ_k mg = 0.1568 N`、`d = k/(2f)(X² − (f/k)²) = 1.593 m`
- 教材习题：振幅每周期减小 `3.0%`，机械能损失 `1 − 0.97² ≈ 5.9%`（教材未给答案，本库复算）
- 减震器习题：`m = 1200 kg`、`v = 0.800 m/s`，需耗散 `½mv² = 384 J`（与教材答案一致）
- 桥梁习题：`k = 1.00×10⁸ N/m`、`X = 0.100 m`，储能 `½kX² = 5.00×10⁵ J`；从 `0.100 m` 增到 `0.500 m` 需 `½k(0.500² − 0.100²) = 1.20×10⁷ J`，以 `1.00×10⁴ J/s` 供给需 `1.20×10³ s`（与教材答案一致）
- 悬挂习题：`k = 5.00×10⁴ N/m`、`X = 0.0750 m`，储能 `½kX² = 141 J`（教材未给答案，本库复算）

> [!IMPORTANT]
> **临界阻尼在教材里有两种互相矛盾的说法。**
>
> 正文写 `The critically damped system may overshoot the equilibrium position, but if it does, it will do so only once.`
> 同一模块的图注与术语表却写 `without overshooting` / `without oscillating back and forth`。
> 本条按图注与术语表的「不越过」使用；正文的「可能越过一次」记为原文矛盾。

> [!IMPORTANT]
> **「稳定后按驱动频率振动」是本库对教材的补全。**
>
> 教材只说球跟着手指动、驱动频率接近固有频率时振幅增大，没有写出「稳定受迫振动的频率等于驱动频率」。
> 本条把这句话标明为补全；教材没有给受迫振动的方程、振幅-频率公式、相位滞后或品质因数。

> [!NOTE]
> **原文的四处问题。**
>
> 1. 正文说 `With less-than critical damping, the system will return to equilibrium faster`，这与「临界阻尼最快回到平衡」的定义冲突：欠阻尼可能更早穿过平衡位置，但包络衰减更慢，稳定下来并不更快。
> 2. AP 题给出 `d = 1.698 m`；按教材自己的公式与所给 `k = 50 N/m`、`μ_k = 0.06`、`m = 0.5 kg`、`X = 0.2 m`、`f = 0.294 N` 重算为 `3.40 m`，相差约 2 倍。本条不采用 `1.698 m`。
> 3. 塔科马海峡大桥被写成「风以共振频率驱动」的案例；本库没有读工程调查的原始报告，不把事故原因当成已证事实。
> 4. 教材把共振定义为驱动频率严格等于固有频率，并说三条共振曲线都在这一点达到峰值；它没有给振幅公式，因此峰值是否随阻尼移动、移动多少，本库无法由所核材料判断，记在缺口表。

## 论证

### K1 · 阻尼把机械能转化为热，三种阻尼按「回到平衡的方式」区分

- **主张**：非保守阻尼力做负功，机械能减少、振幅衰减；小阻尼时周期几乎不变；欠阻尼穿过平衡位置、临界阻尼最快回到平衡、过阻尼不振荡且更慢
- **前提**：教材给出 `W_nc = Δ(KE + PE)` 且阻尼时 `W_nc < 0`，定义三种阻尼并给出汽车悬挂与指针式体重秤的应用（ev-191）
- **推理**：`W_nc < 0` ⇒ `KE + PE` 减少 ⇒ 振幅减小；阻尼增大到临界时，回复力刚好使物体在不到达另一侧的情况下尽快回到平衡；阻尼更大时回复更慢；欠阻尼时回复力足以让物体越过平衡位置，但每次越过都损失能量。小阻尼的周期由回复力与质量决定，阻尼只缓慢移走能量，所以周期几乎不变
- **证据**：ev-191
- **被攻击**：教材对临界阻尼给出两种互相矛盾的说法（正文「可能越过一次」对图注与术语表「不越过」）；正文说欠阻尼「更快回到平衡」，与临界阻尼「最快」的定义冲突；没有阻尼方程、没有指数包络，也没有给出三种情形之间临界阻尼的判据
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 受迫振动在驱动频率等于固有频率时共振，阻尼越小峰越高越窄

- **主张**：周期驱动力使系统按驱动频率振动；驱动频率接近固有频率 `f0` 时振幅增大，等于 `f0` 时共振；阻尼越小，共振峰越高越窄，阻尼越大响应越宽越低
- **前提**：教材的拍球、钢琴弦、秋千、收音机与 MRI 例子，固有频率与共振的定义，以及阻尼对共振曲线的影响（ev-191）
- **推理**：驱动力每周期做功；驱动频率与系统自然频率一致时，能量输入与系统运动同步累积最有效，振幅最大；阻尼消耗能量，阻尼越小，能量在共振附近积累得越多、峰越尖；远离共振时驱动力与运动不同步，输入效率低，振幅小
- **证据**：ev-191
- **被攻击**：教材没有给受迫振动的方程、振幅-频率公式、相位滞后或品质因数；「稳定后按驱动频率振动」没有明写；「同步累积」是本库对教材定性图的解读，不是教材原句；有阻尼时共振峰的位置与高度，本库无法由所核材料定量判断
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 共振既可利用也须防止；教材的桥例混有未经核实的因果叙述

- **主张**：共振可用于选频与能量输入（收音机、MRI、秋千），也必须避免有害的大振幅（汽车悬挂、桥梁、士兵便步）；教材用塔科马桥与千禧桥作警示，但塔科马桥的「风以共振频率驱动」说法本库未能核实
- **前提**：教材的工程例子与 1940 年塔科马桥、伦敦千禧桥的叙述（ev-191）
- **推理**：若驱动频率可调，把系统设计成在工作频段内远离共振，或增大阻尼把共振峰压低拓宽，就能限制振幅；反之，选频器件要小阻尼、尖锐响应。教材的桥例说明振幅失控的后果，但没有给出设计判据
- **证据**：ev-191
- **被攻击**：教材没有给安全系数、阻尼比或设计规范；塔科马桥的破坏原因需要工程调查的原始报告才能判断，本库未读该报告，因此不把教材的因果叙述当作已证事实；千禧桥也只给了一句现象描述
- **署名**：@hpleapfrog · 2026-10-21
