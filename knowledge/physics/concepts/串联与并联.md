> [!TIP]
> **读完这一条，你应该**能判断两个电阻是串联还是并联，算出串并联组合的等效电阻，并说明为什么并联的等效电阻一定小于最小的支路电阻

## 定义

**串联**：元件在同一支路中一个接一个连接。串联电路的**电流处处相同**，各元件的电压降之和等于电源电压，等效电阻为

`R_eq = R1 + R2 + … + RN`

**并联**：每个元件的两端分别直接连在一起。并联各支路的**电压相同**，总电流等于各支路电流之和，等效电阻由

`1/R_eq = 1/R1 + 1/R2 + … + 1/RN`

给出，因此 `R_eq` 必小于最小的支路电阻。N 个相同的电阻 R 并联，`R_eq = R/N`。

教材算例：

- 串联：`1.0 + 6.0 + 13 Ω = 20 Ω`，接 `12 V` 得 `I = 0.60 A`，压降 `0.60 + 3.6 + 7.8 = 12 V`；已知 `R_eq = 150 Ω` 时 `R3 = 150 − 10 − 25 − 15 = 100 Ω`
- 并联：`10 / 25 / 15 Ω` 得 `R_eq = 4.84 Ω`，接 `3 V` 得 `I = 0.62 A`，支路电流 `0.30 + 0.12 + 0.20 = 0.62 A`；支路电阻越小，分到的电流越大
- 七个 `10 Ω` 电阻的混合网络化简为 `160/11 Ω ≈ 14.5 Ω`
- 另一个混合电路化简为 `104.09 Ω`，接 `10 V` 得 `0.096 A`；乱画的电路重画后化为 `8.6 Ω`，两条支路 `0.80 A` 与 `0.60 A`，总电流 `1.4 A`

> [!IMPORTANT]
> **「同一根导线内电压处处相同」是理想导线假设，不是关于真实导线的结论。**
>
> 两个模块都把导线当作完美导体（`perfect conductors`），并据此推出并联各支路两端的电压相同。真实导线有电阻，大电流下沿导线会有电势差；教材公式只在导线电阻可忽略时成立。本条沿用这个假设，但把它写明。

> [!IMPORTANT]
> **教材的等效电阻公式默认电池没有内阻。**
>
> 教材把电池电压当作固定值，例题与化简都直接令外电路端电压等于电池额定电压。真实电池有内阻，接上负载后端电压会下降——这正是「闭合电路欧姆定律与内阻」尚未建的部分。本条的 `R_eq` 只描述外电路。

> [!IMPORTANT]
> **原文有几处排版与用词缺陷，本条目没有沿用。**
>
> m54435 的学习目标第二条把 `and apply Ohm's law to resistors in series` 重复了两遍，选择题选项把 `5V` 打成 `5V4`；m54442 的复杂电路例题把等效电阻写成 `25.71 Ω R.`（多一个 `R`），并把电流说成 `across` 支路（应为 `through`）。这些缺陷不影响公式与算例的数值。

## 论证

### K1 · 串联：电流相同、电压相加，等效电阻为各电阻之和（尚无攻击）

- **主张**：串联电路的 `R_eq = R1 + R2 + … + RN`
- **前提**：教材先由欧姆定律写出各电阻的 `V_i = I R_i`，用「绕回路一周电势变化为零」的「山坡」类比得到 `V_battery = V1 + V2 + V3`，再与 `V_battery = I R_eq` 比较，得出串联等效电阻公式；`12 V` 与 `1.0/6.0/13 Ω` 的例题给出 `R_eq = 20 Ω`、`I = 0.60 A`，并用 `0.60 + 3.6 + 7.8 = 12 V` 回代校验（ev-166）
- **推理**：串联没有分支，电荷守恒要求各处电流相同；每个电阻上的电势降落相加等于电源升高的电势；把公共的 `I` 提出来，括号里就是各电阻之和
- **证据**：ev-166
- **被攻击**：推导用「绕回路电势变化为零」这一结论代替了基尔霍夫电压定律，却没有把它作为定律陈述；当回路中存在变化的磁通时这个结论并不成立（电磁感应），教材没有划出这个边界。把电源电压当作恒定量也默认了内阻为零
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 并联：电压相同、电流相加，等效电阻的倒数为各倒数之和（尚无攻击）

- **主张**：并联电路的 `1/R_eq = Σ 1/R_i`，因此 `R_eq` 小于最小支路电阻；N 个相同 R 并联得 `R/N`
- **前提**：教材指出并联各电阻两端连在同一对导线上，因此电压相同；再由电荷守恒写出 `I = I1 + I2 + I3`，代入 `I_i = V/R_i` 得 `I = V(1/R1 + 1/R2 + 1/R3)`，与 `V = I R_eq` 比较得公式；`10/25/15 Ω` 例题给出 `R_eq = 4.84 Ω`、总电流 `0.62 A`，支路电流 `0.30 + 0.12 + 0.20 = 0.62 A`；三个相同 R 并联用「三条相同路径」的推理与公式都得到 `R/3`（ev-167）
- **推理**：并联给电荷提供了多条支路，每条支路的电流由该支路电阻与公共电压决定，总电流是各支路之和；对相同的 `V`，把 `I/V` 相加就是各电导相加，所以等效电导变大、等效电阻变小
- **证据**：ev-167
- **被攻击**：公式依赖「各支路两端电压完全相同」，这又依赖理想导线与无内阻电源；教材用「路径越多越容易通过」的直觉说明 `R_eq` 小于最小电阻，但真正证明这一点的是公式本身，直觉不能代替它。教材也没有讨论并联支路共用导线上的压降
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 串并联逐步化简能处理「任意」电阻组合（尚无攻击）

- **主张**：教材把「先找只串联或只并联的一组、化为等效电阻、重画电路、重复」说成求 `any arbitrary combination of resistors` 等效电阻的一般方法
- **前提**：教材用七个 `10 Ω` 电阻的网络演示四步化简，得到 `160/11 Ω ≈ 14.5 Ω`；又用 `10 V` 的复杂电路化简到 `104.09 Ω`、电流 `0.096 A`，并把乱画的电路重画后化为 `8.6 Ω`（ev-167）
- **推理**：每一步替换都保持端口的 `V–I` 关系，因此反复替换不改变整个网络的等效电阻；对纯串并联网络，这个过程必然终止于一个电阻
- **证据**：ev-167
- **被攻击**：**并非任意电阻网络都能化为串并联组合**。电桥（惠斯通电桥）与 Y–Δ 网络没有「只串联或只并联」的子组，教材的四步法在第一步就找不到可化简的组；这类网络需要基尔霍夫定律或 Y–Δ 变换。教材的 `any arbitrary combination` 是过度概括，本条只采用它对串并联网络成立的部分
- **署名**：@hpleapfrog · 2026-10-21
