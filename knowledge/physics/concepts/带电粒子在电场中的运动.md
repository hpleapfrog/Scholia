> [!TIP]
> **读完这一条，你应该**能用 `qU = ½mv²` 算加速后的速度、用类平抛公式算偏转位移与偏转角，并说清为什么轨迹是抛物线而不是圆周

## 定义

**匀强电场中的力**：两块平行金属板间接上电势差 `U`，板间（忽略边缘）是匀强电场，场强大小

`E = U/d`

`d` 是板间距，方向从正极板指向负极板。电荷 `q` 在板间受电场力

`F = qE`

方向随 `q` 的正负而反向。由牛顿第二定律，加速度

`a = qE/m = qU/(md)`

对电子（`q = −e`）而言，电场力与电场方向相反，电子被正极板吸引。

**加速**：若粒子从静止出发、沿电场方向经过电势差 `U`，电场力做正功，动能增加。对加速过程取能量增益

`|q|U = ½mv²`

所以

`v = √(2|q|U/m)`

正电荷从高电势移向低电势时被加速，电子从低电势移向高电势时被加速；无论哪种，能量增益都等于 `|q|U`。教材的电子枪算例正是这一条：电子获 25.0 keV 能量，说明它经过的电势差是 25.0 kV（因为电子电荷大小为 `e`）。

**电子伏特**：一个基本电荷经过 1 V 电势差获得的能量定义为 1 电子伏特：

`1 eV = 1.60×10⁻¹⁹ J`

电子经过 100 V 得 100 eV；双正电荷离子经过 100 V 得 200 eV。`keV`、`MeV`、`GeV` 分别是 `10³`、`10⁶`、`10⁹` eV。

**偏转**：粒子以速度 `v₀` 垂直于电场方向射入板间（板长 `L`，板间距 `d`，电势差 `U`）。沿场方向做初速为零的匀加速运动，垂直场方向做匀速运动：

`t = L/v₀`（穿过板间的时间）
`y = ½at² = qUL²/(2mdv₀²)`（出板时的横向位移）
`tan θ = v_y/v₀ = at/v₀ = qUL/(mdv₀²) = 2y/L`（出板速度与入射方向的夹角）

轨迹是**抛物线**，与重力场中的平抛运动同形，所以叫「类平抛」。`y` 与 `tan θ` 的符号随 `q` 的正负改变；若入射速度不与场垂直，要先沿场和垂直场两个方向分解。

**示波管**：中国教材常把示波管作为应用——电子枪把电子加速，偏转板让电子束横向偏转，荧光屏把落点显示成亮点。OpenStax 的材料只提到电子可以在旧式电视管或示波管中被加速（m42324），没有给出静电偏转板的定量公式；本条的 `y` 与 `tan θ` 由匀强场、牛顿第二定律与抛体运动推导，不是教材原文。

> [!IMPORTANT]
> **轨迹是抛物线，不是圆周。**
>
> 匀强电场对电荷的力大小和方向都不变（恒力），所以横向加速度恒定，`y ∝ t²`，轨迹是抛物线。圆周运动要求力始终垂直于速度、且速度大小不变；这里的力方向固定，速度大小还在增加，两个条件都不满足。教材 Test Prep 把「圆周的一段」列为错误选项，正是这个区分。

> [!IMPORTANT]
> **加速公式用能量增益 `|q|U`，不要被源里的双负号绕住。**
>
> m42324 的电子例题把 `q = −1.60×10⁻¹⁹ C` 与 `V = −100 J/C` 同时代入 `v = √(2qV/m)`。两个负号相乘得正，数值 `5.93×10⁶ m/s` 是对的，但读者容易误以为「能量为负」。安全的写法是：先判断粒子是否被加速，再用 `|q|U = ½mv²`；电势差的正负只用来判断能量增减的方向。

> [!IMPORTANT]
> **高速时必须考虑相对论。**
>
> `½mv²` 与 `v = √(2qU/m)` 都是非相对论结果。教材明确提示：远高于 100 V 的加速电压会让电子速度大到必须计入相对论效应。25 keV 电子按经典公式得 `v ≈ 9.4×10⁷ m/s ≈ 0.31c`，相对论修正已约 4%；电压再高，经典公式会高估速度。

> [!IMPORTANT]
> **教材隐藏题把「4 倍射程」对应的质量增加说成 100%，实际是 1500%。**
>
> m42326 有一段被 HTML 注释隐藏的 Test Prep 题：两个电荷相同、初速相同的粒子从同一点射入匀强场，第二个打在正极板上的位置是第一个的 4 倍远；答案说第二个「质量多 100%」。但在横向偏转中，打到同一块板意味着横向位移 `y` 相同，而 `x = v₀√(2my/(qE))`，所以 `x ∝ √m`。射程 4 倍对应质量 16 倍，即多 1500%，不是 100%。按「多 100%」（质量 2 倍）只能得到 `√2 ≈ 1.41` 倍射程。

## 论证

### K1 · 加速公式由能量守恒给出（尚无攻击）

- **主张**：带电粒子从静止经电势差 `U` 加速后，`v = √(2|q|U/m)`
- **前提**：电场力是保守力；忽略重力（对电子与离子，电场力远大于重力）；非相对论；教材的电子加速例题与电子伏特定义（ev-176）
- **推理**：电场力做功 `W = |q|U`，由动能定理 `W = ½mv² − 0`，得 `v = √(2|q|U/m)`。数值检验：电子经 100 V，`v = √(2 × 1.60×10⁻¹⁹ × 100 / 9.11×10⁻³¹) = 5.93×10⁶ m/s`，与教材一致。电子枪 25.0 keV：`v = √(2 × 2.5×10⁴ × 1.60×10⁻¹⁹ / 9.11×10⁻³¹) ≈ 9.4×10⁷ m/s`，约为 `0.31c`，与「25 keV 需要相对论修正」的量级一致
- **证据**：ev-176
- **被攻击**：只适用于非相对论情形；忽略重力在极高能或极低电荷质量比时并非总是成立；教材把 `q` 与 `V` 都写成负值，符号约定容易误导；`U` 必须是粒子实际经过的电势差，不是电源电压
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 横向偏转是类平抛（尚无攻击）

- **主张**：垂直于匀强场射入的带电粒子做抛物线运动，`y = qUL²/(2mdv₀²)`、`tan θ = qUL/(mdv₀²)`
- **前提**：板间场强 `E = U/d`；`F = qE`；恒力，横向匀加速、纵向匀速；忽略边缘场与重力；教材的电子枪与 `E = V_AB/d`（ev-177）
- **推理**：`a = qE/m = qU/(md)`，`t = L/v₀`，所以 `y = ½at² = qUL²/(2mdv₀²)`；出板时 `v_y = at = qUL/(mdv₀)`，`tan θ = v_y/v₀ = qUL/(mdv₀²) = 2y/L`。数值检验：`v₀ = 1.0×10⁷ m/s`、`E = 1.0×10⁴ V/m`、`L = 0.020 m` 的电子，`t = 2.0×10⁻⁹ s`、`a = 1.76×10¹⁵ m/s²`、`y = 3.5×10⁻³ m`、`tan θ = 0.351`、`θ ≈ 19.3°`。质量标度检验：固定 `y` 时 `x = v₀√(2my/(qE)) ∝ √m`，所以射程 4 倍对应质量 16 倍——教材隐藏题的「多 100%」是错的（ev-177）
- **证据**：ev-177
- **被攻击**：公式假设场严格匀强、忽略边缘场；忽略重力；假设入射速度严格垂直于场；高速时 `m` 要用相对论质量（或直接放弃经典公式）；教材没有给出偏转公式，本条的 `y` 与 `tan θ` 是推导而非原文
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 电子枪的场强与力可以复核（尚无攻击）

- **主张**：25.0 keV 电子枪（板距 4.00 cm）的场强为 `6.25×10⁵ V/m`，对 0.500 μC 电荷的力为 0.313 N
- **前提**：电子是单电荷，25.0 keV 对应 25.0 kV 电势差；`E = U/d`；`F = qE`；教材的电子枪例题（ev-177）
- **推理**：`E = 25.0×10³ V / 0.0400 m = 6.25×10⁵ V/m`；`F = 0.500×10⁻⁶ C × 6.25×10⁵ V/m = 0.313 N`，与教材一致
- **证据**：ev-177
- **被攻击**：`E = U/d` 给出的是平均场，边缘处不均匀；把 25.0 keV 全部归为电势能减少，假设电子初动能为零且无碰撞；0.500 μC 是宏观电荷，放在板间会显著改变原有场，教材的「力与位置无关」只在忽略该电荷自身场的意义上成立
- **署名**：@hpleapfrog · 2026-10-21
