## 定义

### 速度选择器：交叉电场与磁场

让一个带电粒子垂直穿过互相垂直的匀强电场和匀强磁场。电场力 `qE` 与洛伦兹力 `qvB` 方向相反；两力大小相等时，粒子不受横向合力，沿直线通过（ev-182）：

`qE = qvB` ⇒ `v = E/B`

- 只有速度恰好等于 `E/B` 的粒子能直穿过去；速度偏大或偏小的粒子会被横向力推离轴线
- `q` 在等式两边约掉，所以选出的速度与**电荷量、质量、电荷符号都无关**——同一入射方向的任何电荷，只要速度是 `E/B` 就能通过（ev-182 的 Section Summary 写的是 `any charge`）
- 改 `E` 或 `B` 就能改选出的速度；这也是它叫「速度选择器」或「速度滤器」（velocity filter）的原因

> 速度选择器只筛速度，不筛质量。要测质量，还需要后面那一级磁场。

### 质谱仪：用磁场把质量分开

质谱仪（mass spectrometer）测的是离子的**质量**；大多数质谱仪靠磁场做到这一点（ev-182）。一种较简单的结构是三段（ev-182）：

1. **离子源**：像电子枪一样，给离子带上电荷、加速到某个速度 `v`，并引成一束
2. **速度选择器**：用上面的交叉场只放行速度为 `E/B` 的离子
3. **均匀磁场区**：只有磁场，离子垂直进入后做圆周运动，半径由 `r = mv/(qB)` 给出（公式见[洛伦兹力](洛伦兹力.md)）

在 `v`、`q`、`B` 都固定时，**半径与质量成正比**：`r ∝ m`（ev-182）。严格地说，质谱仪直接测到的是**质荷比** `m/q`；因为 `q` 总是电子电荷的整数倍，电荷态可以判定，质量也就确定了（ev-182）。

教材给的应用（ev-182）：化学与生物实验室用质谱按质荷比鉴定物质；医学上用质谱测量示踪同位素的浓度；蛋白质等生物大分子通常先打碎再分析，近来也可以把完整的病毒颗粒送进质谱仪；气相色谱或高效液相色谱常先做一次分离，再把样品送进质谱仪。

### 回旋加速器：让粒子在磁场里转着圈加速

回旋加速器（cyclotron）的磁场让粒子做圆周运动，电场只在两个半圆形金属盒（**D 形盒**，Dees）之间的狭缝里加速粒子。交变电压的频率固定；粒子每转一圈两次穿过狭缝，就被加速两次（ev-182）。随着能量增大，粒子的速率和轨道半径都变大，轨迹是一条**向外展开的螺旋**，到边缘时被引出（ev-182）。

关键事实是**周期与速率无关**（ev-182）：

`T = 2πm / (qB)`，`f = qB / (2πm)`，`ω = qB / m`

这三个式子由 `r = mv/(qB)` 与 `T = 2πr/v` 推出，推导在[洛伦兹力](洛伦兹力.md)的 K2；教材在习题里要求证明 `T = 2πm/(qB)`，并注明它与速率、半径乃至能量都无关（ev-182）。正因为周期恒定，电源才能用**固定频率**与粒子同步，每过一次狭缝就推它一把。

教材的两个数值例子（ev-182，本库复算）：

- 质子在 `B = 1.20 T` 中的回旋频率为 `18.3 MHz`
- 25.0 MeV 的质子在 `1.20 T` 中轨道半径为 `60.2 cm`

若 D 形盒的最大半径为 `R`，粒子能获得的最大动能由 `v_max = qBR/m` 给出（本库推导）：

`K_max = q²B²R² / (2m)`

### 同步加速器、直线加速器与「固定频率」的边界

回旋加速器的固定频率只在**非相对论**条件下成立。速率接近光速后，动量要用 `p = γmv`，周期变成 `T = 2πγm/(qB)`，随能量增大而变长；固定频率的电压就会与粒子失步（本库补充，教材未展开这一层）。

同步加速器（synchrotron）的做法是：加速过程中**同时提高交变电压的频率和磁感应强度**，让粒子在固定半径的轨道上越跑越快（ev-182）。磁感应强度要随能量提高才能把高能粒子维持在同样半径，所以高能同步加速器用超导磁体，而且尺寸很大（ev-182）。磁场使带电粒子偏转时会辐射能量，这种辐射叫**同步辐射**；直线加速器把加速管排成直线，就是为了避开电子在弯道上特别严重的同步辐射损失（ev-182）。

## 论证

### K1 · 速度选择器与电荷量、质量、符号都无关（符号无关是本库推理）

- **主张**：交叉场放行的速度是 `v = E/B`；这个条件不含 `q` 与 `m`，对同一入射方向的任何电荷都成立
- **前提**：教材写交叉电场与磁场「producing forces in opposite directions on the ions」，只有两力平衡的离子直穿，且 `qE = qvB`、`q` 约掉得 `v = E/B`；Section Summary 把它称为速度滤器，条件写成 `any charge`（ev-182）
- **推理**：两个力都与 `q` 成正比，`q` 约掉，所以质量不出现。对同一速度方向，把 `q` 换成负号，`qE` 与 `qv × B` 同时反向，两力仍然相反——因此正负电荷可以同时通过（只要速度方向相同）；速度不等于 `E/B` 的粒子会感到横向合力，被推离狭缝
- **证据**：ev-182
- **被攻击**：**「正负电荷都能通过」是本库由 `q` 约掉推出来的，教材只写 `any charge`，没有讨论符号**；教材也没有给狭缝几何、边缘场与速度展宽——真实的选择器通过的是一小段速度区间，不是一个精确值
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 质谱仪：固定 `v`、`q`、`B` 后半径与质量成正比（分离公式是本库推导）

- **主张**：离子在均匀磁场区的半径 `r = mv/(qB)`；固定 `v`、`q`、`B` 时 `r ∝ m`，因此测半径就能测质荷比；同一位置出发的同位素经半圆后分开 `2Δr`，且 `Δr/r = Δm/m`
- **前提**：教材说速度选择器把 `v` 固定后，磁场区里「the radius of the path r is simply proportional to the mass m」，并说明 `q` 是电子电荷的整数倍、电荷态可判定；m42375 的习题给出氧-16 与氧-18 的分离结果 `0.173 m`（ev-182）
- **推理**：把 `v = E/B` 代入 `r = mv/(qB)`，若两区用同一 `B`，得 `r = (m/q)(E/B²)`，半径只由质荷比与场决定。对同种电荷态，`Δr/r = Δm/m`；从同一点出发走半圆后，两条路径的落点相距 `2Δr`。用教材数据复算：氧-16 的 `r = 0.693 m`，氧-18 的 `r = 0.779 m`，`2Δr = 0.173 m`，与答案一致
- **证据**：ev-182
- **被攻击**：**`r = (m/q)(E/B²)` 与 `2Δr` 公式是本库把两段教材内容合起来推的，教材只给定性的「r 与 m 成正比」**；实际仪器还要靠标定与探测器，教材没有讲分辨率、峰形与电荷态混合带来的歧义
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 回旋加速器用固定频率，同步加速器必须调频调场（相对论限制是本库补充）

- **主张**：非相对论下 `T = 2πm/(qB)` 与速率无关，所以固定频率的交变电压能每半圈加速一次；最大动能 `K_max = q²B²R²/(2m)`；速率接近光速后周期随 `γ` 增大，固定频率失效，同步加速器必须同时提高频率与磁场
- **前提**：教材说回旋加速器用固定频率交变电场、粒子螺旋向外；每圈两次穿过 D 形盒之间的狭缝被加速；同步加速器「the frequency of the alternating voltage and the magnetic field strength are increased」以保持半径不变；m42388 的习题要求证明 `T`、`f`、`ω` 与速度、半径、能量无关（ev-182）
- **推理**：由 `T = 2πr/v` 与 `r = mv/(qB)` 消去 `v` 得 `T = 2πm/(qB)`，与速率无关，固定频率才能一直同步。每圈两次加速、每次获得 `qV`，一圈净增 `2qV`；半径随速率增大，到 `R` 时 `v_max = qBR/m`，于是 `K_max = q²B²R²/(2m)`。相对论下 `p = γmv`，`T = 2πγm/(qB)` 随能量增大，固定频率的电压会与粒子失步——同步加速器因此同时调频、调场
- **证据**：ev-182
- **被攻击**：**`K_max`、`γ` 与「固定频率失效」都是本库补的，教材只写同步加速器调频调场，没有解释原因**；推导忽略了狭缝渡越时间与电场相位，`K_max` 也假设粒子始终在理想轨道上
