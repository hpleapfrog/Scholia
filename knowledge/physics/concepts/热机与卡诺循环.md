> [!TIP]
> **读完这一条，你应该**能把热机的一次循环记成 `W = Q_h − Q_c`、把效率写成 `Eff = 1 − Q_c/Q_h`，用 `Eff_C = 1 − T_c/T_h` 算出两台储热温度之间的效率上限，并解释为什么真实热机既做不到 100%，也做不到卡诺效率

## 定义

### 热机与循环过程

**热机**（heat engine）是利用热传递来做功的装置；汽油机、柴油机、喷气发动机与蒸汽轮机都是热机（ev-183）。它从**高温储热**（hot reservoir）吸热 `Q_h`，对外做功 `W`，向**低温储热**（cold reservoir）放热 `Q_c`；两侧温度分别记作 `T_h`、`T_c`（ev-183）。

热机通常按**循环过程**工作：每个循环结束时，工作物质回到初态，所以内能变化为零（ev-183）：

```
ΔU = 0  ⇒  0 = Q − W  ⇒  W = Q_h − Q_c
```

- 教材用 `ΔE_int` 表示内能，本条按[热力学第一定律](热力学第一定律.md)的记号写 `ΔU`
- `Q_h` 是热机从高温储热吸收的热，`Q_c` 是热机向低温储热放出的热；教材把两者都当作正的**大小**，方向体现在 `W = Q_h − Q_c` 的减号上（ev-183）
- 因此循环热机的净功等于净吸热：`W = Q_h − Q_c`

### 效率

热机的**效率**是净功输出与从高温储热吸热之比（ev-183）：

```
Eff = W / Q_h = (Q_h − Q_c) / Q_h = 1 − Q_c / Q_h
```

只有 `Q_c = 0` 时效率才等于 1，即 100%；而第二定律的第二表述说，这在循环过程中不可能（ev-183）。教材还提醒：`Q_c` 通常「a very significant amount」，废热是热机不可避免的产物（ev-183）。

### 第二定律的第二种表述

教材把「用热来做功」这一面的第二定律写成（ev-183）：

> It is impossible in any system for heat transfer from a reservoir to completely convert to work in a cyclical process in which the system returns to its initial state.

也就是说：**任何循环热机都不可能把从储热吸来的热全部变成功**；至少有一部分 `Q_c` 要排给低温储热。

### 卡诺循环与卡诺效率

1824 年，法国工程师 **Sadi Carnot**（1796–1832）在研究当时刚兴起的蒸汽机时，提出了一个理论循环，现在叫**卡诺循环**（Carnot cycle）：它由两条**等温线**和两条**绝热线**组成，而且只使用**可逆过程**（ev-183）。使用卡诺循环的热机叫**卡诺热机**（Carnot engine）。

教材说，对卡诺热机，`Q_c/Q_h` 等于两侧储热的**绝对温度**之比（ev-183）：

```
Q_c / Q_h = T_c / T_h      （卡诺热机）
Eff_C = 1 − T_c / T_h
```

- `T_h`、`T_c` 必须用**热力学温度**（K），不能用摄氏度
- 第二定律的第三种表述：在给定的两个温度之间，卡诺热机的效率最高；所有只使用可逆过程的热机，在这两个温度之间的效率都等于这个上限（ev-183）
- 100% 的效率只有在 `T_c = 0 K` 时才可能，而绝对零度达不到（ev-183）
- 理想的卡诺热机虽然效率最高，却**没有功率**：可逆过程要无限缓慢地进行，所以它不能用来实际做功（ev-183）

真实的循环总含有摩擦、湍流等**不可逆过程**，`Q_c` 比可逆循环更大，效率更低；即使热机本身理想，外围的变压器、传动装置也会把一部分输出功重新变成热（ev-183）。

### 奥托循环：四冲程汽油机的模型

教材用**奥托循环**（Otto cycle）说明四冲程汽油机怎样把热变成功（ev-183）：

| 路径 | 过程 | 对应冲程 |
|---|---|---|
| AB | 绝热压缩，外界对气体做功 | 压缩冲程 |
| BC | 等容吸热 `Q_h`，压强与温度升高 | 点火燃烧 |
| CD | 绝热膨胀，气体对外做功 | 做功冲程 |
| DA | 等容放热 `Q_c`，温度与压强下降 | 排气与进气 |

- 净功等于 `P–V` 图上闭合路径**内部的面积**（ev-183）
- `CD` 段气体对外做的功大于 `AB` 段外界对气体做的功，所以有净功输出（ev-183）
- 热源温度越高、冷源温度越低，闭合面积越大，效率越高；教材由此把效率与两侧储热的温度联系起来，并说下一节要给出「绝对上限」（ev-183）
- 教材明确说：真实的奥托循环路径**并不严格对应**发动机的四个冲程（ev-183）

### 数值例子（本库复算）

**燃煤电厂**（ev-183）：每天从煤的燃烧吸热 `Q_h = 2.50×10¹⁴ J`，向环境放热 `Q_c = 1.48×10¹⁴ J`。

- 净功 `W = 2.50×10¹⁴ − 1.48×10¹⁴ = 1.02×10¹⁴ J`
- 效率 `Eff = 1.02/2.50 = 0.408`，即 **40.8%**
- 排给环境的比例 `1.48/2.50 = 59.2%`
- 每天耗煤 `2.50×10¹⁴ / 2.50×10⁶ = 1.0×10⁸ kg`；按 `C + O₂ → CO₂`，12 kg 碳生成 44 kg CO₂，`1.0×10⁸ × 44/12 ≈ 3.7×10⁸ kg` CO₂/天（37 万吨/天）
- 若全部功转成电能，平均功率 `1.02×10¹⁴ / 86400 ≈ 1.18×10⁹ W`，即 **1180 MW**

**压水堆**（ev-183）：高温侧 `300°C = 573 K`，低温侧 `27°C = 300 K`，卡诺效率 `1 − 300/573 = 0.476`，即 **47.6%**；教材说实际核电站约 35%，燃煤、燃油、燃气电站约 42%。

教材习题中的值（本库复算）：冷源 200°C、卡诺效率 30.0% 对应热源 **403°C**；卡诺效率 42.0%、冷源 27°C 对应热源 **244°C**，若真实热机只达到卡诺效率的 0.700，则热源要 **477°C**；450°C → 270°C 与 270°C → 150°C 两级蒸汽机串联的总效率为 **41.5%**，与单台 450°C → 150°C 的卡诺机相同；450°C 热源要达到 0.700 的卡诺效率，冷源需 **−56.3°C**，低于水的凝固点，因此该题的前提不合理（ev-183）。

> [!NOTE]
> **教材里的几处措辞问题与本库的补写**（ev-183）
>
> 1. m42234 在写出 `W = Q_h − Q_c` 后说 `all Qs are positive. The direction of heat transfer is indicated by a plus or minus sign. For example, Qc is out of the system and so is preceded by a minus sign.`——既说所有 `Q` 都是正的，又说 `Q_c` 前面带负号，措辞自相矛盾；本条目按「`Q_h`、`Q_c` 是正的量值，方向由公式里的减号表示」使用，不沿用原句的后半段。
> 2. m42234 说 `in every imaginable cyclical process, it is absolutely necessary for heat transfer from the system to occur in order to get a net work output`，紧接着只举 `DA` 段的放热为例；但 `BC` 段也有吸热。原句想说的是「必须有**放热** `Q_c`」，不是「没有任何热传递」。
> 3. m42235 的开头把喝水鸟称为 `an example of Carnot's engine`，并说除最初弄湿头部外它是 `a perpetual motion machine of sorts`。这个类比是科普化的：喝水鸟靠水**持续蒸发**与每次低头重新沾水运行，不是只输入一次能量，也不是在两个固定储热之间工作的卡诺热机。本条目不复述这个说法。
> 4. m42235 在「发明家声称效率」一题里说 `the best-ever achieved of about 70%`，没有给出来源；本条目只引用该题的判断逻辑（实际效率为卡诺效率的 96%，远高于现实水平），不把 70% 当作可核数据。
> 5. m42235 的 Section Summary 写 `Carnot cycles without heat loss may be possible at absolute zero`，与正文「100% 效率只在 `T_c = 0 K` 时可能」的表述不一致；本条目采用正文的说法。
>
> **本库补写、教材未给的**：用可逆循环的熵守恒推出 `Q_c/Q_h = T_c/T_h`（见 K2）。教材只把这条比值作为卡诺的结论直接给出，没有推导；本条目在 K2 明确标注这是本库借助 `ΔS = Q/T` 的补写。

## 论证

### K1 · 循环过程的能量账：`W = Q_h − Q_c` 与效率（教材直接给出，尚无攻击）

- **主张**：循环热机每转一周 `ΔU = 0`，净功 `W = Q_h − Q_c`，效率 `Eff = 1 − Q_c/Q_h`
- **前提**：教材说循环过程让系统在每个循环结束时回到初态，因此 `ΔE_int = 0`；把第一定律 `ΔE_int = Q − W` 用于整个循环，得到 `W = Q`，而 `Q = Q_h − Q_c`；效率定义为 `Eff = W/Q_h`（ev-183）
- **推理**：一周内内能回到原值，第一定律的账上只剩「吸热 − 放热 = 对外做功」。把 `W = Q_h − Q_c` 代入效率定义，就得到 `Eff = 1 − Q_c/Q_h`。效率只由「排掉多少热」决定；`Q_c` 越小效率越高，`Q_c = 0` 才等于 1。教材的例子与习题答案都能复算：`Q_h = 2.50×10¹⁴ J`、`Q_c = 1.48×10¹⁴ J` 给出 40.8%；`W = 10.0 kJ`、`Q_c = 8.50 kJ` 给出 `Q_h = 18.5 kJ`、54.1%；`W = 2.00×10⁸ J`、效率 5.00% 给出 `Q_h = 4.00×10⁹ J`、`Q_c = 3.80×10⁹ J`，合 0.667 桶燃料
- **证据**：ev-183
- **被攻击**：**教材没有讨论实际的机械损失与泵功**——它把 `W` 当作净输出，但没有说明轴承摩擦、冷却泵等如何进入这本账；例子把电厂当作理想循环处理。教材关于「所有 Q 都是正的」的措辞也自相矛盾（见 NOTE）。本库只复算它的算术，没有替它补工程模型
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 卡诺效率：`Q_c/Q_h = T_c/T_h` 与 `Eff_C = 1 − T_c/T_h`（教材断言，本库用熵补出推导）

- **主张**：对只使用可逆过程的卡诺热机，`Q_c/Q_h = T_c/T_h`，因此 `Eff_C = 1 − T_c/T_h`；在相同两个温度之间，任何热机的效率都不超过这个值
- **前提**：教材说卡诺循环由两条等温线与两条绝热线组成、只含可逆过程；`Q_c/Q_h` 等于两侧储热的绝对温度之比；`Eff_C = 1 − T_c/T_h`；真实热机的效率低于卡诺效率（ev-183）
- **推理**（本库补写）：把一个可逆循环看成在 `T_h` 处吸热 `Q_h`、在 `T_c` 处放热 `Q_c`。熵是状态量，循环一周后回到初态，所以总熵变为零：`Q_h/T_h − Q_c/T_c = 0`，即 `Q_c/Q_h = T_c/T_h`。代入 `Eff = 1 − Q_c/Q_h` 得 `Eff_C = 1 − T_c/T_h`。这条推导用的是[热力学第二定律](热力学第二定律.md)里的 `ΔS = Q/T`（ev-157）
- **证据**：ev-183（教材断言）、ev-157（`ΔS = Q/T`）
- **被攻击**：**教材没有推导这条比值，只写「What Carnot found was...」；上面的熵守恒推导是本库补的**，而且它默认吸热与放热各在一个恒定温度下可逆进行、工作物质经历的是理想卡诺循环。教材也没有证明卡诺定理（所有可逆热机在相同两温度间效率相同），只把它作为第二定律的第三种表述直接陈述。「卡诺热机没有功率」也只是定性说明，没有给出「无限缓慢」与功率之间的定量关系
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 奥托循环与 `P–V` 图：为什么效率与温度有关（教材的定性推理，尚无攻击）

- **主张**：循环的净功等于 `P–V` 图上闭合路径内部的面积；热源温度越高、冷源温度越低，面积越大，效率越高；这个规律与卡诺上限一致
- **前提**：教材逐步描述奥托循环的 AB 绝热压缩、BC 等容吸热、CD 绝热膨胀、DA 等容放热，并说 CD 段对外做的功大于 AB 段外界做的功；净功是闭合路径内部的面积；「The lower the temperature on the path AB, the less work has to be done to compress the gas... the higher the temperature along the path CD, the more work output there is」；教材还说真实四冲程的路径并不严格对应奥托循环（ev-183）
- **推理**：`W_net = ∮ P dV`，在 `P–V` 图上就是闭合曲线围出的面积。降低 AB 段的温度会降低压缩所需的外功，提高 CD 段的温度会增大膨胀做出的功，两者都增大面积，所以效率随 `T_h` 升高、`T_c` 降低而升高。这个趋势与卡诺效率 `1 − T_c/T_h` 一致，但奥托循环的效率还受压缩比限制，低于同温度的卡诺上限
- **证据**：ev-183
- **被攻击**：**教材没有给出奥托循环的效率公式**（例如含压缩比 `r` 与比热比 `γ` 的 `1 − r^(1−γ)`），也没有把奥托效率与卡诺效率做定量比较；`P–V` 示意图不是按比例画的，「面积 = 净功」也没有讨论摩擦与节流损失。教材说「循环必须有热传递才能有净功」时只举了放热段，表述不严谨（见 NOTE）
