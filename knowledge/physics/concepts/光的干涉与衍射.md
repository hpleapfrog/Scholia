> [!TIP]
> **读完这一条，你应该**能用 `d sinθ = mλ` 算双缝亮纹与光栅亮纹的位置、用 `D sinθ = mλ` 算单缝暗纹的位置、用 `θ = 1.22λ/D` 说明为什么口径越大分辨率越高，并解释「干涉与衍射是同一件事的两种说法」大致是什么意思

## 定义

**光的波动行为什么时候看得见**：光与比波长大得多的物体作用时走直线、像光线；与尺寸接近波长的物体作用时，干涉与衍射变得显著。**干涉是波的标志性行为**——两条缝（或更多缝）发出的波在屏上叠加，程差为整数倍波长处相长（亮），半整数倍处相消（暗）。**衍射**是波绕过开口边缘、向几何阴影里弯折的现象；开口越窄（越接近波长），弯折越明显。

**介质中的波长**：光从真空进入折射率为 `n` 的介质，频率 `f` 不变，波长变为

`λ_n = λ/n`

颜色由频率决定，所以进入水中颜色不变，但波长变短（`550 nm` 的绿光在水中约 `414 nm`）。

**Huygens 原理**：波前上每一点都可看作发出球面子波的新波源，这些子波以波速 `v` 向前传播，经过时间 `t` 后走过 `s = vt`；新波前是所有子波的包络面。要判断光绕过开口后往哪里走，就用这个办法逐点叠加。

**双缝干涉**（Young，1801）：两条很近的缝把同一束光分成两个相干光源。屏上某点到两缝的程差为 `d sinθ`（`d` 为缝距，`θ` 从中心轴量起，屏足够远）。于是

- 相长：`d sinθ = mλ`，`m = 0, ±1, ±2, …`
- 相消：`d sinθ = (m + ½)λ`，`m = 0, ±1, ±2, …`

`m` 叫级次。教材用 `d = 0.0100 mm`、第三级亮纹在 `10.95°` 的 He-Ne 激光数据反算出 `633 nm`，并指出这正是用干涉图样测波长的方法。条纹强度随角度减小，但教材只作定性说明。

**单缝衍射**：一条宽 `D` 的缝产生中央很宽很亮的极大，两侧是更暗更窄的次级极大。暗纹位置为

`D sinθ = mλ`，`m = ±1, ±2, …`（`m` 不能取 0）

屏很近或角度很小时可用 `Dy/L = mλ`（`L` 为缝到屏的距离，`y` 为暗纹到中央的距离）；教材只写了第一极小的 `Dy/L = λ`。中央极大的宽度是次级极大的两倍。用 `550 nm`、第二极小在 `45.0°` 的例题反算出 `D = 1.56 μm`。

**衍射光栅**：大量等距平行缝（缝距 `d`）。亮纹条件与双缝相同

`d sinθ = mλ`

但缝数越多，亮纹越窄越亮，暗区越黑，因此光栅比双缝更适合做光谱分析。白光入射时中央（`m = 0`）仍是白色，高级次把白光展开成从紫到红的彩带。用刻刀划玻璃可做透射光栅；CD 的螺旋沟槽、蛋白石与蝴蝶翅膀的微结构则是反射光栅，虹彩就来自不同角度上不同波长的相长干涉。教材用 `520 nm`、`d = 5,000 nm`（约每毫米 2,000 条）算出一级亮纹在 `5.97°`。

**分辨率的衍射极限**：圆孔（直径 `D`）的衍射图样是中央亮斑加一圈圈暗环，第一极小在

`θ = 1.22 λ/D`

`θ` 以弧度为单位。**Rayleigh 判据**：两个点光源的图样，当一个的中央极大正好落在另一个的第一极小上时，恰能分辨；因此可分辨的最小角距离就是 `1.22λ/D`。波长越短、口径越大，分辨率越高。教材用 `633 nm` 的 He-Ne 激光束、直径 `1.00 mm` 算出 `7.72×10⁻⁴ rad = 0.0442°`。任何镜头或反射镜都受这一极限限制：望远镜受主镜直径限制，人眼受瞳孔直径限制。**完美的分辨率不存在**——无论孔径多大、波长多短，图像总有某种程度的模糊。

> [!IMPORTANT]
> **教材说 CD「每毫米有 1,600 条沟槽」，与它自己给的 1,600 nm 间距矛盾。**
>
> 原文写 `they are extremely narrow—1,600 in a millimeter`，同一段又说沟槽间距是 `1,600 nm`。间距 1,600 nm 对应每毫米 625 条，不是 1,600 条。本条采用 `1,600 nm` 的间距（与 CD 轨道间距的通行值一致），不采用「每毫米 1,600 条」这个密度。

> [!IMPORTANT]
> **教材的 Concept Items 把 Rayleigh 判据的式子印成 `θ = λ/D`，漏掉了 1.22。**
>
> 同模块的正文、Key Equations 与同一组 Concept Items 的正确选项都写 `θ = 1.22λ/D`。`λ/D` 是单缝第一极小的角位置；直径为 `D` 的**圆孔**第一极小在 `1.22λ/D`，多出的 1.22 来自圆孔的几何。本条对分辨率一律用 `1.22λ/D`，对单缝一律用 `λ/D`，不把两者混用。

> [!IMPORTANT]
> **两个模块给的可见光范围不一致。**
>
> m54369 写 `380 to 750 nm`，m54371 写 `380–780 nm`。两者都是教材常用的近似端点，本条按 `380–750 nm` 叙述；引用 m54371 的 780 nm 时只说明差异，不把任一端点当作精确的物理边界。

> [!IMPORTANT]
> **m54369 的教学提示有两处笔误。**
>
> 原文写 `Note that the sign of an angle is always ≥ 1`：正弦（sine）的取值范围是 `0 ≤ sinθ ≤ 1`，讨论单缝衍射时 `θ` 在 `0°` 到 `90°` 之间，所以 `sinθ` 不超过 1；原文把 sine 写成了 sign。同一段还把 `λ` 拼成 `lamda`。本条按正确的说法写。

## 论证

### K1 · 双缝亮纹的位置由 `d sinθ = mλ` 决定，可反过来测波长（尚无攻击）

- **主张**：两条相干缝在屏上某点的程差为 `d sinθ`；程差等于整数倍波长时相长、半整数倍时相消，因此第 `m` 级亮纹满足 `d sinθ = mλ`，测出 `θ` 就能求 `λ`
- **前提**：Young 1801 年的双缝实验；屏足够远时两缝到同一点的角 `θ` 近似相同；He-Ne 例子（`d = 0.0100 mm`、`m = 3`、`θ = 10.95°` → `633 nm`）（ev-171）
- **推理**：两缝由同一波前照明，发出同相的子波；到屏上同一点的程差为 `d sinθ`。程差为 `mλ` 时波峰对波峰，为 `(m + ½)λ` 时波峰对波谷。代入 `0.0100 mm × sin 10.95° / 3` 得 `6.33×10⁻⁴ mm = 633 nm`，与 He-Ne 激光的已知波长一致，说明公式与远屏近似在该条件下合用
- **证据**：ev-171
- **被攻击**：公式假设缝无限窄、单色、屏无穷远、缝距远大于波长；真实缝宽有限，会使条纹被单缝衍射包络调制，模块只用「强度随角度衰减」一句带过；单缝的 `Dy/L` 形式依赖小角近似，角度大时必须回到 `sinθ`
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 单缝暗纹满足 `D sinθ = mλ`，中央极大是次级极大的两倍宽（尚无攻击）

- **主张**：宽 `D` 的单缝，第 `m` 个（`m` 为非零整数）暗纹在 `D sinθ = mλ`；中央极大位于两个一级极小之间，宽度是次级极大的两倍
- **前提**：教材把缝内光线两两配对、相距 `D/2` 的两条光线在 `D sinθ = λ` 时相差 `λ/2` 而相消的论证；`550 nm`、`m = 2`、`45.0°` → `1.56 μm` 的例子（ev-171）
- **推理**：`D sinθ = λ` 时，缝的上半每条光线都能在下半找到相差 `λ/2` 的伙伴，于是整个缝相消，给出第一极小。中央极大从 `−λ/D` 到 `+λ/D`，角宽度为 `2λ/D`；相邻两个极小之间的次级极大只有 `λ/D` 宽，所以中央极大宽一倍。代入 `2 × 550 nm / sin 45.0°` 得 `1.56 μm`
- **证据**：ev-171
- **被攻击**：教材的 `Dy/L = λ` 只写第一极小，用于更高级次时须写成 `mλ`；`45.0°` 的例题不能使用小角近似，教材本身用 `D sinθ` 而非 `Dy/L`，处理正确；模块没有给出单缝强度公式，中央极大「六倍高」之类的说法只在图注里出现
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 光栅把不同波长分开：`d sinθ = mλ`，级次越高分得越开（尚无攻击）

- **主张**：大量等距缝的光栅在 `d sinθ = mλ` 处产生细亮纹；同一级次下 `θ` 随 `λ` 增大，所以白光被展开成光谱；CD 的 1,600 nm 沟槽就是反射光栅
- **前提**：光栅方程；「光栅亮纹比双缝更窄更亮」的叙述；`520 nm`、`d = 5,000 nm`（约每毫米 2,000 条）→ `5.97°` 的例题；CD 沟槽间距 1,600 nm 与彩虹现象（ev-172）
- **推理**：每条缝都向同一方向发出子波，`d sinθ = mλ` 时所有缝的贡献同相叠加。缝数 `N` 越大，相长方向越窄（宽度大致与 `1/N` 成正比），所以光栅条纹比双缝锐利。`d` 固定时 `sinθ ∝ λ`，同一级次里红光的 `θ` 大于蓝光，白光因此被展开；`m = 0` 时 `θ = 0` 与波长无关，所以中央仍是白色
- **证据**：ev-172
- **被攻击**：光栅方程假设正入射、缝无限窄、单色，实际光栅有缺级、闪耀角与偏振依赖；教材把 CD 沟槽密度写成「每毫米 1,600 条」，与 1,600 nm 的间距矛盾；「宽度与 `1/N` 成正比」教材没有给出，本条只作量级说明
- **署名**：@hpleapfrog · 2026-10-21

### K4 · 衍射给分辨率设下 `θ = 1.22λ/D` 的下限（尚无攻击）

- **主张**：直径为 `D` 的圆孔或镜头，两个点光源的角距离小于 `1.22λ/D` 时无法分辨；波长越短、孔径越大，分辨率越高
- **前提**：圆孔衍射图样由一个中央极大与一圈圈暗环组成、第一极小在 `1.22λ/D`；Rayleigh 判据（一个图样的中央极大落在另一个的第一极小上时恰能分辨）；`633 nm`、`1.00 mm` → `7.72×10⁻⁴ rad = 0.0442°` 的例题（ev-172）
- **推理**：每个点光源都形成一个衍射图样。两个图样重叠后，若一个的中央极大落进另一个的中央亮斑以内，合成图样只剩一个峰，探测器无法判断有两个源；把第一极小的角位置作为可分辨的最小角距离，就得到 `1.22λ/D`。`λ` 越小或 `D` 越大，这个角越小，能分辨的细节越细
- **证据**：ev-172
- **被攻击**：Rayleigh 判据是一条约定，不是硬阈值，它假设两个源强度相等、圆孔、无像差、无大气扰动；真实系统还受像差、散射与探测器噪声限制。教材的 Concept Items 把式子印成 `θ = λ/D`（漏 1.22），与正文矛盾；对单缝第一极小确实是 `λ/D`，不能与圆孔混用。模块也没有给出 Abbe 公式或具体望远镜的数值
