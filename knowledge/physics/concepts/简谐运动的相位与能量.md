> [!TIP]
> **读完这一条，你应该**能把简谐运动写成 `x = X cos(ωt + φ)`、读出相位与初相，说明同频两振动的相位差怎样换算成时间差，并用 `E = ½kX²` 与 `v = ±ω√(X² − x²)` 计算任意位置的动能与势能

## 定义

**相位**是描述振动在一个周期中走到哪里的角。教材把匀速圆周运动的投影当作简谐运动（ev-190）：

`x = X cos θ`，其中 `θ = ωt`、`ω = 2π/T`

所以 `x(t) = X cos(2πt/T)`。`θ` 随时间以恒定的角频率 `ω` 增大，每增加 `2π` 投影完成一次全振动——相位就是「周期中的位置」。

更一般的写法是

`x = X cos(ωt + φ)`

其中 `θ = ωt + φ` 是相位，`φ` 是 `t = 0` 时的相位，叫**初相**。教材只给 `φ = 0` 的特例（`t = 0` 从最大位移处释放）；带 `φ` 的一般式是**本库补写**，不是教材原句。相位是角，单位是弧度（rad），不是位移。给定 `X` 与 `ω` 时，相位同时决定位移比例 `x/X` 与速度方向。

两个同频振动

`x₁ = X cos(ωt + φ₁)`，`x₂ = X cos(ωt + φ₂)`

的**相位差** `Δφ = φ₂ − φ₁` 不随时间改变。`Δφ = 2kπ` 叫同相，`Δφ = (2k+1)π` 叫反相。相位差与时间差的换算是 `Δt = |Δφ|/ω`（本库补写）：相位落后的振动晚 `Δt` 达到同一状态。

`ω = 2π/T = 2πf` 叫**角频率**，单位 rad/s。

### 能量

无阻尼弹簧振子的弹性势能与动能是

`PE_el = ½kx²`，`KE = ½mv²`

教材写 `KE + PE_el = constant`，即

`½mv² + ½kx² = ½kX²`

右边是 `t = 0`、`x = X`、`v = 0` 时的总能量。解出速度

`v = ±√(k/m)√(X² − x²) = ±ω√(X² − x²)`，`ω = √(k/m)`

- 平衡位置 `x = 0`：`|v| = v_max = ωX`，能量全为动能
- 端点 `x = ±X`：`v = 0`，能量全为弹性势能
- 任意位置：`KE = ½k(X² − x²)`，`PE_el = ½kx²`
- 由 `a = −(k/m)x = −ω²x` 可得 `a_max = ω²X`（本库由牛顿第二定律与 `ω² = k/m` 推出；教材未给）

单摆的小角度能量式由同一方程代换得到（教材）：

`v = Lω`、`k = mg/L`、`x = Lθ` ⇒ `½mL²ω² + ½mgLθ² = constant`

这里的 `ω` 是摆球的角速度 `dθ/dt`，与前面圆运动的角频率 `ω = 2π/T` 不是同一个量（见下方提示）。

教材例题：900 kg 汽车、`k = 6.53×10⁴ N/m`、`X = 0.100 m`，得 `v_max = 0.852 m/s`。重算：`√(6.53×10⁴/900) × 0.100 = 8.518 × 0.100 = 0.852 m/s`。教材 AP 题：`m = 1 kg`、`X = 1 m`、`T = 1 s`，得 `k = 4π²m/T² = 39.48 N/m`、`E = ½kX² = 19.74 J`（教材答案 `19.7 J`）。当 `v = v_max/2` 时 `x/X = √3/2 ≈ 0.866`（教材习题，本库复算）。

> [!IMPORTANT]
> **一般式里的初相 `φ` 是本库补写，不是教材内容。**
>
> 教材 m42245 只给 `x = X cos(2πt/T)`，等价于 `φ = 0`；它没有定义初相、相位差或时间差。
> 补写依据是相位的定义 `θ = ωt + φ`；凡本文用 `φ` 与 `Δφ` 的地方都按补写处理。

> [!IMPORTANT]
> **同一个 `ω` 在教材里有两个意思。**
>
> 圆运动投影与 `T = 2π/ω` 中的 `ω` 是**角频率**（常量，等于 `2π/T`）；
> 单摆能量式 `v = Lω` 中的 `ω` 是摆球**角速度** `dθ/dt`（随摆动变化）。
> 教材用同一个字母，没有提醒两者不同。

> [!NOTE]
> **原文的三处问题。**
>
> 1. AP 题把 `½kX²` 叫 `internal energy`；这是弹簧振子的机械能，不是热力学内能，同名不同义。
> 2. Section Summary 把 `v_max` 排版成 `Xkm`，按正文应为 `X√(k/m)`。
> 3. 教材只对弹簧振子写能量式；单摆是直接代换 `k = mg/L`、`x = Lθ`，没有说明这依赖小角度近似 `sinθ ≈ θ`。

## 论证

### K1 · 相位把「振到哪里、往哪边走」编码成一个角（投影式来自教材，初相与相位差为本库补写）

- **主张**：简谐运动可写成 `x = X cos(ωt + φ)`；相位 `θ = ωt + φ` 与振幅一起决定位移比例 `x/X` 和速度方向；同频两振动的相位差恒定，`Δφ` 对应时间差 `Δt = |Δφ|/ω`
- **前提**：教材把匀速圆周运动的投影当作简谐运动，给出 `x = X cos θ`、`θ = ωt`、`ω = 2π/T`（ev-190）
- **推理**：投影点以恒定 `ω` 绕圆运动，`x = X cos θ`；`θ` 每增加 `2π`，投影完成一次全振动，所以 `θ` 标记「周期中的位置」。两个同频振动的相位差 `θ₂ − θ₁` 不随时间变化；把 `θ = ωt + φ` 代入，`t = 0` 时 `θ = φ`，故 `φ` 是初相。教材只取 `φ = 0`（`t = 0` 在最大位移处释放），一般式由相位的定义补写
- **证据**：ev-190
- **被攻击**：教材没有给 `φ`、相位差或时间差，也没有证明「任何简谐运动都能写成余弦」；投影是运动学对应，不是从 `F = −kx` 出发的动力学推导。本库补写的一般式未由所核教材给出
- **署名**：@hpleapfrog · 2026-10-21

### K2 · 无阻尼简谐运动的机械能守恒，能量在动能与弹性势能之间往返

- **主张**：`½mv² + ½kx² = ½kX²`；任意位置 `KE = ½k(X² − x²)`、`PE_el = ½kx²`；`v_max = ωX` 在平衡位置
- **前提**：教材给出 `PE_el = ½kx²` 与 `KE + PE_el = constant`，并从 `x = X`、`v = 0` 解出 `v = ±√(k/m)√(X² − x²)`；教材写能量 `oscillates back and forth between kinetic and potential, going completely from one to the other`（ev-190）
- **推理**：无耗散时总能量等于初始势能 `½kX²`；代入 `½mv² + ½kx² = ½kX²` 得 `v(x)`。`x = 0` 时势能为零、动能最大；`x = ±X` 时动能为零、势能最大。用 `ω = √(k/m)` 可把 `v_max` 写成 `ωX`
- **证据**：ev-190
- **被攻击**：教材只对弹簧振子写能量式，单摆是直接代换，没有说明小角度条件；没有势能曲线或能量-时间图；假设无阻尼。教材 AP 题把 `½kX²` 叫 `internal energy`，与热力学内能同名不同义
- **署名**：@hpleapfrog · 2026-10-21

### K3 · 相位差给同频振动提供「时间差」的读法（本库补写）

- **主张**：同频同幅的两个简谐运动，若 `x₂` 的相位比 `x₁` 落后 `Δφ`，则 `x₂` 比 `x₁` 晚 `Δt = Δφ/ω` 达到同一状态；`Δφ = 0` 时步调相同，`Δφ = π` 时反相
- **前提**：教材给 `x = X cos θ` 与 `θ = ωt`（ev-190）；相位差与时间差的换算由本库补写
- **推理**：`x₁ = X cos(ωt)`、`x₂ = X cos(ωt + Δφ)`。令 `t′ = t + Δφ/ω`，则 `x₂(t) = x₁(t′)`：`x₂` 在 `t` 时刻的状态等于 `x₁` 在 `t + Δφ/ω` 时刻的状态，即 `x₂` 落后 `Δφ/ω`。`Δφ = π` 时 `x₂ = −x₁`
- **证据**：ev-190（只含投影关系；换算为本库补写）
- **被攻击**：教材没有相位差、时间差或两个振动叠加的讨论；本条不涉及不同频率的合成（拍）与相位差的实验测量，二者都记在缺口表
- **署名**：@hpleapfrog · 2026-10-21
