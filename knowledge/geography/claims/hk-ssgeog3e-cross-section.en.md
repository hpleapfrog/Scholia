## Statement

On p.20, p.21 and p.72 the English gloss is written **`cross-section`** (hyphenated),
whereas the latest glossary / curriculum guide gives **`cross section`** (no hyphen).

Reason for change: to conform to the latest geography (S4–S6) print-textbook compilation guide.

## Argument

### A1 · Publisher's statement (no attack yet)

- **Claim**: the publisher states this form does not match the latest compilation guide
- **Premise**: the OUP official errata list three page numbers and the correction (ev-014)
- **Reasoning**: the errata give the "original / corrected" columns and note the basis is a guide update
- **Evidence**: ev-014
- **Attacked**: none
- **Attribution**: @hpleapfrog · 2026-10-05

## Nature

**A terminology-standard update, not a knowledge error** — the original `cross-section` is acceptable in general English.

But it records the fact that **a textbook changes with the guide**, so it is a **timeliness** issue:

> The value of this kind of entry is that **it ages**. If the guide changes again, this entry needs re-review.
