## 目录约定

| 目录 | 存什么 |
|---|---|
| `知识点/` | **概念节点**：承载先修关系；教法挂在其下 |
| `命题/` | 有真假、需要收敛的知识主张 |
| `教法/` | 教学做法，条件性有效，**不收敛**，必填禁忌 |
| `误解/` | 常见错误概念，是教学资产 |
| `路径/` | 知识点的编排，含先修约束与目标 |
| `资源/` | 图示、动画、例题、习题 |

`evidence/` 在仓库根目录，为全库共享。

## 状态图例

| 状态 | 含义 |
|---|---|
| 草案 | 刚建立，证据不足 |
| 待审 | 有证据，等待复核 |
| 已确证 | 存活论证结论一致（**仅命题可用**） |
| 争议 | 存活论证结论冲突，并列展示，不选边 |
| 有效 | 条件性成立（教法 / 误解 / 资源 / 路径） |
| 需复审 | 证据过期或条件变化 |
| 已推翻 / 已失效 | 被更强证据推翻，或锚点无法定位 |

> [!IMPORTANT]
> **教法、误解、资源禁止使用「已确证」**——它们不存在唯一正确。

## 为什么大量条目停在「待审」

> [!NOTE]
> 按 [CONTRIBUTING](../CONTRIBUTING.md) 规则 3–4：
> 写成「已确证」需要**一名非作者的独立复核**，而**目前仓库只有一名贡献者**。
>
> 所以全部 14 条都停在非终态（`待审` / `有效`）——**这不是录入没做完，是规则在正常生效。**
> **允许长期悬置。** 等第二位贡献者出现，`已确证` 才可能出现。
