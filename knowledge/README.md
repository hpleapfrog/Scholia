## 目录约定

| 目录 | 存什么 |
|---|---|
| `命题/` | 有真假、需要收敛的知识主张 |
| `教法/` | 教学做法，条件性有效，**不收敛**，必填禁忌 |
| `误解/` | 常见错误概念，是教学资产 |
| `路径/` | 知识点编排，含先修约束与目标 |
| `资源/` | 图示、动画、例题、习题 |

`证据/` 在仓库根目录，为全库共享。

## 状态图例

| 状态 | 含义 |
|---|---|
| 草案 | 刚建立，证据不足 |
| 待审 | 有证据，等待复核 |
| 已确证 | 存活论证结论一致（**仅命题可用**） |
| 争议 | 存活论证结论冲突，并列展示，不选边 |
| 有效 | 条件性成立（教法 / 误解 / 资源 / 路径） |
| 需复审 | 证据过期或条件变化 |
| 已推翻 / 已失效 | 被更强证据推翻，或锚点无法定位 |

> [!IMPORTANT]
> **教法、误解、资源禁止使用「已确证」**——它们不存在唯一正确。

## 怎么贡献

| 你想做什么 | 去哪里 |
|---|---|
| 提问、讨论方法论、提出还不成熟的想法 | **Discussions**（不影响结论） |
| 报告一处疑似错误、提交一种教法 | **Issue**（用模板） |
| 真的修改知识本身 | **PR**（唯一能改变结论的通道） |

> [!WARNING]
> **👍 reactions 只用来排序注意力，绝不用来判定对错。**
> 结论由「证据等级 + 反驳关系」决定，不由人数决定。

## ⚠️ 关于示例数据

> [!CAUTION]
> **本目录当前的条目是格式示例，不是真实知识。**
>
> - `author` 与「复核」字段里的 `@alice` `@bob` `@carol` `@dave` **是虚构账号**，并不存在
> - `ev-xxx` 指向的课堂观察、测评数据**是构造的示例**
> - 条目日期（2026-09）**是示例日期**，不是真实录入时间
>
> **正式使用前必须：**
> 1. 用真实账号替换全部 `author` 与「复核」字段
> 2. 用真实、可核验的证据替换示例证据
> 3. 把 [CONTRIBUTORS.md](../CONTRIBUTORS.md) 里的名单换成真实贡献者
>
> 在此之前，请不要把这些条目的内容当作可信知识引用。
> 它们的作用只有一个：**演示格式**。
