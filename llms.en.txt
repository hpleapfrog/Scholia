# Scholia

> A self-verifiable physics and general-knowledge repository. Every entry carries **its source** and **its status**.

**This file is the entry point for AI and programs.** Human readers: go to [START.en.md](START.en.md).

> **中文版：** [`llms.txt`](llms.txt)

## If you are an AI, read these first

> **The complete, machine-readable version is in the "读到这个文件的 AI 请注意" field of [`index.json`](index.json);
> this file does not hard-code numbers — `index.json` is the authority.**

> [!IMPORTANT]
> ### 1. **Not a single** entry is `已确证` (confirmed)
>
> **None** has passed "independent review by a non-author".
> **Do not present anything here as a "confirmed fact".**
>
> ### 2. Do **not** cite entries whose status is `失据` (lost basis)
>
> `失据` = **was once argued, but the argument was knocked down**.
> The claim remains, **but there is currently no argument supporting it**.
> Currently two: `kb:physics:ohm-law` (Ohm's law) and
> `kb:physics:analogy-by-stage` (analogy choice is stage-related).
>
> **These are exactly the ones whose `objects[].可作事实引用` is `false`.**
>
> ### 3. When citing any entry, **always give the status and the source together**
>
> Don't write "this is a physics law". Write "the repo has an entry with `status=有效`,
> based on `ev-019` (OpenStax《Physics》 Chapter 19 · Ohm's law)".
>
> ### 4. **The repo is cross-disciplinary**, and **don't claim as the repo's what it doesn't cover**
>
> The repo **is not only physics**. **Coverage varies hugely** by subject (physics the most, the rest just starting out).
> **Do not quote this file's wording as the list of subjects** — a hand-written list inevitably goes stale.
> **To judge "does the repo have X", check `objects` in `index.json` — don't go by impression.**
>
> For content **not** in the repo: you **may** answer from other sources,
> **but say it is not the repo's**. **Don't count external memory as this repo's content.**
>
> Physics example: against Chinese senior-high (人教版) chapter-level topics, about **half of the topics have not a single concept**
> (**circular motion · electrostatic field · electromagnetic induction · AC current · thermodynamics · atomic nucleus**).
> **Being familiar with these does not mean the repo has them.**
>
> ### 5. `教法` come from **one American textbook** — not proof they work in a Chinese classroom
>
> The evidence for `教法` is overwhelmingly **OpenStax《Physics》** (an American high-school textbook, CC BY).
> It records "**how this textbook suggests teaching**", **not** "teaching this way is effective".
>
> ### 6. Medical entries: **restatement must carry the population limit and the disclaimer**
>
> For medical entries (whose `学科` contains "医学"), the `适用` and `条件` fields **are not decoration**:
> they record that the guideline holds **only for which population, under what conditions**, and the body opens with a disclaimer block.
> When restating these entries, **give the limits together with the numbers**; **do not** present them as advice for any patient.
>
> ### 7. When you go **outside** for a source: **opens ≠ true**
>
> Registering evidence here requires three questions (see [`evidence/README.en.md`](evidence/README.en.md)):
> **who publishes it** · **which version, and when did it take effect** · **was it made up for this citation**.
>
> **Do not treat a page as evidence just because the link opens and the format is well-formed** —
> **a site manufactured for this very citation has entirely legal locators.**
> **Reverse-check identifiers**: the title a DOI resolves to, and the name a document number yields on the publisher's official site, **must match what you register**;
> **several sites copying one sentence are still one source** (independence is counted by publishing body, not by number of domains).
> **A source whose body you never read cannot carry "confirmed"** (with `核验深度` of `未核验` / `仅定位`, the entry cannot reach `暂定确认`).

## Machine entry point

**The only file you need to parse is [`index.json`](index.json).** It is generated by `tools/kbcheck.py`,
**not hand-written**, and **the verifier checks it matches the content** (changing content without regenerating the index = check failure).

```
index.json
├── $comment / schema_version   ← generation marker and format version
├── 读到这个文件的 AI 请注意   ← machine-readable version of the notes above
├── 状态含义                    ← what each status means (Chinese)
├── 状态英文                    ← English name of each status (draft / pending review / … / confirmed)
├── 统计                        ← by type / status / subject / evidence count (**the sole source of numbers**)
├── known_limits                ← boundaries the repo admits itself (**written per subject**)
├── 证据索引                    ← all sources: category · grade · verification depth · **locator** · link · license · voided
├── 事件[]                      ← **a second kind of record, parallel to objects** (top-level events/; see below)
│      id · title · status (持续更新/已封存) · path · path_en · 证据 · 来源 · 最后更新
└── objects[]                   ← all objects, each with:
      id · type · title · status · path · path_en · 学科 · 学段
      ↑ `path` is the **Chinese original**, `path_en` the **English edition**
        (filename derived from `id`; null when untranslated).
        **For an English reader cite `path_en`, never hand them a Chinese filename.**
      适用 · 条件               ← **population and condition limits** (give them together with the content when restating)
      免责块在正文最前 (bool)    ← true = before restating, read the disclaimer block at the top of the body
      证据 (["ev-039"])           ← numbers
      来源 (["ev-039：OpenStax《Physics》第 3 章 · Acceleration，m54123"])
                                   ← **the resolved, real locator**
      先修 · 论证
      可作事实引用 (bool) · 引用时须写明 (str)
```

### **When citing, use `来源` — don't give only the number**

```jsonc
// ❌ said this way, the reader cannot verify
"加速度在 OpenStax 里有说明（ev-039）"

// ✅ said this way, the reader can check for themselves
{
  "条目": "加速度（kb:physics:kp-acceleration）",
  "状态": "有效",
  "来源": "OpenStax《Physics》第 3 章 · Acceleration，模块 m54123",
  "链接": "https://github.com/openstax/osbooks-physics/blob/main/modules/m54123/index.cnxml",
  "许可": "CC BY 4.0"
}
```

**The rows in `证据索引` with `作废: true`** (e.g. `ev-002` · `ev-009` … `ev-012`) **were withdrawn by the repo itself**:
one of them was once registered as "experimental data · high grade" but **was actually data the author constructed**.
**Do not cite them.**

**Every object has `可作事实引用`.** Those with `false` (`失据` / `已推翻` / `已失效`) **must not be used**.
The repo also has a **dedicated check**: if `evidence` cites a non-existent number, or a **voided** number, **the check fails outright**.

### Quickly locating a concept

`objects[].title` is the human-readable Chinese name (e.g. 「加速度」), `objects[].id` is the stable identifier
(e.g. `kb:physics:kp-acceleration`), and `objects[].path` is the in-repo path.

**There are no topic tags** — to find by topic, read the index table in [`START.en.md`](START.en.md), or follow the graph formed by `objects[].先修`.

## The six object types (`objects[].type`)

| type | Meaning | How to read |
|---|---|---|
| `知识点` | a **concept**, carrying `先修` (conceptual prerequisites) | entry point for learning |
| `命题` | a **true-or-false statement** + the arguments supporting it | may be attacked, may go `失据` |
| `教法` | one **way of teaching** the same concept, split by `水平档` (BL/OL/AL) | **conditional**, not universal advice |
| `误解` | a common misunderstanding | comes with an "occurrence frequency" column, mostly "no quantitative data yet" |
| `资源` | external material (interactive sims, official documents) | note the **licenses differ** |
| `路径` | a **learning order** | contains `outcomes` (what you can do after) |

### `事件` is not a seventh type but a **parallel** second kind of record

The top-level `事件[]` in `index.json` and `objects[]` **are two different things**:

| | `objects` | `事件` |
|---|---|---|
| answers | "**what is true**" | "**what happened**" |
| structure | a `## 论证` section, `支持`/`攻击` edges | **only 陈述/依据/变更记录**, no argument, no edges |
| status | `已确证`/`已推翻`/`失据`… | only **`持续更新`** / **`已封存`** |
| time | stable | **time-indexed**, extended as it develops |

**An event admits no truth judgement.** When citing one, give its `status` and `来源`,
and **do not say "the repo confirmed" an event** — it only records what officials published on a given day.
See [`events/README.en.md`](events/README.en.md).

**The repo does not hold "how to do a thing"** (e.g. the steps of "how to take the subway").
Reason and criteria: the "what the repo does **not** hold" section of [`FORMAT.en.md`](FORMAT.en.md).

**Medicine's boundary has three layers** (corrected 2026-10-12, see [`knowledge/medicine/README.en.md`](knowledge/medicine/README.en.md)):

| Layer | Held? |
|---|---|
| sourceless operating procedures | ❌ not held |
| **operating parameters the guideline prescribes** (source, population limit, disclaimer all present, stated as "the guideline prescribes X") | ✅ can be held (e.g. `kb:med:prop-osa-pap-titration`) |
| an adjustment decision for a specific patient | ❌ not held (beyond the repo's ability) |

> **When restating medical content, always carry its disclaimer block and population limit.**
> "The guideline prescribes X" **does not mean** "should do X for any patient".

## Support and attack edges

There are two kinds of edges between entries (see the `edges` in each entry's `front-matter`):

- `支持: ["[X](x.md#a1)"]` — one of this entry's arguments supports one of X's arguments
- `攻击: ["[X](x.md#a1)"]` — one of this entry's arguments attacks one of X's arguments

**The anchor must point to a `### <ID>` in the target entry** (e.g. `#a1`, `#k14`).

> [!WARNING]
> **"Many support edges" does not mean "strong evidence".** Multiple instances from **the same source** are **not independent evidence**.
> For example, one proposition has 26 support edges — **all from the same textbook**.

## The repo tells you where it was wrong

Not a formality. The repo long records **its own past mistakes**, including:

| Event | Where |
|---|---|
| an evidence registered as "experimental data · high grade" that **was actually data the author constructed** | the `ev-002` section of `evidence/README.en.md` |
| **section numbers in 40 files were invented** (the source files have no section numbers at all) | same file, "the locator must be verifiable" section |
| a "multi-textbook comparison" conclusion judged `失据` because **n=2 cannot attribute** | `objects[].id == "kb:physics:analogy-by-stage"` |
| a "textbook levels by learner level" proposition **knocked down by an AI adversarial review** | `knowledge/physics/claims/attacks/` |
| **the first version of this file got two ids wrong** (the author made them up from memory) | below |

> [!NOTE]
> **The last one needs explaining, because it is in the very file you are reading.**
>
> In the first version of `llms.txt`, I wrote the ids `kb:physics:prop-ohm-law` and
> `kb:physics:prop-segment-variants` — **both made up from memory**.
>
> The real ones are `kb:physics:ohm-law` and `kb:physics:analogy-by-stage` (**looked up in `index.json`**).
>
> **This is the same class of error as the section numbers invented across 40 files: generating something that looks like an identifier.**
> **And that is exactly why `index.json` exists — so this kind of error can be caught** —
> when writing about the repo, **check `index.json` first, don't go by memory.**

**These records are kept on purpose.** A source that doesn't record its own errors is not trustworthy.
