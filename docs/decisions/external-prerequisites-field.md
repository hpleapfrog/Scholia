# 库外前置终于有了字段：`外部先修` 的五项结构与七例迁移

> 关闭 [README](../../README.md)「未决（要紧的几条）」第 3 条。
> 评审前的例数、原话与三个选项见
> [库外前置攒到 7 例](out-of-library-prerequisites.md)；
> 现场记录见 [Issue #17](https://github.com/hpleapfrog/Scholia/issues/17)。
> 记录于 2026-10-29。

## 决定

新增**可选** front-matter 字段 `外部先修`，与 `edges.先修` **分开**：

```yaml
外部先修:
  - 名称: 几何中的角
    标识: angle
    学科: 数学
    学段: 初中
    来源: ev-026
```

它声明的是「**要懂这条，先会 X**」，而 **X 在本库没有节点**。
因此它**不是图边**：不参与 `先修` 无环检查，不进 `objects[].先修`，
也不表示本库已经拥有 X。

## 为什么不是自由文本

Issue #17 的选项 1 原文写的是「自由文本字段」。实现时改成了**五项结构**，
因为自由文本只能解决「写下来了」，解决不了下面三件事：

| 要解决的问题 | 自由文本的后果 | 结构字段的后果 |
|---|---|---|
| **同一前置反复出现** | 「角」「几何中的角」「angle」是三个字符串，数不出「4 个条目都需要它」 | `标识: angle` 可分组、可计数；≥2 个对象即提示「考虑建节点」 |
| **这条前置从哪来** | 没有地方放来源，「教材说它是前置」无法核实 | 每项强制一个 `来源: ev-###`，并复用 `R-EVID-01` 查存在与作废 |
| **中英双语对齐** | 英文名一翻译，两边就不相等；不翻译又不自然 | `名称` 可翻译；`标识` / `学科` / `学段` / `来源` 必须一致，可机检 |

换句话说：**自由文本记录的是「有人提过」，结构字段记录的是「谁、在哪、对多少条目提过」。**
后者才是 Issue #17 真正缺的东西——七例本来就是靠人工 grep 找出来的。

## 五个子字段

| 子字段 | 规则 | 为什么 |
|---|---|---|
| `名称` | 人读名称，可翻译 | 正文与索引要给人看 |
| `标识` | `[a-z0-9][a-z0-9-]*`，同一条目内唯一，跨条目复用 | **唯一可计数的键**；中文名、英文名、别名都不稳定 |
| `学科` | 文本；不在已登记学科里只**警告** | 库外前置本来就可能来自未收录学科，不能一刀切阻塞 |
| `学段` | 枚举：小学 / 初中 / 高中 / 大学 / 不限 | 与 `scope.学段` 同一套枚举，避免第二套词汇 |
| `来源` | **单个**已登记 `ev-###` | 一条声明对应一个可核实的出处；要列多个出处就写多条声明 |

> `来源` 故意不做成数组：数组会让「一条声明」与「一组证据」混在一起，
> 而本库还没有任何规则能判断「这组证据是否独立」。先保持一对一，等真有需要再扩。

## 七例迁移（8 条声明 / 4 个标识）

| `标识` | 名称 | 学科 · 学段 | 条目 | 来源 |
|---|---|---|---|---|
| `angle` | 几何中的角 | 数学 · 初中 | [光的反射](../../knowledge/physics/concepts/光的反射.md) · [反射-BL-几何前提](../../knowledge/physics/methods/光的反射-BL-几何前提.md) · [光的折射](../../knowledge/physics/concepts/光的折射.md) · [折射-BL-几何前提与n大于1](../../knowledge/physics/methods/折射-BL-几何前提与n大于1.md) | `ev-026` / `ev-038` |
| `inverse-trig` | 反三角函数 | 数学 · 高中 | [光的折射](../../knowledge/physics/concepts/光的折射.md) | `ev-038` |
| `vector` | 矢量与矢量加法 | 数学 · 高中 | [力（高中）](../../knowledge/physics/concepts/力-高中.md) · [加速度](../../knowledge/physics/concepts/加速度.md) | `ev-041` / `ev-039` |
| `angular-velocity-vector` | 角速度的矢量方向（右手定则） | 物理 · 高中 | [匀速圆周运动](../../knowledge/physics/concepts/匀速圆周运动.md) | `ev-080` |

- **`angle` 4 条、`vector` 2 条**——这正是「反复出现 ⇒ 考虑建节点」要抓的形状。
- 英文译本同步迁移；`名称` 译成英文，`标识` / `学科` / `学段` / `来源` 与中文一致。
- 正文里的原有说明**保留**：字段回答「声明过没有」，正文回答「为什么是它」。
  两者不是重复，删掉正文会让迁移变成一次信息损失。

## 机器管什么、不管什么

**管（`R-SCHEMA-20`，阻塞）**：

- `外部先修:` 声明了却没有任何列表项；
- 列表项缺五个子字段之一、出现未知子字段、同一项重复子字段；
- `标识` 不是 `[a-z0-9][a-z0-9-]*`，或在同一条目里重复；
- `学段` 不在枚举里；
- `来源` 不是单个 `ev-###`。

**管（`R-EVID-01`，阻塞）**：`来源` 指向不存在或已作废的证据编号。

**提示（不阻塞）**：

- 同一个 `标识` 在 ≥2 个对象里出现 → 「考虑建节点」；
- 同一个 `名称` 配了不同 `标识` → 可能同一前置被写成两个键；
- `学科` 不在已登记学科里 → 请确认不是笔误。

**不管（`M-12`，人判）**：

- 这条前置**是否真的必需**；
- 是否该为它**建一个知识点节点**；
- 「进阶 / 后续」是不是先修。

> [!IMPORTANT]
> **复发提示不是自动建节点的命令。** `angle` 出现 4 次是一个强信号，
> 但建节点要回答「它的适用范围、证据、双语正文是什么」——这些都不是计数能给的。
> 机器把「有人提过 4 次」变成可查的事实，决定仍然在人。

## 没有解决的部分

- **「进阶 / 后续」仍未建模。** 它们不是「库外前置」：一个是同主题的层次深化，
  一个是学完之后的去向。现有 3 处实例仍写在正文里；是否成为第四类边，需要另一次判断。
- **迁移只覆盖已知的七例。** 正文里可能还有没被 grep 到的前置表述；
  新条目由自检项与 `new_entry` 提示，旧条目只能在下一次编辑时补。
- **建节点仍需人。** 本字段的产出是「该考虑建节点」的清单，不是节点本身。
