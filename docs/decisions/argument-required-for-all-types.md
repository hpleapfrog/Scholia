# 为什么六种类型都必须有 `## 论证`

> 规则见 [FORMAT.md](../../FORMAT.md) §5「必备小节」。

上表（§5）**此前只在 `命题` 与 `教法` 两行列了 `论证`**，而 `kbcheck.py` 一直按
「所有类型都必须有」执行——**并且在自己的报错信息里注明「FORMAT.md §5」**。

> **也就是说：代码声称规范这么写了，而规范没写。规范比代码窄。**

**发现方式**：写「乘坐地铁」探针时，`路径` 被报
「缺必备小节「论证」（所有类型都必须有）」，而查表发现 `路径` 一行没有它。
**一个从未有人写过的 `路径` 第一次被写出来时，这个不一致才浮出来。**

**为什么所有类型都要有 `论证`**：本库的每一条内容都应当能回答「**我凭什么这么说**」。
`资源` 也要——「为什么这份资源值得收进来」本身是个主张
（见 [PhET 资源的 `R1`](../../knowledge/物理/资源/PhET-力与运动基础.md)）。
