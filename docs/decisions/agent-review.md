# 复核者可以是谁：agent 也能签 `已确证`

> 2026-11-05。一天内改过两次，这里记的是**最后**那次，以及为什么最后还是这么选。

## 一、问题

| 事实 | 数字 |
|---|---|
| `已确证` 的门槛 | 一名**非作者**复核 |
| 贡献者 | 1 人 |
| `待审` | 570 条，论证已写、证据已读到全文 |

**这不是内容问题。** 复核要核的东西早就摆在桌上了（`R-GRAPH-07` 报的「覆盖深度下限 = 全文」），
卡住的只有「谁来签」——而规则把笔只给了人。

## 二、先选了一个折中，然后被否掉

第一版方案是**顶分两格**：人签 `已确证`，agent 签 `已机审`，两者不共用一格。
理由写在当时的版本里：

> `已确证` 的全部价值是「机器没参与」。让 agent 也能写它，这一格就变成免费的了。

**作者当天否掉了这个折中**：一个人 + 一个 agent 就该能把一条推到顶，不该再造一格。
这条意见是对的——**两格几乎相同的东西，读者分不清，作者也记不住**。

## 三、最后的样子：一格，但把代价用信息偿还

`已确证` 现在有**两条署名通道**：

| 复核者 | 机器查什么 | 索引里写成 |
|---|---|---|
| **人**（非作者） | `author` 与变更记录里 **≥2 个不同 `@` 署名** | `复核者: 人` |
| **agent** | `## 复核记录` 四栏齐全（模型 · 日期 · 引文核验 · 限制） | `复核者: agent` |

两条通道**都要**溯源档 `T4`（引用的每份来源都读到全文）。

> [!IMPORTANT]
> **让 agent 签名的真实代价，不是「分数变便宜」，是「读者会误读」。**
> 一个人看到 `已确证`，会默认「有人看过」。所以这个代价必须用**信息**偿还，而不是用形容词：
> `复核者` 是 `index.json` / `citations.json` 里的**字段**，站点与 MCP 都会带出来。
> **没有这个字段的 `已确证`，按违规处理**（`R-SCHEMA-19` 保证它一定被算出来）。

## 四、agent 那条通道的四个栏，为什么是这四个

`模型` · `日期` · `引文核验` · `限制`。前三个是**可复算**的凭据：谁、何时、核了几条。
第四个是这条规则的良心：

- `限制` 写「能力有限」= **空话**，规则失效；
- `限制` 写「中国人教版是否也用这个表述，未核」= **可用**，下一个人知道从哪继续。

**判据**：打开一条 `复核者: agent` 的 `已确证`，看它的 `限制` 有没有具体到「哪一件事没判」。
做不到，就该回退到只认人。

## 五、第一条实例

[向心力不是一种新的力](../../knowledge/physics/claims/向心力不是一种新的力.md)：
`待审` → `已确证`，`复核者: agent`。5 条英文引文 5 条命中（阈值 0.92，逐条 1.00），
逐句对照 m54181 全文；`限制` 写明三件**没判**的事。

**这就是这条规则期望的样子：核得动的地方给数字，核不动的地方写出来。**

## 六、批量机审：一次签了 540 条，靠什么不变成盖章

一条条点太慢。`tools/batch_review.py` 把 572 条 `待审` 一次跑完，**签了 540 条**，
剩下的**留在 `待审`**。区别不在「跑得快」，在**每一类写的是不同的话**：

| 通道 | 条目长什么样 | 记录里必须写出 |
|---|---|---|
| OpenStax 勘误 API | 515 条勘误（数学 308 · 物理 200 · 地理/科学 7） | 编号存在 · `status`/`resolution` 与陈述一致 · `location` 章号对得上 |
| 教材模块 `m#####` | 54 条物理条目 | N 条英文引文 · 命中几条 · 逐句对照了哪个模块 |
| 官方文件 URL | 3 条 | 页面可访问 · 引文是否出现 |

**核不动的就不签。** 剩下 32 条的原因：12 条只有中文引文（无法字面比对）、
8 条来源是扫描 PDF、11 条引文未命中、3 条页面不含引文。
其中「引文未命中」是**真问题**——若干条把转述放进了引号（`力矩`、`光电效应`、`波粒二象性`），
正是 [引文核验](../../drafts/README.md) 存在的理由。它们该由人改，不该由机器签字放过。

> **这一批唯一不能自动化的事：`限制` 一栏。**
> 脚本按通道写具体限制（「未核当前网页版正文」「未判断中文教材等价性」「公式未验算」），
> 但它**不知道每一条真正的边界在哪**。所以批量签出的 509 条，`限制` 是**同一族**的话，
> 不是逐条想过的。**这是这笔交易的代价，写在这里，不藏。**
