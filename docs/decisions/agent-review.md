# agent 复核：为什么顶分两格，而不是把 `已确证` 让给机器

> 2026-11-05，作者决定：**不再要求第三个人**。一个人 + 一个 agent 也要能把一条推到顶。
> 这份记录写的是「推到哪里」与「为什么不推满」。

## 一、问题：天花板不可达，队列没有出口

| 事实 | 数字 |
|---|---|
| `已确证` | **0** —— 它要求一名非作者的人，而全库只有一位贡献者 |
| `待审` | 570 条，论证已写、证据已读到全文，只差一次复核（[GAPS](../GAPS.md)） |

这不是内容问题。**`R-GRAPH-07` 说这些条目的证据「覆盖深度下限 = 全文」，也就是复核者要核的东西已经摆好了。**
卡住的只有「谁来签」——而规则把签字权只给了人。

## 二、三个选项

| 方案 | 结果 | 为什么不选 / 为什么选 |
|---|---|---|
| A. 让 agent 也能写 `已确证` | 立刻有 570 条确证 | **最坏**。`已确证` 的全部价值是「机器没参与」，让 agent 写，它就和模型输出没有区别——而免费的最高分等于没有分 |
| B. 维持只认人 | 保持诚实 | 等于承认这个库永远停在 0，570 条队列是死重。**诚实但无用** |
| C. **另开一格 `已机审`** | 机器复核可达、且可辨认 | **选它**。它比 `暂定确认` 强、可复算；比 `已确证` 弱的只有「判断」，所以不叫确证 |

## 三、`已机审` 硬条件（都是机器能查的）

1. `## 机审记录` **四栏齐全**：`模型` · `日期` · `引文核验` · `限制`；
2. **溯源档 = `T4`**：引用的每一份证据都读到 `全文`（没读透就说「复核过」，复核的只是自己脑子里那版）；
3. 有 `## 论证`（`R-SCHEMA-17`）；
4. `限制` 一栏**不许空**：说得出自己判不了什么，才配叫复核。
   这不是道德要求，是**这条规则的可用性来源**——下一个复核者靠它知道从哪继续。

`R-SCHEMA-19` 强制前三条；`R-SCHEMA-17` 管第四条的前半。
注入样本见 `tools/verify_rules.py`（「写已机审却没留机审记录」）。

## 四、它不做什么

- **不做判断。** 机审只回答「原文有没有这么说」「结论有没有超出这一段」。
  学科上的适用性、教材体系的差异、教学有效性，都写进 `限制`，不写成结论。
- **不冒充人。** `llms.txt` 明确要求：转述 `已机审` 时必须说「agent 复核，非人工复核」。
- **不自动升级。** 一条 `已机审` 后来被人复核，改 `已确证` 要留下第二个 `@` 署名——两格之间没有自动通道。

## 五、第一条实例

[向心力不是一种新的力](../../knowledge/physics/claims/向心力不是一种新的力.md)：
`待审` → `已机审`。5 条英文引文 5 条命中（阈值 0.92，逐条 1.00），逐句对照 m54181 全文；
`限制` 里写清了三件**没判**的事（人教版是否同样表述、中文语境是否已把向心力当力种、
非惯性系那一段的边界）。**这就是这条规则期望的样子：核得动的地方给数字，核不动的地方写出来。**

## 六、什么时候该回退

如果 `已机审` 变成「一键通过」——记录里的 `限制` 开始写空话（「能力有限」）、
`引文核验` 只剩一个数字没有对照物——**这条规则就失效了，应当回退到只认人**。
判据很简单：**打开一条 `已机审`，看它的 `限制` 有没有具体到「哪一件事没判」。**
