# 面向学习者的三条规矩：来历

> 规则见 [FORMAT.md](../../FORMAT.md)「面向学习者的可读性」。

**这三条是 2026-10-05 补的，起因是一句批评：「这个仓库能被小白看到，并且轻易地能够学习到他想要的内容」。**

## 「读完你会什么」原先放错了地方

`知识点` 正文第一行必须是 `> [!TIP]`（读完你会什么）。这句话**原先写在 `front-matter` 的 `scope.目标` 里**。

- `kbcheck.py` **从来没有解析过 `目标`**（它只用 `scope.学段`）；
- 也就是说：**一句纯给人看、而且决定「读不读得下去」的话，被放在了「存机器需要的」那一半**——
  违反了 [FORMAT.md §1](../../FORMAT.md) 第 2 条硬规矩「同一个事实不写两处」。

**2026-10-05 起移出 front-matter，写进正文第一行。** 20 个 `知识点` 已改，**`scope.目标` 这个键不再使用**。

## 一次差点变成断言的自测

**第一版测量**：脚本扫「面向学习者的小节里，整行无中文的英文行」，报出 **196 行，涉及 43 个文件**。
我据此在规范里写了一句「这是个问题」。

**抽查之后发现数字高估了。** 以 `万有引力-AL` 为例（它报了 13 行，是最多的之一）：

```
教材的 [AL] 提示走一条跟「天体」相反的路：……      ← 中文导读
### 一、先让人犹豫，再让人算                        ← 中文小标题
> `Ask the students what the attraction would be…`  ← 英文引用（被计数）
**顺序是设计好的**：先猜，后算。                     ← 中文解释
```

**中文在。** 而且学生直接读的三类（`知识点` / `误解` / `路径`）里，这样的行**只有 5 处**——
196 行里绝大多数在 `教法`，而 `教法` 是**给老师看的**。

**「整行无中文」=「没有中文说明」是错的推断。** 引用行与说明分开写，本来就是自然的中文夹引文格式。

> 这与 `ev-002`（把可复算当成证据强度）和 40 个文件里编出来的节号是**同一类错：
> 把一个测量直接当成了结论**。

**所以规矩不是「翻译每一句」，而是那三条——而它们描述的是本库已经在做的事。**

## 第 1 条还没有机械化

一个「英文字符多、中文字符少」的检查是可行的，但**必然误报**（代码块、公式、专有名词、引用行）。
**上面那个 196 就是把误报当了真**——所以先不写检查，免得又来一个「给错建议的检查」
（见 [status-and-liveness.md](status-and-liveness.md) 里被删掉的那条）。
