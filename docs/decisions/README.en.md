# Decision Records

> **The spec ([FORMAT.md](../../FORMAT.en.md)) holds only the "rules"; this directory holds the "why".**
>
> The spec used to embed lots of cases, incidents, and reasoning. They have value — they explain where a rule came from and prevent repeating the same mistake — but they made the spec long, and readers open the spec to **look up rules**.
>
> So: **rules stay in `FORMAT.md`; the reasons move here.**
> **Moved, not deleted** — deleting the trace really does lose information (this is the repo's consistent stance toward voided evidence and invented section numbers).
