# 决策记录

> **规范（[FORMAT.md](../../FORMAT.md)）只写「规则」，本目录放开「为什么」。**
>
> 本库的规范里原本夹着大量案例、事故与推断过程。它们有价值——解释规则怎么来的、
> 防止重犯同样的错——但会让「规范」变得很长，而读者打开规范是来**查规则**的。
>
> 于是：**规则留在 `FORMAT.md`，理由搬到这里。**
> **搬、不删**——删掉痕迹才是真的丢信息（这是本库对待作废证据、编造的节号一贯的态度）。
